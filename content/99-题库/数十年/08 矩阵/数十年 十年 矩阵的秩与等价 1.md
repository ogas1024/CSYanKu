## 题干

1.  (25-1) 设 $n$ 阶矩阵 $A, B, C$ 满足 $r(A) + r(B) + r(C) = r(ABC) + 2n$，给出下列四个结论：

① $r(ABC) + n = r(AB) + r(C)$；

② $r(AB) + n = r(A) + r(B)$；

③ $r(A) = r(B) = r(C) = n$；

④ $r(AB) = r(BC) = n$。

其中正确结论的序号是（ ）

A. ①②.

B. ①③.

C. ②④.

D. ③④.

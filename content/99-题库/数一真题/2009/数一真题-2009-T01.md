## 题干

1. 当 $x \to 0$ 时, $f(x) = x - \sin ax$ 与 $g(x) = x^2 \ln(1 - bx)$ 是等价无穷小, 则 ( )

A. $a = 1, b = -\frac{1}{6}$.

B. $a = 1, b = \frac{1}{6}$.

C. $a = -1, b = -\frac{1}{6}$.

D. $a = -1, b = \frac{1}{6}$.

> [!note]- 原题截图
> ![[数一真题-2009-T01.png|500]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 要与三阶无穷小 $x^2\ln(1-bx)\sim-bx^3$ 等价，须先令一次项消失，故 $a=1$。此时 $x-\sin x\sim x^3/6$，从而 $-b=1/6$，选 A。

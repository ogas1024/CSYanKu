## 题干

21. （本题满分 6 分）

设 $\xi, \eta$ 是相互独立且服从同一分布的两个随机变量，已知 $\xi$ 的分布律为 $P\{\xi=i\}=\frac{1}{3}, i=1,2,3$。

又设 $X=\max\{\xi, \eta\}, Y=\min\{\xi, \eta\}$。

- **（1）** 写出二维随机变量 $(X,Y)$的分布律：

| $X\backslash Y$ | $1$ | $2$ | $3$ |
|:---:|:---:|:---:|:---:|
| $1$ | | | |
| $2$ | | | |
| $3$ | | | |

- **（2）** 求随机变量X的数学期望 $E(X)$.

> [!note]- 原题截图
> ![[数一真题 1996 T21.png|500]]

> [!success]- 答案与解析
> **答案：**
>
> 当 $x>y$ 时，$(X,Y)=(x,y)$ 对应 $(\xi,\eta)=(x,y)$ 或 $(y,x)$，概率为 $2/9$；当 $x=y$ 时概率为 $1/9$。故分布律为
>
> | $X\backslash Y$ | 1 | 2 | 3 |
> |:---:|:---:|:---:|:---:|
> | 1 | $1/9$ | 0 | 0 |
> | 2 | $2/9$ | $1/9$ | 0 |
> | 3 | $2/9$ | $2/9$ | $1/9$ |
>
> 边缘分布为 $P(X=1)=1/9$、$P(X=2)=3/9$、$P(X=3)=5/9$，所以
> $$\boxed{E(X)=\frac{1+6+15}{9}=\frac{22}{9}}.$$
>
> **解析：** 按最大值与最小值相等或不等分类列出联合分布，再求 X 的边缘分布和期望。

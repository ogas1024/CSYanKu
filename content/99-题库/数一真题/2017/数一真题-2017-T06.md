## 题干

6. 已知矩阵 $\mathbf{A}=\begin{pmatrix}2&0&0\\0&2&1\\0&0&1\end{pmatrix}$， $\mathbf{B}=\begin{pmatrix}2&1&0\\0&2&0\\0&0&1\end{pmatrix}$， $\mathbf{C}=\begin{pmatrix}1&0&0\\0&2&0\\0&0&2\end{pmatrix}$，则（ ）

A. A 与 C 相似，B 与 C 相似。

B. A 与 C 相似，B 与 C 不相似。

C. A 与 C 不相似，B 与 C 相似。

D. A 与 C 不相似，B 与 C 不相似。

> [!note]- 原题截图
> ![[数一真题-2017-T06.png|500]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 三者特征值均为 $2,2,1$。A 对特征值 2 的几何重数为 2，故可对角化并与 C 相似；B 对特征值 2 的几何重数为 1，不可对角化，故选 B。

## 题干

20. 设随机变量 X 与 Y 相互独立, 下表列出了二维随机变量 $(X,Y)$ 联合分布律及关于 X 和关于 Y 的边缘分布律中的部分数值, 试将其余数值填入表中的空白处.

| $X\backslash Y$ | $y_1$ | $y_2$ | $y_3$ | $P\{X=x_i\}=p_i$ |
|:---:|:---:|:---:|:---:|:---:|
| $x_1$ | | $\frac{1}{8}$ | | |
| $x_2$ | $\frac{1}{8}$ | | | |
| $P\{Y=y_j\}=p_j$ | $\frac{1}{6}$ | | | $1$ |

> [!note]- 原题截图
> ![[数一真题-1999-T20.png|500]]

> [!success]- 答案与解析
> **答案：**
>
> 设行边缘概率为 $r_1,r_2$，列边缘概率为 $q_1,q_2,q_3$。已知 $q_1=1/6$，且独立性给出
> $$p_{21}=r_2q_1=\frac18\Rightarrow r_2=\frac34,\quad r_1=\frac14.$$
> 再由 $p_{12}=r_1q_2=1/8$ 得 $q_2=1/2$，故 $q_3=1/3$。所有联合概率为行、列边缘概率乘积：
> $$
> \boxed{
> \begin{array}{c|ccc|c}
>  &y_1&y_2&y_3&r_i\\\hline
> x_1&1/24&1/8&1/12&1/4\\
> x_2&1/8&3/8&1/4&3/4\\\hline
> q_j&1/6&1/2&1/3&1
> \end{array}}
> $$
>
> **解析：** 用独立性 $p_{ij}=r_iq_j$ 先恢复边缘概率，再补全全部单元格。

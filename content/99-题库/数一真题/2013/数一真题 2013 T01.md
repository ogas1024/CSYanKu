## 题干

1. 已知极限 $\lim_{x \to 0} \frac{x - \arctan x}{x^k} = c$，其中 $c, k$为常数，且 $c \neq 0$，则（ ）

A. $k = 2, c = -\frac{1}{2}$

B. $k = 2, c = \frac{1}{2}$

C. $k = 3, c = -\frac{1}{3}$

D. $k = 3, c = \frac{1}{3}$

> [!note]- 原题截图
> ![[数一真题 2013 T01.webp|500]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** $\arctan x=x-x^3/3+o(x^3)$，故 $x-\arctan x\sim x^3/3$，所以 $k=3,c=1/3$，选 D。

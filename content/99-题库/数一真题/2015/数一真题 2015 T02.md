## 题干

2. 设 $y=\frac{1}{2}e^{2x}+\left(x-\frac{1}{3}\right)e^{x}$ 是二阶常系数非齐次线性微分方程 $y''+ay'+by=c e^{x}$ 的一个特解，则（ ）

A. a = -3, b = 2, c = -1.

B. a = 3, b = 2, c = -1.

C. a = -3, b = 2, c = 1.

D. a = 3, b = 2, c = 1.

> [!note]- 原题截图
> ![[数一真题 2015 T02.png|500]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** $e^{2x}$ 项要求齐次特征多项式以 2 为根，$xe^x$ 项要求 1 为根，故 $a=-3,b=2$；代入 $xe^x$ 得右端系数 $c=-1$，选 A。

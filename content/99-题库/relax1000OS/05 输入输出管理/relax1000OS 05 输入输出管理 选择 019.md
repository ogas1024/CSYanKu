## 题干

19. 引入缓冲区的原因包括（ ）。

I. 缓和 CPU 与 I/O 设备间速度不匹配的矛盾
II. 减少对 I/O 中断的频率，放宽对 CPU 中断响应时间的限制
III. 解决数据粒度不匹配的问题
IV. 提高 CPU 和 I/O 设备之间的并行性

A. I、II、III
B. Ⅰ、Ⅱ、Ⅳ
C. Ⅱ、Ⅲ、Ⅳ
D. Ⅰ、Ⅱ、Ⅲ、Ⅳ

> [!note]- 原题截图
> ![[relax1000OS 05 输入输出管理 选择 019.png]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** I 正确，凡数据到达速率与离去速率不同之处都可设置缓冲区，以缓和速率不匹配的矛盾。II 正确，在远程通信、磁盘/磁带控制器中配置缓冲寄存器，可减少对 CPU 的中断频率，放宽对 CPU 中断响应时间的限制。III 正确，缓冲区可解决生产者与消费者之间数据粒度（数据单元大小）不匹配的问题。IV 正确，缓冲区的引入可显著提高 CPU 和 I/O 设备间的并行操作程度，提高系统吞吐量和设备利用率。综上选 D。

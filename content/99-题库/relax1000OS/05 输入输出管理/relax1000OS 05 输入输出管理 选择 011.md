## 题干

11. 进程执行系统调用从键盘获取一个字符的输入而被阻塞，当用户在键盘上键入一个字符时，系统的正确处理流程是（ ）。

A. 键盘硬件 → 中断处理程序 → 设备驱动程序 → 进程调度 → 系统调用返回 → 用户程序

B. 键盘硬件 → 设备驱动程序 → 中断处理程序 → 系统调用返回 → 进程调度 → 用户程序

C. 键盘硬件 → 系统调用返回 → 设备驱动程序 → 中断处理程序 → 进程调度 → 用户程序

D. 键盘硬件 → 中断处理程序 → 系统调用返回 → 设备驱动程序 → 进程调度 → 用户程序

> [!note]- 原题截图
> ![[relax1000OS 05 输入输出管理 选择 011.png]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 完整处理流程：①键盘硬件——用户按键，键盘控制器生成编码存入内部寄存器；②中断处理程序——键盘控制器向 CPU 发出中断请求，CPU 响应中断，保存现场后转去执行内核中的键盘中断处理程序；③设备驱动程序——中断处理程序调用键盘驱动程序，驱动程序从控制器读取字符（可能做扫描码到 ASCII 的转换），放入内核输入缓冲区，并唤醒等待该输入的进程，使其从阻塞态变为就绪态；④进程调度——若被唤醒进程优先级足够高，调度程序会选择它投入运行；⑤系统调用返回——进程再次获得 CPU 后，从内核缓冲区取得字符，作为系统调用结果返回给用户程序，CPU 从内核态切换回用户态；⑥用户程序——继续执行后续逻辑。故选 A。

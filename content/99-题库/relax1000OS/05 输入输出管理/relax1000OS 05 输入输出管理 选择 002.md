## 题干

2. 下列关于 I/O 端口编址方式和访问 I/O 端口的叙述中，错误的是（ ）。

A. 在独立编址方式下，I/O 端口拥有独立的地址空间，访问这些端口需要使用专门的 I/O 指令

B. 在统一编址方式下，I/O 端口和内存单元统一编址，访问 I/O 端口就像访问内存单元一样，可以使用通用的访存指令

C. 采用统一编址方式时，用户程序可以直接通过普通的访存指令自由读写任何映射到内存地址空间的 I/O 端口，无需操作系统干预

D. 设备控制器中的数据寄存器、状态寄存器和控制寄存器都通过各自的 I/O 端口地址与 CPU 进行信息交互

> [!note]- 原题截图
> ![[relax1000OS 05 输入输出管理 选择 002.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** C 错误，即使采用统一编址（内存映射 I/O），映射到 I/O 设备寄存器的内存地址通常也受到内存保护机制的控制。用户程序在用户态下试图直接访问这些受保护的地址（即 I/O 端口）仍然会引发保护异常，或需要通过系统调用请求操作系统内核来执行实际的 I/O 操作。允许用户程序"自由读写任何……I/O 端口，无需操作系统干预"会破坏系统的安全性和稳定性。

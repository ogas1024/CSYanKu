## 题干

32. 在一个引入了标准 SPOOLing 输出系统（如共享打印机）的计算机中，用户进程 P1 发起打印系统调用到最终纸张打印输出，打印数据在系统内部流经的物理介质及管理软件的正确顺序是（ ）。

A. P1 用户空间 → 内核输入缓冲区 → 磁盘输入井 → 物理打印机

B. P1 用户空间 → 内核输出缓冲区 1 → 磁盘输出井 → 内核输出缓冲区 2 → 物理打印机

C. P1 用户空间 → 打印机数据寄存器 → 磁盘输出井 → 打印机控制逻辑

D. P1 用户空间 → 通用寄存器 → 内核输出缓冲区 → 物理打印机

> [!note]- 原题截图
> ![[relax1000OS 05 输入输出管理 选择 032.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 完整数据流向：①进程 P1 发出系统调用，数据从 P1 用户空间复制到内核的输出缓冲区 1；②系统的"井管理程序"启动，将数据从缓冲区 1 写入磁盘的"输出井"，此时 P1 即可直接返回继续执行；③独立的常驻系统进程"输出进程"在后台运行，从磁盘输出井读取待打印作业到内核输出缓冲区 2；④最终由输出缓冲区 2 送往慢速的物理打印机。整个路径为 P1 用户空间 → 内核输出缓冲区 1 → 磁盘输出井 → 内核输出缓冲区 2 → 物理打印机，选 B。

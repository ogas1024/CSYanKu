## 题干

9. 下列关于 DMA 的叙述中，正确的是（ ）。

A. DMA 在 CPU 和 I/O 设备之间建立一条直接数据通路

B. DMA 是一个专门负责输入/输出的处理机

C. I/O 过程由 DMA 控制器进行完成，CPU 只需要在预处理和后处理阶段进行干预

D. DMA 不需要 CPU 指出所取数据的地址与长度

> [!note]- 原题截图
> ![[relax1000OS 05 输入输出管理 选择 009.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** A 错误，DMA 在主存和 I/O 设备之间建立一条直接数据通路。
>
> B 错误，DMA 并不是处理机，只能单方面受 CPU 控制。
>
> D 错误，DMA 方式中，数据传输过程由 DMA 控制器进行控制，不需要 CPU 介入，但是数据传输的预处理和后处理阶段都需要 CPU 的干预，DMA 需要 CPU 在预处理时指出所取数据的地址与长度。

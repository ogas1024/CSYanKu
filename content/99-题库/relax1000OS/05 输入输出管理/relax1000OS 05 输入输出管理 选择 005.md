## 题干

5. 关于 I/O 接口的 I/O 逻辑说法错误的是（ ）。

A. 不同 I/O 接口的 I/O 端口不重复，各 I/O 逻辑同时对地址线上的地址进行译码，分辨出此次传输是否属于自己

B. 通过控制线的读/写信号来对地址标明的 I/O 端口进行读写

C. 对控制寄存器的 I/O 命令字进行译码，对外设发出具体的控制

D. 采集外设的状态，并通过控制线向 CPU 反馈设备状态信息以及发出中断请求

> [!note]- 原题截图
> ![[relax1000OS 05 输入输出管理 选择 005.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** A 正确，如果不同 I/O 接口的端口编号相同，那么无法分辨 I/O 指令中的地址属于哪个 I/O 接口，所以不同 I/O 接口的 I/O 端口不重复，对地址译码是 I/O 逻辑实现的功能之一。
>
> B 正确，定位好具体的 I/O 端口后，再根据读写信号（比如 IN 指令是读信号，OUT 指令是写信号）来进行具体的输入输出。
>
> C 正确，CPU 通过数据线向控制寄存器写入 I/O 命令字，I/O 逻辑接着会对 I/O 命令字进行译码，对外设发出对应操作命令。
>
> D 错误，状态信息也是通过数据线传输的（I/O 接口→CPU 寄存器），状态、控制寄存器通常共用一个。中断信号是通过控制线传输的（I/O 接口 IRQi 中断请求控制线→中断控制器），故本题选 D。

## 题干

1. 在操作系统中，I/O 设备是计算机系统与外部世界交互的桥梁。下列关于 I/O 设备及其管理方式的叙述中，错误的是（ ）。

A. 从数据传输单位来看，键盘和鼠标属于字符设备，而磁盘和磁带属于块设备

B. 为了方便用户使用和提高系统可移植性，应用程序通常通过物理设备名直接访问 I/O 设备

C. 设备控制器是 CPU 与 I/O 设备之间的接口，负责接收 CPU 命令并控制 I/O 设备完成具体操作

D. 按共享属性划分，打印机通常被视为独占设备，而磁盘则通常被视为可共享设备

> [!note]- 原题截图
> ![[relax1000OS 05 输入输出管理 选择 001.png]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** A 正确，字符设备是以字符为单位进行数据传输的设备，如键盘、鼠标、打印机等。块设备则是以数据块为单位进行数据传输的设备，如磁盘、磁带、光盘等。
>
> B 错误，为了实现设备无关性（或称设备独立性），方便用户使用和提高系统的可移植性与可适应性，应用程序通常通过逻辑设备名来请求使用 I/O 设备，而不是直接使用物理设备名。操作系统负责将逻辑设备名映射到具体的物理设备名。如果应用程序直接使用物理设备名，那么当物理设备更换或配置改变时，应用程序就需要修改，这不利于移植和维护。
>
> C 正确，设备控制器是介于 CPU 和 I/O 设备之间的硬件部件。它负责接收来自 CPU 的指令和数据，并将其转换为 I/O 设备能够理解的控制信号和操作序列，然后控制 I/O 设备执行具体任务。同时，它也会将设备的状态和 I/O 操作的结果反馈给 CPU。
>
> D 正确，独占设备在一段时间内只能被一个进程所使用，如打印机。可共享设备允许多个进程同时（宏观上）访问，如磁盘。操作系统会通过调度和管理机制来协调多个进程对共享设备的访问。

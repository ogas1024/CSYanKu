## 题干

87. 有两个并发进程 P1 和 P2，它们的程序代码如下(其中 x 为 P1, P2 的共享变量)：

P1( ) {
    x = 0;      // (1)
    y = -1;     // (2)
    z = x * y;  // (3)
    print z;    // (4)
}

P2( ) {
    x = 3;      // (5)
    c = x * x;  // (6)
    print c;    // (7)
}

可能打印出的 z 和 c 的值有（）。

A. z=0 或 -3; c=0 或 9

B. z=0 或 3; c=0 或 9

C. z=0 或 3 或 1; c=9

D. z=0; c=0 或 9

> [!note]- 原题截图
> ![[relax1000OS 02 进程管理 选择 087.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 按不同的交叉执行顺序分析：若按1,2,3,4,5,6,7顺序执行，(3)执行时x=0，故z=0*(-1)=0；(6)执行时x=3，c=3*3=9，得z=0，c=9。若按1,5,2,6,3,7,4顺序执行，(3)执行时x已被(5)改为3，z=3*(-1)=-3；(6)执行时x=3，c=9，得z=-3，c=9。若按5,1,6,2,7,3,4顺序执行，(6)执行时x已被(1)改回0，c=0*0=0；(3)执行时x=0，z=0，得z=0，c=0。因此z可能为0或-3，c可能为9或0，选A。

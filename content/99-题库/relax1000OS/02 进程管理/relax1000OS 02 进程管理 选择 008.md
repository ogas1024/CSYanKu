## 题干

8. 假设系统支持内核级多线程。在进程 P1 的线程 T1 与进程 P2 的线程 T2 之间发生 CPU 调度切换时，操作系统必须执行的操作不包括（ ）。

A. 将 T1 的通用寄存器内容保存到 T1 的线程控制块（TCB）中

B. 更新页表基址寄存器，使其指向 P2 的页表基址

C. 必须清空 TLB（快表）和 Cache（高速缓存）中的所有数据以保证地址转换正确

D. 切换内核栈指针，使其指向 T2 的内核栈

> [!note]- 原题截图
> ![[relax1000OS 02 进程管理 选择 008.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** A 正确：无论是进程切换还是线程切换，保存当前执行流的上下文（通用寄存器、PC 等）到其控制块（TCB/PCB）是必须的第一步。
>
> B 正确：由于是从进程 P1 切换到进程 P2，虚拟地址空间发生了改变。如果不更新页表基址寄存器，CPU 会使用 P1 的页表去翻译 P2 的虚拟地址，必然导致严重的内存访问错误。因此这是跨进程切换必须执行的操作。（注：如果是同进程内的线程切换，则不需要此操作，这也是本题强调 P1 和 P2 的原因。）
>
> C 错误：关于 TLB（快表）：TLB 缓存的是"虚拟地址→物理地址"的映射。因为 P1 和 P2 的虚拟地址空间不同（相同的虚拟地址映射的物理页框不同），进程切换后 TLB 中的映射关系失效，必须刷新/清空 TLB。关于 Cache（高速缓存）：Cache 缓存的是物理内存的数据副本。现代 CPU 的 Cache 通常采用物理地址索引，进程切换并不会导致物理内存中的数据失效。更重要的是，Cache 对操作系统是完全透明的，由硬件自动管理，操作系统在进程切换时不需要、也无法直接去"清空"Cache。因此，"必须清空 Cache"是严重的错误表述。
>
> D 正确：每个线程（无论属于哪个进程）在进入内核态时都需要使用独立的内核栈来保存内核局部变量和调用链路。因此，切换到 T2 时，必须将内核栈指针切换指向 T2 的内核栈。

## 题干

39．在段页式存储管理系统中，进程R和S共享数据段data，若进程R和S都想访问该data段里某个内存单元x，若x在R和S的段表中的段号分别为p1和p2，x所在页对应的页框号分别为f1和f2则下列叙述中，正确的是（）。

A. p1 和 p2 一定相等，f1 和 f2 一定相等

B. p1 和 p2 一定相等，f1 和 f2 不一定相等

C. p1 和 p2 不一定相等，f1 和 f2 一定相等

D. p1 和 p2 不一定相等，f1 和 f2 不一定相等

> [!note]- 原题截图
> ![[relax1000OS 02 进程管理 选择 039.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 每个进程拥有各自独立的段表，共享段data在不同进程段表中登记的段号是由各进程自己的地址空间布局决定的，因此p1和p2不一定相等。但由于data是被两个进程共享的同一物理数据段，其内部经过页表映射后最终都指向同一组物理页框，所以x所在页对应的页框号f1、f2一定相等。故选C。

## 题干

94. 某同学试图用以下算法以实现两个进程 P0 和 P1 的互斥访问：

```
// 进程 P0
void P0() {
    while (TRUE) {
        turn = 1;               // 语句①：先礼让
        flag[0] = TRUE;         // 语句②：后表达意愿
        while (flag[1] && turn == 1);
        临界区;
        flag[0] = FALSE;
    }
}
// 进程 P1
void P1() {
    while (TRUE) {
        turn = 0;               // 语句③
        flag[1] = TRUE;         // 语句④
        while (flag[0] && turn == 0);
        临界区;
        flag[1] = FALSE;
    }
}
```

关于该算法的评估，下列说法正确的是（ ）。

A. 该算法依然能完美保证"忙则等待"
B. 该算法会导致两个进程同时进入临界区，违背"忙则等待"
C. 该算法会导致死锁，违背"空闲让进"
D. 该算法满足"让权等待"

> [!note]- 原题截图
> ![[relax1000OS 02 进程管理 选择 094.png]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 假设P0执行完语句①（turn=1），此时发生进程切换；P1接着执行语句③（turn=0）和语句④（flag[1]=TRUE）。接着P1执行到while(flag[0] && turn==0)。由于此时P0还没执行语句②，flag[0]依然是FALSE，因此P1顺利跳出循环，进入临界区。此时若切换回P0，P0执行语句②（flag[0]=TRUE），然后检查while(flag[1] && turn==1)。由于turn已经被P1改成了0，turn==1为假，P0也跳出循环，进入临界区。两个进程同时在临界区，违背“忙则等待”，故本题选B。

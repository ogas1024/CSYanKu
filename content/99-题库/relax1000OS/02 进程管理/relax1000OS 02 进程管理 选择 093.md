## 题干

93. 两个线程使用以下算法处理对打印机设备的互斥访问，可能出现的问题是（ ）。

```
int turn=1;
void Thread1(){
        //other...
        while(turn!=1);
        //操作打印机
        turn=2;
        //other...
}
void Thread2(){
        //other...
        while(turn!=2);
        //操作打印机
        turn=1;
        //other...
}
```

A. 两个线程都无法使用打印机，发生饥饿现象
B. 两个线程同时使用打印机，打印出现错误
C. 若线程 1 没有使用打印机，转而执行其他操作，则线程 2 也无法使用
D. 不会发生错误，两线程正常使用打印机

> [!note]- 原题截图
> ![[relax1000OS 02 进程管理 选择 093.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 本题考察单标志法的缺点：若Thread1没有使用打印机、转而执行其他操作而没有将turn置为2，则线程2会一直在while(turn!=2)处等待，因此本题选C。

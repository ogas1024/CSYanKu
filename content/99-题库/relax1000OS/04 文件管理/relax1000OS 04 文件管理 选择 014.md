## 题干

14. 用户进程通过 read(fd, buf, len)读取文件数据。若该文件的数据块不在内存的页缓存中，操作系统内核在处理该系统调用时，涉及以下步骤：

① 将进程状态设为阻塞，并调用磁盘驱动程序发起 I/O

② 检查文件描述符 fd 的合法性及读写权限

③ 磁盘完成 I/O，触发中断，进程被唤醒并重新获得 CPU

④ 将数据从内核空间的缓冲区拷贝到用户空间的 buf 中

⑤ 陷入内核态，保存用户态上下文

正确的执行顺序是（）。

A. ⑤ -> ② -> ① -> ③ -> ④

B. ⑤ -> ① -> ② -> ③ -> ④

C. ② -> ⑤ -> ① -> ④ -> ③

D. ⑤ -> ② -> ④ -> ① -> ③

> [!note]- 原题截图
> ![[relax1000OS 04 文件管理 选择 014.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：**
>
> 系统调用的标准流程：陷入内核(⑤) → 检查参数合法性(②) → 发现缺块，发起 I/O 并阻塞进程(①) → 硬件中断唤醒进程(③) → 内核将数据从内核缓冲区拷贝到用户空间并返回(④)。

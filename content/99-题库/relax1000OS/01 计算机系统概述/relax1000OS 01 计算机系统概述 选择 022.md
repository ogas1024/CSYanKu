## 题干

22. 下列选项中，能够引起外部中断的有（ ）。

Ⅰ. 时间片结束

Ⅱ. 键盘输入

Ⅲ. 访存缺页

Ⅳ. I/O 操作结束

A. Ⅰ、Ⅱ

B. Ⅱ、Ⅲ、Ⅳ

C. Ⅰ、Ⅱ、Ⅳ

D. 全部

> [!note]- 原题截图
> ![[relax1000OS 01 计算机系统概述 选择 022.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 中断是指 CPU 对系统中或系统外发生的异步事件所做的一种响应。根据中断信号的来源，中断可以分为外部中断（或称硬件中断）和内部中断（或称异常、陷入）。
>
> 外部中断（Hardware Interrupts）：指来自 CPU 处理器以外的中断信号，通常由外部设备（如 I/O 设备、时钟）或外部事件引起。
>
> Ⅰ. 时间片结束：在分时操作系统中，时间片结束是由时钟部件（定时器）产生的时钟中断引起的。定时器是 CPU 外部的硬件，因此时钟中断属于外部中断。
>
> Ⅱ. 键盘输入：键盘是外部 I/O 设备，当用户按下键盘按键时，键盘控制器会向 CPU 发出中断信号，请求处理输入。这属于典型的外部中断。
>
> Ⅳ I/O 操作结束：当外部设备（如磁盘、打印机等）完成 CPU 下达的 I/O 操作后，会向 CPU 发出中断信号，通知 CPU 操作已完成。这也是一种常见的外部中断。
>
> 内部中断（Exceptions/Traps）：指来自 CPU 处理器内部的中断信号，通常是由于 CPU 在执行指令过程中检测到某些错误或特定条件而引起的。
>
> Ⅲ. 访存缺页：访存缺页是在执行一条指令的过程中，当该指令要访问的页面不在物理内存时，由 CPU 内部的内存管理单元（MMU）检测到并产生的一种异常。这属于内部中断。
>
> 综上所述，能够引起外部中断的是时间片结束、键盘输入和 I/O 操作结束。因此，选项Ⅰ、Ⅱ、Ⅳ正确，选 C。

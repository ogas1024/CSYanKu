## 题干

【3】设 $A=\begin{pmatrix}2&1\\-1&0\end{pmatrix},B=\begin{pmatrix}1&1\\0&1\end{pmatrix},C=\begin{pmatrix}1&0\\1&1\end{pmatrix},D=\begin{pmatrix}1&0\\0&1\end{pmatrix}$，则正确的是（）.

A. A 与 B 相似, B 与 C 合同 B. A 与 D 相似, B 与 D 合同

C. A 与 D 合同, B 与 C 相似 D. B 与 D 相似, C 与 D 合同

> [!note]- 原题截图（OCR 校对用）
> ![[数二880-线代-C12综选-003.png]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 排除法：A、B、C 均非对称阵，与对称的 D 都不合同，排除 B、C、D。验证 A：B 与 C 通过同一初等相似变换 $\begin{pmatrix}0&1\\1&0\end{pmatrix}$ 合同；A、B 特征值都是二重 $\lambda=1$ 且都只有一个线性无关特征向量，可解出可逆 $P=\begin{pmatrix}1&0\\-1&1\end{pmatrix}$ 使 $P^{-1}AP=B$，故 A 与 B 相似、B 与 C 合同，选 A。

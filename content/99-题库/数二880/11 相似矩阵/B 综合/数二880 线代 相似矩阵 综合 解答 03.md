## 题干

【3】设 A 是  $\mathrm{n}(n \geqslant 2)$ 阶矩阵， $\alpha_{1}, \alpha_{2}, \cdots, \alpha_{n}$ 是 n 维列向量，且  $A\alpha_{1} = \alpha_{2}, A\alpha_{2} = \alpha_{3}, \cdots, A\alpha_{n-1} = \alpha_{n}, A\alpha_{n} = 0, \alpha_{n} \neq 0$.

（I）证明： $\alpha_{1}, \alpha_{2}, \cdots, \alpha_{n}$ 线性无关；

（Ⅱ）求可逆矩阵P及三角矩阵B，使得 $P^{-1}AP=B$

> [!note]- 原题截图（OCR 校对用）
> ![[数二880 线代 相似矩阵 综合 解答 03.png]]

> [!success]- 答案与解析
> **答案：**
>
> （I）$\alpha_1,\alpha_2,\cdots,\alpha_n$ 线性无关；（II）取 $P=(\alpha_1,\alpha_2,\cdots,\alpha_n)$，$B$ 为次对角线全为 1、其余为 0 的 n 阶矩阵，使 $P^{-1}AP=B$。
>
> **解析：** 用 $A^{n-1},A^{n-2},\cdots,A$ 依次左乘 $\sum k_i\alpha_i=0$ 逐步消去系数证明线性无关；由 $A\alpha_i=\alpha_{i+1}(i<n),A\alpha_n=0$ 直接写出 $AP=PB$ 的矩阵形式。

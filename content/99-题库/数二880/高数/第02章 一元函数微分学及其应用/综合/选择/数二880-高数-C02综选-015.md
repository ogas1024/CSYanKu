## 题干

A. 当 n 为奇数时， $x_{0}$ 是 f(x) 的极大值点

B. 当 n 为奇数时， $x_{0}$ 是 f(x) 的极小值点

C. 当 n 为偶数时， $x_{0}$ 是 f(x) 的极小值点

D. 当 n 为偶数时， $x_{0}$ 是 f(x) 的极大值点

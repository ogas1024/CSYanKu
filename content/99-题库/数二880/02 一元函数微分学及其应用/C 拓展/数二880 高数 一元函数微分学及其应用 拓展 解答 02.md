## 题干

【2】设 f(x) 在 [a,b] 上有二阶连续导数,且 f(a) = f(b) = 0,M =  $\max_{a \leq x \leq b} |f''(x)|$.

(I) 证明:  $\max_{a \leq x \leq b} |f(x)| \leq \frac{1}{8} M(b - a)^2$;

(II) 证明:  $\max_{a \leq x \leq b} |f'(x)| \leq \frac{1}{2} M(b - a)$.

> [!note]- 原题截图（OCR 校对用）
> ![[数二880 高数 一元函数微分学及其应用 拓展 解答 02.webp]]

> [!success]- 答案与解析
> **答案：**
>
> （I）$\displaystyle\max_{[a,b]}|f(x)|\le\frac18M(b-a)^2$；（II）$\displaystyle\max_{[a,b]}|f'(x)|\le\frac12M(b-a)$。
>
> **解析：** 在 $|f|$ 或 $|f'|$ 取得最大值的点分别使用带二阶余项的 Taylor 公式，再利用到较近端点的距离不超过区间长度的一半。

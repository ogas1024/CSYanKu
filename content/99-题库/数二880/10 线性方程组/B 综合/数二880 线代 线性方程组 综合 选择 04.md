## 题干

【4】设向量组  $\boldsymbol{\alpha}_1 = (1,1,a)^\top, \boldsymbol{\alpha}_2 = (1,-2,b)^\top, \boldsymbol{\alpha}_3 = (-2,1,c)^\top$ 的秩为  $a$，若  $\boldsymbol{\beta} = (1,2,0)^\top$ 可由  $\alpha_1, \alpha_2, \alpha_3$，线性表示，且表示法不唯一，则（ ）。

A.  $a = 2, b = 8, c = -10$

B.  $a = 2, b = 8, c = 10$

C.  $a = 1, b = -8, c = 10$

D.  $a = 1, b = -8, c = -10$

> [!note]- 原题截图（OCR 校对用）
> ![[数二880 线代 线性方程组 综合 选择 04.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 由 $AX=\beta$ 有无穷多解且表示不唯一得 $r(A)=2=a$；对 $(A,\beta)$ 消元得 $b+c+2=0,\ \tfrac13 b-\tfrac83=0$，解得 $b=8,c=-10$，故选 A。

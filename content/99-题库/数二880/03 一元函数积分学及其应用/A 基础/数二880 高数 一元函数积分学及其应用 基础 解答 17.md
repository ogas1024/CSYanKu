## 题干

【17】设曲线  $y = \sin x \left(0 \leq x \leq \frac{\pi}{2}\right)$，直线  $y = k(0 \leq k \leq 1)$ 与 x = 0 所围面积为  $S_{1}$， $y = \sin x \left(0 \leq x \leq \frac{\pi}{2}\right)$， $y = k$ 与  $x = \frac{\pi}{2}$ 所围面积为  $S_{2}$，求  $S = S_{1} + S_{2}$ 的最小值.

> [!note]- 原题截图（OCR 校对用）
> ![[数二880 高数 一元函数积分学及其应用 基础 解答 17.png]]

> [!success]- 答案与解析
> **答案：**
>
> 阴影面积的最小值为 $\sqrt2-1$。
>
> **解析：** 以唯一交点参数化两块面积，求和后求驻点并比较端点。

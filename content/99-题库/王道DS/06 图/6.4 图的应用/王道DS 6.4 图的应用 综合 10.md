## 题干

10. 【2014 统考真题】某网络中的路由器运行 OSPF 路由协议，下表是路由器 R1 维护的主要链路状态信息（LSI），R1 构造的网络拓扑图（见下图）是根据题下表及 R1 的接口名构造出来的网络拓扑。

| 信息项 | 字段 | R1 的 LSI | R2 的 LSI | R3 的 LSI | R4 的 LSI | 备注 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---|
| Router ID |  | 10.1.1.1 | 10.1.1.2 | 10.1.1.5 | 10.1.1.6 | 标识路由器的 IP 地址 |
| Link1 | ID | 10.1.1.2 | 10.1.1.1 | 10.1.1.6 | 10.1.1.5 | 所连路由器的 Router ID |
| Link1 | IP | 10.1.1.1 | 10.1.1.2 | 10.1.1.5 | 10.1.1.6 | Link1 的本地 IP 地址 |
| Link1 | Metric | 3 | 3 | 6 | 6 | Link1 的费用 |
| Link2 | ID | 10.1.1.5 | 10.1.1.6 | 10.1.1.1 | 10.1.1.2 | 所连路由器的 Router ID |
| Link2 | IP | 10.1.1.9 | 10.1.1.13 | 10.1.1.10 | 10.1.1.14 | Link2 的本地 IP 地址 |
| Link2 | Metric | 2 | 4 | 2 | 4 | Link2 的费用 |
| Net1 | Prefix | 192.1.1.0/24 | 192.1.6.0/24 | 192.1.5.0/24 | 192.1.7.0/24 | 直连网络 Net1 的网络前缀 |
| Net1 | Metric | 1 | 1 | 1 | 1 | 到达直连网络 Net1 的费用 |

![[王道DS 6.4 图的应用 综合 10-fig1.webp]]

请回答下列问题：

- **（1）** 本题中的网络可抽象为数据结构中的哪种逻辑结构？
- **（2）** 针对表中的内容，设计合理的链式存储结构，以保存表中的链路状态信息（LSI）。

要求给出链式存储结构的数据类型定义，并画出对应表的链式存储结构示意图（示意图中可仅以 ID 标识结点）。
- **（3）** 按照 Dijkstra 算法的策略，依次给出 R1 到达子网 192.1.x.x 的最短路径及费用。

> [!note]- 原题截图
> ![[王道DS 6.4 图的应用 综合 10.webp]]

> [!success]- 答案与解析
> **答案：**
>
> **（1）逻辑结构**
>
> 该网络可抽象为一个无向带权图。
>
> **（2）链式存储结构**
>
> 以路由器为表头结点；每个表头的边链中同时保存相邻路由器链路和直连网络。用标志位区分两类弧结点：
>
> ```c
> typedef struct {
>     unsigned int ID, IP;
> } LinkNode;
>
> typedef struct {
>     unsigned int Prefix, Mask;
> } NetNode;
>
> typedef struct ArcNode {
>     int flag;                 // 1: Link，2: Net
>     union {
>         LinkNode link;
>         NetNode net;
>     } info;
>     unsigned int metric;
>     struct ArcNode *next;
> } ArcNode;
>
> typedef struct HNode {
>     unsigned int routerID;
>     ArcNode *first;
>     struct HNode *next;
> } HNode;
> ```
>
> 四个表头依次为 R1(10.1.1.1)、R2(10.1.1.2)、R3(10.1.1.5)、R4(10.1.1.6)，各自边链按题表链接两条 Link 和一条 Net 记录。
>
> **（3）R1 的最短路径**
>
> | 目的网络 | 路径 | 费用 |
> |---|---|---:|
> | 192.1.1.0/24 | 直接到达 | 1 |
> | 192.1.5.0/24 | R1→R3→网络 | 3 |
> | 192.1.6.0/24 | R1→R2→网络 | 4 |
> | 192.1.7.0/24 | R1→R2→R4→网络 | 8 |
>
> **解析：** 链路状态数据库本质是邻接表：路由器是顶点，路由器间链路及直连网络是带费用的邻接记录。Dijkstra 从 R1 出发，先确定直连网络与 R3，再确定 R2，最后经 R2 到 R4 的直连网络；表中费用均包含到目标直连网络的最后一段费用 1。

## 题干

15. 【2015 统考真题】已知程序如下：

```cpp
int S(int n)
{
    return (n <= 0) ? 0 : S(n - 1) + n;
}

void main()
{
    cout << S(1);
}
```

程序运行时使用栈来保存调用过程的信息，自栈底到栈顶保存的信息依次对应的是（ ）。

A. `main()` $\to$ `S(1)` $\to$ `S(0)`

B. `S(0)` $\to$ `S(1)` $\to$ `main()`

C. `main()` $\to$ `S(0)` $\to$ `S(1)`

D. `S(1)` $\to$ `S(0)` $\to$ `main()`

> [!note]- 原题截图
> ![[王道DS-3.3选-015.png]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 调用链依次为 `main()` 调用 `S(1)`，`S(1)` 调用 `S(0)`。活动记录按先调用者在栈底、后调用者在栈顶排列。

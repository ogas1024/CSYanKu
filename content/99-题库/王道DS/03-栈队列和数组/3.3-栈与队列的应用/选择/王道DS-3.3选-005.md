## 题干

5. 执行下列语句段后，`i` 的值为（ ）。

```cpp
int f(int x)
{
    return (x > 0) ? x * f(x - 1) : 2;
}

int i;
i = f(f(1));
```

A. 2

B. 4

C. 8

D. 无限递归

> [!note]- 原题截图
> ![[王道DS-3.3选-005.png]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** `f(1)=1*f(0)=2`，因而外层为 `f(2)=2*f(1)=4`，最终 `i=4`。

## 题干

3. 【2021 统考真题】已知某排序算法如下：

```c
void cmpCountSort(int a[], int b[], int n) {
    int i, j, *count;
    count = (int *)malloc(sizeof(int) * n);
                         // C++语言：count=new int[n];
    for (i=0; i<n; i++)
        count[i]=0;
    for (i=0; i<n-1; i++)
        for (j=i+1; j<n; j++)
            if (a[i]<a[j])
                count[j]++;
            else
                count[i]++;
    for (i=0; i<n; i++)
        b[count[i]]=a[i];
    free(count);         // C++语言：delete[] count;
}
```

请回答下列问题。

（1） 若有 `int a[]={25,-10,25,10,11,19}, b[6];`，则调用 `cmpCountSort(a,b,6)` 后数组 `b` 中的内容是什么？
（2） 若 $a$ 中含有 $n$ 个元素，则算法执行过程中，元素之间的比较次数是多少？
（3） 该算法是稳定的吗？若是，阐述理由；

否则，修改为稳定排序算法。

> [!note]- 原题截图
> ![[王道DS 8.5 归并排序和基数排序 综合 03.png]]

> [!success]- 答案与解析
> **答案：**
>
> **（1）数组 b 的内容**
>
> 调用后：
>
> ```text
> b = {-10, 10, 11, 19, 25, 25}
> ```
>
> `count[i]` 记录比 `a[i]` 小的元素个数，因此它就是该元素在升序结果中的下标。
>
> **（2）比较次数**
>
> 双重循环让每一对元素恰好比较一次，比较次数为
>
> $$1+2+...+(n-1)=n(n-1)/2.$$
>
> **（3）稳定性与修改**
>
> 原算法**不稳定**。当 `a[i]==a[j]` 且 `i<j` 时，原来的 `else` 会增加 `count[i]`，使原序列中靠前的相等元素排到靠后位置。
>
> 把判断修改为：
>
> ```c
> if (a[i] <= a[j])
>     count[j]++;
> else
>     count[i]++;
> ```
>
> 相等时增加后一个元素 `a[j]` 的计数，使它仍排在 `a[i]` 之后，即可保持稳定。
>
> **解析：** 该算法是比较计数排序：两两比较后，由每个元素的排名直接确定输出位置。加入等号后，相等元素按原下标先后获得递增的排名，从而避免相对次序颠倒。时间复杂度为 $O(n^2)$，额外空间为 $O(n)$。

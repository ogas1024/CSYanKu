## 题干

1. 已知线性表按顺序存储，且每个元素都是不相同的整数型元素，设计把所有奇数移动到所有偶数前边的算法（要求时间最短，辅助空间最少）。

> [!note]- 原题截图
> ![[王道DS 8.3 交换排序 综合 01.webp]]

> [!success]- 答案与解析
> **答案：**
>
> 采用类似快速排序划分的双指针方法。左指针从前向后寻找偶数，右指针从后向前寻找奇数，找到后交换；直到两指针相遇。
>
> ```cpp
> void moveOddBeforeEven(int A[], int n) {
>     int i = 0, j = n - 1;
>     while (i < j) {
>         while (i < j && A[i] % 2 != 0) ++i;  // 左侧已有奇数
>         while (i < j && A[j] % 2 == 0) --j;  // 右侧已有偶数
>         if (i < j) {
>             int t = A[i]; A[i] = A[j]; A[j] = t;
>             ++i; --j;
>         }
>     }
> }
> ```
>
> 时间复杂度为 **$O(n)$**，辅助空间复杂度为 **$O(1)$**。
>
> **解析：** 每个元素至多被一个指针扫描一次，交换后奇数进入左半区、偶数进入右半区。题目只要求两类元素分区，并不要求各分区内部有序，因此无需完整排序。

## 题干

2. 设顺序表用数组 `A[]` 表示，表中元素存储在数组下标 $1\sim m+n$ 的范围内，前 $m$ 个元素递增有序，后 $n$ 个元素递增有序，设计一个算法，使得整个顺序表有序。

- **（1）** 给出算法的基本设计思想。
- **（2）** 根据设计思想，采用 C/C++ 描述算法，关键之处给出注释。
- **（3）** 说明你所设计算法的时间复杂度与空间复杂度。

> [!note]- 原题截图
> ![[王道DS 8.6 各种内部排序算法的比较及应用 综合 02.webp]]

> [!success]- 答案与解析
> **答案：**
>
> 把前 m 个元素视为已有序区，依次将后 n 个元素插入其中：
>
> ```c
> void Insert_Sort(ElemType A[], int m, int n) {
>     int i, j;
>     for (i = m + 1; i <= m + n; i++) {
>         A[0] = A[i];              // 哨兵，暂存待插入元素
>         for (j = i - 1; A[j] > A[0]; j--)
>             A[j + 1] = A[j];
>         A[j + 1] = A[0];
>     }
> }
> ```
>
> 这里采用原书的 1-based 下标，`A[0]` 为哨兵。最坏情况下，后 n 个元素都要越过前面的有序元素，时间复杂度为 $O(mn)$；只使用常数个辅助变量，空间复杂度为 $O(1)$。
>
> **解析：** 两个分段各自已有序。若要求原地完成，可把第二段元素逐个插入不断扩大的前缀有序区，这正是原书的主解。若允许额外开辟 $O(m+n)$ 空间，也可像归并排序那样合并两段，将时间降为 $O(m+n)$。

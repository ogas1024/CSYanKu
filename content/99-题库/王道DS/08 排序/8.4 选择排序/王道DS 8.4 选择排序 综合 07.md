## 题干

7. 优先队列（Priority Queue）是一种数据结构，它类似于普通队列，但每个元素都有一个优先级。

元素在入队时会根据其优先级来排序，而不按照先入先出的顺序来排序。

每次从优先队列中出队时，出队的是优先级最高的元素，而不是最早进入队列的元素。

队列中的元素的数据结构的定义如下：

```c
typedef struct {
    int value;    // 元素的值
    int priority; // 元素的优先级，priority 越大，优先级越高
} PriorityQueueElement;
```

请设计一个优先队列，要求满足：①初始时队列为空；

②入队时，不允许增加队列的占用空间；

③出队后，出队元素所占用的空间可重复使用，即整个队列所占用的空间不变；

④入队操作和出队操作的时间复杂度始终保持为 $O(\log_2 n)$。

请回答：

- **（1）** 该队列是应选择链式存储结构，还是选择顺序存储结构？
- **（2）** 给出优先队列的数据结构的定义。
- **（3）** 用伪代码给出入队操作和出队操作的基本过程（关键之处可用文字描述）。

> [!note]- 原题截图
> ![[王道DS 8.4 选择排序 综合 07.png]]

> [!success]- 答案与解析
> **答案：**
>
> **（1）存储结构**
>
> 采用**顺序存储结构**，即使用固定容量数组实现大根堆。这样整个队列占用空间不变，删除后的数组位置可由后续入队复用，入队和出队均为 $O(log_2 n)$。
>
> **（2）数据结构**
>
> ```cpp
> const int MAX_SIZE = 1000;
>
> struct PriorityQueue {
>     PriorityQueueElement heap[MAX_SIZE];
>     int size;
> };
> ```
>
> 堆按 `priority` 比较，根结点保存优先级最高的元素。
>
> **（3）基本操作**
>
> 入队：
>
> 1. 若 `size==MAX_SIZE`，队列已满。
> 2. 把新元素放在 `heap[size]`，`size++`。
> 3. 将新元素与父结点比较；若优先级更高就交换，反复向上调整到根或满足堆序。
>
> 出队：
>
> 1. 若 `size==0`，队列为空。
> 2. 保存堆顶元素作为返回值。
> 3. 把最后一个元素移到堆顶并令 `size--`。
> 4. 将新堆顶与两个孩子中优先级较高者比较；必要时交换并反复向下调整。
> 5. 返回原堆顶元素。
>
> **解析：** 固定数组同时满足不扩容和空间复用要求。大根堆使最高优先级元素始终位于根；插入上调和删除下调最多经过树高数量级的结点，所以两个操作始终为 $O(log_2 n)$，占用总空间为固定的 $O(MAX_SIZE)$。

## 题干

12. 在线性表 $a_0,a_1,\cdots,a_{100}$ 中，删除元素 $a_{50}$ 需要移动（ ）个元素。

A. 0

B. 50

C. 51

D. 0 或 50

> [!note]- 原题截图
> ![[王道DS-2.3选-012.png]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 题目没有指定存储方式。若为链式存储，删除结点只需改指针，移动 0 个元素；若为顺序存储，需将 $a_{51}$ 至 $a_{100}$ 共 50 个元素前移。因此为 0 或 50。

## 题干

【答案 P11】1. 分析以下各程序段，求出算法的时间复杂度。

- **①**

  ```cpp
  i = 1;
  k = 0;
  while (i < n - 1) {
      k = k + 10 * i;
      i++;
  }
  ```

- **②**

  ```cpp
  y = 0;
  while ((y + 1) * (y + 1) <= n)
      y = y + 1;
  ```

- **③**

  ```cpp
  for (i = 0; i < n; i++)
      for (j = 0; j < m; j++)
          a[i][j] = 0;
  ```

> [!note]- 原题截图
> ![[王道DS-1.2综-001.png]]

> [!success]- 答案与解析
> **答案：**
>
> ① 基本语句 `k = k + 10 * i` 共执行 $n-2$ 次，因此 $T(n)=O(n)$。
>
> ② 循环结束时有 $(y+1)^2>n$，循环次数与 $\sqrt n$ 同阶，因此 $T(n)=O(\sqrt n)$。
>
> ③ 内层循环执行 $m$ 次，外层循环执行 $n$ 次，共执行 $nm$ 次，因此 $T(n,m)=O(nm)$。
>
> **解析：** 分别以各程序段中基本语句的执行次数为依据：第一段是关于 $n$ 的一次函数，第二段由平方边界得到 $\sqrt n$ 量级，第三段是两重独立循环次数的乘积。

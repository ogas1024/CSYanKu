## 题干

15. 【2025 统考真题】有两个长度均为 $n$ 的一维整型数组 $A$ 和 $res$，对数组 $A$ 中的每个元素 $A[i]$，计算 $A[i]$ 与 $A[j]\ (0\leq i\leq j\leq n-1)$ 乘积的最大值，并将其保存到 $res[i]$ 中。

例如，当 $A[]=\{1,4,-9,6\}$ 时，得到 $res[]=\{6,24,81,36\}$。

现给定数组 $A$，设计一个时间和空间上尽可能高效的算法 `calMulMax`，求 $res$ 中各元素的值。

函数原型为 `void calMulMax(int A[], int res[], int n)`。

要求如下：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

（3）说明你所设计算法的时间复杂度和空间复杂度。

> [!note]- 原题截图
> ![[王道DS 2.2 线性表的顺序表示 综合 15.png]]

> [!success]- 答案与解析
> **答案：**
>
> 从右向左扫描 $A$，维护当前后缀 $A[i..n-1]$ 的最大值 `Max` 和最小值 `Min`。先用 `A[i]` 更新二者；若 `A[i]>=0`，则 `res[i]=A[i]*Max`；否则 `res[i]=A[i]*Min`。
>
> ```cpp
> Max = Min = A[n-1];
> for (int i = n-1; i >= 0; --i) {
>     if (A[i] > Max) Max = A[i];
>     if (A[i] < Min) Min = A[i];
>     res[i] = A[i] >= 0 ? A[i] * Max : A[i] * Min;
> }
> ```
>
> 时间复杂度为 $O(n)$，除输出数组外空间复杂度为 $O(1)$。
>
> **解析：** 当 $A[i]$ 非负时，与后缀最大值相乘得到最大积；当 $A[i]$ 为负时，与后缀最小值相乘得到最大积。维护后缀极值即可避免逐对枚举。

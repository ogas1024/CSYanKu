## 题干

18. 【2012 统考真题】假定采用带头结点的单链表保存单词，当两个单词有相同的后缀时，可共享相同的后缀存储空间，例如，loading 和 being 的存储映像如下图所示。

![[王道DS 2.3 线性表的链式表示 综合 18-fig1.jpg]]

设 `str1` 和 `str2` 分别指向两个单词所在单链表的头结点，链表结点结构为

![[王道DS 2.3 线性表的链式表示 综合 18-fig2.jpg]]

请设计一个时间上尽可能高效的算法，找出由 `str1` 和 `str2` 所指向两个链表共同后缀的起始位置（如图中字符 `i` 所在结点的位置 $p$）。

要求：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。

（3）说明你所设计算法的时间复杂度。

> [!note]- 原题截图
> ![[王道DS 2.3 线性表的链式表示 综合 18.png]]

> [!success]- 答案与解析
> **答案：**
>
> 分别求出 `str1`、`str2` 所指链表的长度 $m$、$n$。长链表的工作指针先后移 $|m-n|$ 个结点，使两指针到各自表尾的剩余距离相等。然后两指针同步后移，第一个指向同一结点的位置，就是共同后缀的起始地址；若直到表尾仍未相同，则不存在共同后缀。
>
> 时间复杂度为 $O(m+n)$，空间复杂度为 $O(1)$。
>
> **解析：** 两个单链表一旦共享某个结点，此后的 `next` 链必然完全重合。因而先按长度对齐表尾，再比较结点地址，遇到的第一个共享结点就是答案，不能只比较字符值。

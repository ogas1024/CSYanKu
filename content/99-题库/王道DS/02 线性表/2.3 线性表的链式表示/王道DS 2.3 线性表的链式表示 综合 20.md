## 题干

20. 【2019 统考真题】设线性表 $L=(a_1,a_2,a_3,\cdots,a_{n-2},a_{n-1},a_n)$ 采用带头结点的单链表保存，链表中的结点定义如下：

```cpp
typedef struct node
{
    int data;
    struct node *next;
} NODE;
```

请设计一个空间复杂度为 $O(1)$ 且时间上尽可能高效的算法，重新排列 $L$ 中的各结点，得到线性表 $L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\cdots)$。

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

（3）说明你所设计的算法的时间复杂度。

> [!note]- 原题截图
> ![[王道DS 2.3 线性表的链式表示 综合 20.webp]]

> [!success]- 答案与解析
> **答案：**
>
> 先用快慢指针找到链表的中间结点 `p`：`p` 每次走一步，`q` 每次走两步。令 `q=p->next`、`p->next=NULL`，将链表分为前后两段；再将后半段原地逆置。最后令 `s` 从前半段首元结点开始，依次取逆置后的后半段结点，把它们逐个插到前半段相应结点之后，得到 $L'=(a_1,a_n,a_2,a_{n-1},\cdots)$。
>
> 时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。
>
> **解析：** 原地逆置后半段后，其顺序变为 $a_n,a_{n-1},\cdots$；再与前半段的 $a_1,a_2,\cdots$ 交替归并，正好形成题目所需次序。分割、逆置和交替归并各扫描常数遍，且只改变链域。

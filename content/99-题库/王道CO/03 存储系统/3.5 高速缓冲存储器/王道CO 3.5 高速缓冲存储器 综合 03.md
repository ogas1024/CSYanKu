## 题干

某计算机有容量为 $256\,\mathrm{B}$ 的数据 Cache，主存块大小为 $32\,\mathrm{B}$。

现有如下 C 语言程序段：

```c
int i, j, c, s, a[128];
/* ... */
for (i = 0; i < 10000; i++)
    for (j = 0; j < 128; j = j + s)
        c = a[j];
```

int 型数据用 32 位补码表示，编译器将变量 `i`、`j`、`c`、`s` 都分配在通用寄存器中，因此只需考虑数组元素的访存情况。

假定数组起始地址正好在一个主存块的开始。

请回答：

- **（1）** 若 Cache 采用直接映射，则当 $s=64$ 和 $s=63$ 时，缺失率分别为多少？
- **（2）** 若 Cache 采用 2 路组相联映射方式，则当 $s=64$ 和 $s=63$ 时，缺失率分别为多少？

> [!note]- 原题截图
> ![[王道CO 3.5 高速缓冲存储器 综合 03.png]]

> [!success]- 答案与解析
> **答案：**
>
> **（1）直接映射**
>
> - $s=64$ 时，缺失率为 **100%**。
> - $s=63$ 时，缺失率约为 **67%**。
>
> **（2）2 路组相联**
>
> - $s=64$ 时，总缺失 2 次，缺失率近似为 **0**。
> - $s=63$ 时，总缺失 3 次，缺失率近似为 **0**。
>
> **解析：** 32B 主存块可容纳 8 个 int，256B Cache 共 8 行。直接映射时，$s=64$ 的两个主存块相差 8 块，持续映射到同一 Cache 行并相互替换；$s=63$ 时，a[63] 与 a[126] 冲突，a[0] 不冲突，因而约有 $2/3$ 访问缺失。2 路组相联时，冲突的两块可同时留在同组的两行中，除初次强制缺失外均命中。

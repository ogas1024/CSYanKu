## 题干

【2020 统考真题】假定主存地址为 32 位，按字节编址，指令 Cache 和数据 Cache 与主存之间均采用 8 路组相联映射方式、直写法（Write Through）和 LRU 算法，主存块大小为 $64\,\mathrm{B}$，数据区容量各为 $32\,\mathrm{KB}$。

开始时 Cache 均为空。

请回答下列问题：

- **（1）** Cache 每一行中标记（Tag）、LRU 位各占几位？是否有修改位？
- **（2）** 有如下 C 语言程序段：

  ```c
  for (k = 0; k < 1024; k++)
      s[k] = 2 * s[k];
  ```

  若数组 `s` 及其变量 `k` 均为 int 型，int 型数据占 4B，变量 `k` 分配在寄存器中，数组 `s` 在主存中的起始地址为 `0080 00C0H`，则在该程序段执行过程中，访问数组 `s` 的数据 Cache 缺失次数为多少？
- **（3）** 若 CPU 最先开始的访问操作是读取主存单元 `0001 0003H` 中的指令，简要说明从 Cache 中访问该指令的过程，包括 Cache 缺失处理过程。

> [!note]- 原题截图
> ![[王道CO-3.5综-006.png]]

> [!success]- 答案与解析
> **答案：**
>
> **（1）标记位、LRU 位和修改位**
>
> 每行的 Tag 占 **20 位**，LRU 位占 **3 位**；采用直写法，因此 **没有修改位**。
>
> **（2）数据 Cache 缺失次数**
>
> 数组起始地址正好位于主存块起始处，1024 个 int 共占
>
> $$1024*4B/64B=64$$
>
> 个主存块。每块第一次读时缺失，随后该块中各元素的读、写均命中，因此共缺失 **64 次**。
>
> **（3）首次读指令的 Cache 访问过程**
>
> 地址 `0001 0003H` 的组索为 0，所在主存块映射到指令 Cache 的第 0 组。Cache 初始为空，该组所有行的有效位均为 0，因此访问缺失。
>
> 缺失处理时，从主存读出包含该地址的整个 64B 主存块，存入指令 Cache 第 0 组的任一空行；把主存地址高 20 位（`00010H`）写入标记字段，置有效位并修改 LRU 位。最后按块内地址 `000011B` 取出相应指令。
>
> **解析：** 64B 块使块内地址占 6 位；$32KB/(64B*8)=64$ 组，组号占 6 位，因而 Tag 占 $32-6-6=20$ 位。8 路组相联按原书记法每行用 3 位 LRU 信息。直写法每次写命中都同步更新主存，不需脏位。

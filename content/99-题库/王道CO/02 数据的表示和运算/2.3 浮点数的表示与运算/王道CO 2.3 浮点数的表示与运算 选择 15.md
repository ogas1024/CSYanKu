## 题干

15. 【P68】在 IEEE 754 标准浮点格式中,非规格化浮点数表示为（）

A. 阶码为 0, 尾数为任意非 0 的二进制数

B. 阶码为 255, 尾数全为 0

C. 阶码为 255, 尾数为任意非 0 的二进制数

D. 阶码为 0, 尾数全为 0

> [!note]- 原题截图
> ![[王道CO 2.3 浮点数的表示与运算 选择 15.png]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** IEEE 754 中阶码全 0、尾数非 0 表示非规格化数；阶码和尾数均为 0 才是零。

## 题干

【2011 统考真题】假定在一个 8 位字长的计算机中运行如下 C 程序段：

```c
unsigned int x = 134;
unsigned int y = 246;
int m = x;
int n = y;
unsigned int z1 = x - y;
unsigned int z2 = x + y;
int k1 = m - n;
int k2 = m + n;
```

若编译器编译时将 8 个 8 位寄存器 R1～R8 分别分配给变量 `x`、`y`、`m`、`n`、`z1`、`z2`、`k1` 和 `k2`，请回答下列问题（提示：有符号整数用补码表示）：

- **（1）** 执行上述程序段后，寄存器 R1、R5 和 R6 的内容分别是什么（用十六进制表示）？
- **（2）** 执行上述程序段后，变量 `m` 和 `k1` 的值分别是多少（用十进制表示）？
- **3. ** 上述程序段涉及有符号整数加减、无符号整数加减运算，这四种运算能否利用同一个加法器辅助电路实现？简述理由。
- **（4）** 计算机内部如何判断有符号整数加减运算的结果是否发生溢出？上述程序段中，哪些有符号整数运算语句的执行结果会发生溢出？

> [!note]- 原题截图
> ![[王道CO 2.2 运算方法和运算电路 综合 03.webp]]

> [!success]- 答案与解析
> **答案：**
>
> **（1）寄存器内容**
>
> - R1（`x`）=`86H`。
> - R5（`z1=x-y`）=`90H`。
> - R6（`z2=x+y`）=`7CH`。
>
> **（2）变量值**
>
> `m` 的位型为 `86H`，按 8 位补码解释为 $134-256=-122$。`n` 的位型为 `F6H`，即 -10，所以 `k1=m-n=-122-(-10)=-112`，位型为 `90H`。
>
> **（3）能否共用加法器**
>
> 能。无论操作数被解释为有符号数还是无符号数，定长加减法都进行模 $2^8$ 的位运算，减法又可转为加上减数的补码，因而可使用同一个加法器及其辅助电路。
>
> **（4）溢出判断及本题结果**
>
> 有符号加法可根据“同号相加得异号结果”判断溢出；减法可转为加法后用同样的符号规则判断，也可用符号位进位输入与输出的异或作为 OF。
>
> 本程序的有符号运算中，`k1=m-n` 结果为 -112，不溢出；`k2=m+n` 的数学结果为 -132，低 8 位为 `7CH`，两个负数相加得正数位型，因而只有 `k2=m+n` 发生溢出。
>
> **解析：** 赋值给不同有符号性的同字长整数时，8 位位型保持不变，只是解释方式改变。因此 x 的 134 对应 `86H`，赋给 m 后解释为 -122；y 的 246 对应 `F6H`，赋给 n 后解释为 -10。硬件加法器不区分有符号性，区别体现在结果的解释与标志位判断。

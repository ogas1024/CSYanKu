## 题干

【答案 P188】1. 【2017 统考真题】在按字节编址的计算机 M 上，f1 的部分源程序（阴影部分）如下。

将 f1 中的 `int` 都改成 `float`，可得到计算 $f(n)$ 的另一个函数 f2。

```c
int f1(unsigned n) {
    int sum = 1, power = 1;
    for (unsigned i = 0; i <= n - 1; i++) {
        power *= 2;
        sum += power;
    }
    return sum;
}
```

对应的机器级代码（包括指令的虚拟地址）如下：

```text
 1  00401020  55        push ebp
... ...       ...       ...
20  0040105E  39 4D F4  cmp dword ptr [ebp-0Ch], ecx
... ...       ...       ...
23  00401066  D1 E2     shl edx, 1
... ...       ...       ...
35  0040107F  C3        ret
```

其中，机器级代码行包括行号、虚拟地址、机器指令和汇编指令。

- **（1）** 计算机 M 是 RISC 还是 CISC？为什么？
- **（2）** f1 的机器指令代码共占多少字节？要求给出计算过程。
- **（3）** 第 20 条指令 `cmp` 通过 `i` 减 `n-1` 实现对 `i` 和 `n-1` 的比较。

执行 `f1(0)` 的过程中，当 `i=0` 时，`cmp` 指令执行后，进位/借位标志 CF 的内容是什么？要求给出计算过程。
- **（4）** 第 23 条指令 `shl` 通过左移操作实现了 `power*2` 运算，在 f2 中能否用 `shl` 指令实现 `power*2`？为什么？

> [!note]- 原题截图
> ![[王道CO 4.3 程序的机器级代码表示 综合 01.webp]]

> [!success]- 答案与解析
> **答案：**
>
> **（1）** M 是 **CISC**。其指令长度不等，不符合 RISC 通常采用定长指令的特征。
>
> **（2）** 第一条指令地址为 00401020H，最后一条 ret 的地址为 0040107FH，且 ret 占 1 字节，所以机器代码长度为
>
> $$0040107FH-00401020H+1=60H=96B.$$
>
> **（3）** 执行 f1(0) 时，n-1 的 32 位机器数为 FFFFFFFFH。i=0 时，cmp 执行 0-FFFFFFFFH，即补码加法 00000000H+00000000H+1=00000001H。进位输出为 0，减法控制位为 1，故
>
> $$CF=C_{out}\oplus Sub=0\oplus1=1.$$
>
> **（4）** f2 中不能用 shl 实现 float 型 power×2。整数左移可整体移动有效数位来乘 2；浮点机器数还包含阶码，直接把整个编码左移不能实现浮点乘 2，而且浮点运算比整数运算复杂、耗时更长。
>
> **解析：** 机器码地址跨度直接给出函数代码长度。cmp 使用补码减法并按题中 ALU 的 CF 定义计算。shl 操作的是整数位串，而浮点数由符号、阶码和尾数组成，不能把整体编码左移当作数值乘 2。

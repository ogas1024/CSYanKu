## 题干

30. 进程  $P_{1}$ 和  $P_{2}$ 均包含并发执行的线程，部分伪代码描述如下所示。

```c
//进程 P1
int x=0;
Thread1()
{
    int a;
    a=1;
    x+=1;
}
Thread2()
{
    int a;
    a=2;
    x+=2;
}

//进程 P2
int x=0;
Thread3()
{
    int a;
    a=x;
    x+=3;
}
Thread4()
{
    int b;
    b=x;
    x+=4;
}
```

下列选项中，需要互斥执行的操作是( )。

A. `a=1` 与 `a=2`

B. `a=x` 与 `b=x`

C. `x+=1` 与 `x+=2`

D. `x+=1` 与 `x+=3`

> [!note]- 原题截图
> ![[408真题 2016 T30.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 只有同一进程内不同线程对共享变量的冲突写需要互斥；选项 C 符合，其他为局部、只读或跨进程。

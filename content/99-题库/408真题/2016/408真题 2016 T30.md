## 题干

30. 进程  $P_{1}$ 和  $P_{2}$ 均包含并发执行的线程，部分伪代码描述如下所示。

```c
//进程 P1
int x=0;
Thread1()
{
    int a;
    a=1;
    x+=1;
}
Thread2()
{
    int a;
    a=2;
    x+=2;
}

//进程 P2
int x=0;
Thread3()
{
    int a;
    a=x;
    x+=3;
}
Thread4()
{
    int b;
    b=x;
    x+=4;
}
```

下列选项中，需要互斥执行的操作是( )。

A. `a=1` 与 `a=2`

B. `a=x` 与 `b=x`

C. `x+=1` 与 `x+=2`

D. `x+=1` 与 `x+=3`

> [!note]- 原题截图
> ![[408真题 2016 T30.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 对于进程  $P_1$ 而言，变量 x 是全局变量，属于临界资源。进程  $P_1$ 包含 2 个并发执行的线程 Thread1 和 Thread2，变量 a 分别是线程 Thread1 和 Thread2 的局部变量，属于各自线程的私有资源。
>
> 同理，对于进程  $P_2$ 而言，变量 x 是全局变量，属于临界资源。进程  $P_2$ 包含 2 个并发执行的线程 Thread3 和 Thread4，变量 a 是线程 Thread3 的局部变量，变量 b 是线程 Thread4 的局部变量。
>
> ① A（a = 1 与 a = 2）错误 ×：两个 a 分别是线程 Thread1、Thread2 的局部变量，是线程的私有资源，互不共享，无需互斥。
>
> ② B（a = x 与 b = x）错误 x：这两个操作都是读进程  $P_{2}$ 的全局变量 x，读操作不会产生冲突，无需互斥。
>
> ③ C（x += 1 与 x += 2）正确 ✓：线程 Thread1 的 “x += 1” 与 Thread2 的 “x += 2” 操作同一进程  $P_1$ 内的共享变量 x，都是修改操作，并发执行会导致结果不确定，需要互斥。
>
> ④D（x+=1与x+=3）错误×：“x+=1”属于进程 $P_{1}$中的操作、“x+=3”属于进程 $P_{2}$中的操作，不同进程的地址空间相互隔离，两个x位于各自独立的地址空间，无需互斥。故选C。
>
> 【点评】难题。综合考查线程与进程的资源模型：同一进程内线程共享全局变量/堆（需互斥）、线程各自私有的局部变量相互独立、不同进程地址空间相互隔离等。题目要求考生分析具体的代码实例，而不是考纯概念，进一步增加了题目的难度和灵活性，考查灵活应用。

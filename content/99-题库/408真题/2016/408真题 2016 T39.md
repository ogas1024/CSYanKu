## 题干

39. 若 H1 与 H2 的默认网关和子网掩码均分别配置为 192.168.3.1 和 255.255.255.128, H3 和 H4 的默认网关和子网掩码均分别配置为 192.168.3.254 和 255.255.255.128，则下列现象中可能发生的是（）。

A. H1 不能与 H2 进行正常 IP 通信

B. H2 与 H4 均不能访问 Internet

C. H1 不能与 H3 进行正常 IP 通信

D. H3 不能与 H4 进行正常 IP 通信

> [!note]- 原题截图
> ![[408真题 2016 T39.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** ①A和D均错误×：根据默认网络和子网掩码配置，H1与H2网络地址相同，同属一个网段，可以进行正常IP通信；H3与H4同属一个网段，可以进行正常IP通信。
>
> ②B 错误×：H4 默认网关地址 192.168.3.254 恰好为路由器 R2 的 E1 接口地址，且 R2 是 NAT 路由器，可以将私有 IP 转化为公网 IP，所以 H4 能正常访问 Internet。H2 的默认网关为 192.168.3.1，该地址在题目给出的图中没有标出，无法判断 H2 能否访问 Internet。
>
> ③ C 可能正确（本题选 C）：
>
> ◇ H3 → H1 的通信：H3 所属的子网为 192.168.3.128/25，H1 所属的子网为 192.168.3.0/25。由于 H1 与 H3 同属两个不同网络，双方通信需要借助路由器转发。H3 的默认网关地址 192.168.3.254 恰好为路由器 R2 的 E1 接口地址，故 H3 能通过 R2 将 IP 分组转发给 H1。
>
> ◇ H1 → H3 的通信：H1 的默认网关为 192.168.3.1 在题目给出的图中没有标出，无法判断 H1 的默认网关和 R2 是否连通，所以无法判断 H1 能否和 H3 进行正常通信（若 H1 的默认网关为 192.168.3.1 和 R2 连通，则 H1 有可能和 H3 正常通信）。
>
> ▷【提示】判断两台主机能否 **直接**通信，看的是“网络地址是否相同”（IP与掩码做与运算），与是否为私有地址无关。网络地址不同，则必须路由器转发。
>
> 【点评】难题。从实际应用场景出发，综合考查子网划分、IP转发、默认网关等多个考点，考查灵活运用。

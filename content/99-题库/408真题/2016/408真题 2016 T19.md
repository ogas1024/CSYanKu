## 题干

19. 在无转发机制的五段基本流水线（取指、译码/读寄存器、运算、访存、写回寄存器）中，下列指令序列存在数据冒险的指令对是（）

```text
I1: add R1, R2, R3; (R2) + (R3) → R1
I2: add R5, R2, R4; (R2) + (R4) → R5
I3: add R4, R5, R3; (R5) + (R3) → R4
I4: add R5, R2, R6; (R2) + (R6) → R5
```

A. I1 和 I2

B. I2 和 I3

C. I2 和 I4

D. I3 和 I4

> [!note]- 原题截图
> ![[408真题 2016 T19.png]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** I2 写 R5 在时钟5，I3 却在时钟3读 R5，形成写后读数据冒险，故 B。

## 题干

38. 假设连接 R1、R2 和 R3 之间的点对点链路使用 201.1.3.x/30 地址，当 H3 访问 Web 服务器 S 时，R2 转发出去的封装 HTTP 请求报文的 IP 分组的源 IP 地址和目的 IP 地址分别是（）

A. 192.168.3.251、130.18.10.1

B. 192.168.3.251、201.1.3.9

C. 201.1.3.8、130.18.10.1

D. 201.1.3.10、130.18.10.1

> [!note]- 原题截图
> ![[408真题 2016 T38.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** ①H3（192.168.3.251）访问S（130.18.10.1），分组到达R2（NAT路由器）的接口E1，经NAT转换后从R2的L0接口发出：源地址192.168.3.251（私网地址）必须替换为R2的公网出口地址；目的地址始终是S的真实地址130.18.10.1。
>
> ② S 在 Internet 方向，须经 R1 到达，故 R2 从连接 R1 的 L0 接口转发。路由器 R1 至 R2 之间链路使用网络地址 201.1.3.x/30：
>
> ◇ 201.1.3.x/30的网络前缀长度为30，主机号仅占2位，可分配的主机地址只有 $2^{2}-2=2$个（主机号全为0和全为1的地址不分配），R1的一个接口已占用201.1.3.9，故仅剩一个可分配的主机地址201.1.3.10、分配给R2的L0接口。
>
> ③所以，R2 转发出去的 IP 分组：源 IP = 201.1.3.10，目的 IP = 130.18.10.1。故选 D。
>
> ▷【提示】① NAT 维护一张映射表，地址转换是双向的。出方向修改 IP 分组的源 IP，入方向改目的 IP：
>
> ▷出方向：内网主机发往外网的包，源IP是私有地址，路由器把源IP换成自己的公网IP。
>
> ▷ **入方向**：外网返回的响应包，目的IP是路由器公网IP，路由器查地址转换（映射）表，把目的IP换回对应内网主机的私有IP。
>
> ②主机号全为0的地址是子网地址，主机号全为1的地址是子网的广播地址，这2个地址均不分配给主机使用。
>
> 【点评】难题。综合考查 NAT 地址转换和子网 IPv4 地址分配。

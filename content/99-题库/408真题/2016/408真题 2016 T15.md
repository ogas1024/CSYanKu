## 题干

15. 有如下 C 语言程序段：

```c
for(k=0;k<1000;k++)
    a[k]=a[k]+32;
```

若数组 `a` 及变量 `k` 均为 `int` 型，`int` 型数据占 $4\mathrm{B}$，数据 Cache 采用直接映射方式，数据区大小为 $1\mathrm{KB}$、块大小为 $16\mathrm{B}$，该程序段执行前 Cache 为空，则该程序段执行过程中访问数组 `a` 的 Cache 缺失率约为（）

A. $1.25\%$

B. $2.5\%$

C. $12.5\%$

D. $25\%$

> [!note]- 原题截图
> ![[408真题 2016 T15.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** ①每次循环对 $a[k]$先读再写，共2次访存，故访存总次数 $=1000\times2=2000$次。
>
> ② Cache 块大小 16B = 4 个 int，数组顺序访问、空间局部性好：每个 Cache 块的第一次访问缺失，其后 3 个元素的读、写全部命中（读缺失装入块后，同元素的写必命中）。
>
> ③ 数组共占  $1000 \times 4B = 4000B = 250$ 个 Cache 块（ $4000 \div 16$），故缺失次数为 250 次。缺失率  $=250 \div 2000 = 12.5\%$。故选 C。
>
> 【点评】常规题。类似题是408中的高频考点。

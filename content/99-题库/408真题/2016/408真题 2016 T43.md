## 题干

43. 已知由  $n(n \geq 2)$ 个正整数构成的集合  $A = \{a_k | 0 \leq k < n\}$，将其划分为两个不相交的子集  $A_1$ 和  $A_2$，元素个数分别是  $n_1$ 和  $n_2$， $A_1$ 和 $A_2$ 中元素之和分别为  $S_1$ 和  $S_2$。

设计一个尽可能高效的划分算法，满足  $|n_1 - n_2|$ 最小且  $|S_1 - S_2|$ 最大。

要求：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

（3）说明你所设计算法的平均时间复杂度和空间复杂度。

> ![[408真题 2016 T43.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) 算法思想：先将集合 A 中的元素按照单调递增的顺序进行排序，再把集合 A 分成： $A_1$ 和  $A_2$ 两个集合，集合  $A_1$ 保存前  $[n/2]$ 个元素，集合  $A_2$ 保存后  $[n/2]$ 个元素。本题也可以采用类似快排的拆分思想，不需要对集合 A 进行排序，仅需要让一边的子集中的每个元素小于另一边的子集中的每个元素即可。首先将 A 从枢轴处分为两个子集，之后根据枢轴所处位置（用 i 进行表示）进行以下处理：
>
> ① 若  $i = \lfloor n/2 \rfloor$，则算法结束；
>
> ② 若  $i < \lfloor n/2 \rfloor$，则枢轴之前的所有元素划分给  $A_1$，继续划分 i 之后的元素；
>
> ③ 若  $i > \lfloor n/2 \rfloor$，则枢轴之后的所有元素划分给  $A_2$，继续划分 i 之前的元素。
>
> (2) C 语言代码实现如下：
>
> int setPartition(int a[], int n) { int pivotkey, // 划分基准值 left = 0, left0 = 0, // 左边界、左边界初值 right = n - 1, right0 = n - 1, // 右边界、右边界初值 flag = 1, // 标记位 k = n / 2; // 要划分的集合元素个数 int sum1 = 0, sum2 = 0; // 两个子集合元素之和 while (flag) { pivotkey = a[left]; // 取第一个元素作为基准值 // 将小于基准值的元素放到左边，大于等于基准值的元素放到右边 while (left < right) { while (left < right && a[right] >= pivotkey) --right; if (left != right) a[left] = a[right]; while (left < right && a[left] <= pivotkey) ++left; if (left != right) a[right] = a[left]; } a[left] = pivotkey; // 将基准值放到中间 if (left == k - 1) { flag = 0; // 标记位设为 0，退出循环 } else { if (left < k - 1) { left += 1; left0 = left right = right0; // 右边界回到初值 } else { right -= 1; } } } }
>
> right0=right; left = left0; // 左边界回到初值 } } // 计算两个子集合的元素之和 for (int i = 0; i < k; ++i) sum1 += a[i]; for (int i = k; i < n; ++i) sum2 += a[i]; return sum2 - sum1; // 返回两个子集合元素之和的差值 }
>
> (3) 因为不是对全部元素进行完整的快速排序，时间复杂度为  $O(n)$，空间复杂度为  $O(1)$。
>
> ▷【真题溯源】这道题在LeetCode上没有直接对应的原题，其算法内核是经典的选择问题（快速排序划分）思想。
>
> 【点评】常规题。考查数组操作的算法题。首先考生可以举一个实例数组，排序后发现，将数组均分成两个长度相等的数组，返回中间位置即可解决问题。所以此时考生可以考虑先将数组排序，再处理后续问题，这也是推荐的方法。考场上留给算法题的时间非常有限，本题的暴力解法很直白也容易想到，暴力解法能拿8分左右。这里的最优解是快速排序中划分的思想，如果考生能想到，这道算法题还是比较容易拿满分的。

## 题干

43. （13分）有实现 $x\times y$ 的两个 C 语言函数如下：

```c
unsigned umul(unsigned x, unsigned y) { return x*y; }
int imul(int x, int y) { return x*y; }
```

假定某计算机 M 中 ALU 只能进行加减运算和逻辑运算。

请回答下列问题。

（1）若 M 的指令系统中没有乘法指令，但有加法、减法和位移等指令，则在 M 上也能实现上述两个函数中的乘法运算，为什么？

（2）若 M 的指令系统中有乘法指令，则基于 ALU、位移器、寄存器以及相应控制逻辑实现乘法指令时，控制逻辑的作用是什么？

（3）针对以下三种情况：①没有乘法指令；②有使用 ALU 和位移器实现的乘法指令；③有使用阵列乘法器实现的乘法指令，函数 `umul()` 在哪种情况下执行时间最长？哪种情况下执行的时间最短？说明理由。

（4）n位整数乘法指令可保存2n位乘积，当仅取低n位作为乘积时，其结果可能会发生溢出。

当 $n=32,x=2^{31}-1,y=2$ 时，带符号整数乘法指令和无符号整数乘法指令得到的 $x\times y$ 的 $2n$ 位乘积分别是什么（用十六进制表示）？此时函数 `umul()` 和 `imul()` 的返回结果是否溢出？对于无符号整数乘法运算，当仅取乘积的低 $n$ 位作为乘法结果时，如何用 $2n$ 位乘积进行溢出判断？

> [!success]- 答案与解析
> **解析：**
>
> (1) 乘法运算可以转换为加法运算和移位运算来实现。在计算机中，若没有乘法指令，可以通过多次的加法和移位操作、直到循环次数达到乘数的位数，从而实现乘法指令的功能。
>
> (2) 控制逻辑的作用：控制加法操作和移位操作的次数，并且发出控制信号来执行判断、加法、移位等操作。
>
> (3) 情况①的执行时间最长，情况③的执行时间最短。情况①要用到多条指令的配合来实现乘法运算，每条指令的执行都可能要经过取指、译码、取数、执行和写回这些阶段。因此情况①中要循环执行多条指令，历时多条指令的指令周期，所以其时间最长。情况②和情况
>
> ③都是使用乘法指令来实现乘法运算，但是乘法指令的实现方式不同。具体来说，情况②使用ALU、位移器实现，要经过多次加法、移位操作，所以需要多个时钟周期；而使用阵列乘法器实现，通过硬件电路直接输出乘法结果，时间最短。所以情况③执行时间最短，情况②次之，情况①执行时间最长。
>
> (4) ① 这一小问无需知道乘法运算的具体细节，题干已经说明，通过 n 位乘法指令保存 2n 位乘积，若只保存 n 位乘积，则可能会由于截断高 n 位而产生溢出。所以求 2n 位乘积时，可以先将乘积的真值求出来，再扩充至 2n 位机器数即可。
>
> $x \times y = (2^{51} - 1) \times 2 = 2^{52} - 2$，对应十八进制为 FFFF FFFF。结果是止数，符号扩展（针对有符号数）或零扩展（针对无符号数）均在高位补 0。所以带符号整数乘法指令和无符号整数乘法指令的 2n 位乘积均为 0000 0000 FFFF FFFEH。
>
> ② umul() 和 imul() 的返回值均为截断高 n 位后的末 n 位乘积，为 FFFF FFFEH。n 位乘积解释为无符号数时真值不变，解释为有符号数时发生溢出（因为 FFFF FFFEH 为负数）。所以 umul() 返回结果不溢出，imul() 返回结果溢出。
>
> ③通过上述分析可知，判断 n 位乘积是否溢出的关键为截断后真值是否发生变化。对于无符号整数乘法运算，当 2n 位乘积的高 n 位全为 0 时，截断高 n 位后真值不发生改变，则结果不溢出，否则溢出。
>
> 【点评】难题。主要围绕乘法运算来考查。乘法运算这个考点难度比较大，可能有些考生备考时放弃了对该考点的学习。本题前3问还是很常见的，基本属于常识性内容。最后一问比较难理解，难以做对。

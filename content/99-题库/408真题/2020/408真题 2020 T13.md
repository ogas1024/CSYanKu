## 题干

13. 已知带符号整数用补码表示，float 型数据用 IEEE754 标准表示，假定变量 x 的类型只可能是 int 或 float。

当 x 的机器数为 C800 0000H 时，x 的值可能是（）

A. $-7 \times 2^{27}$

B. $-2^{16}$

C. $2^{17}$

D. $25 \times 2^{27}$

> [!note]- 原题截图
> ![[408真题 2020 T13.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** C800 0000H 对应的二进制为 1100 1000 0000 0000 0000 0000 0000B。① 若 x 为 float 型，IEEE 754 单精度浮点数格式为：数符（1 位）+ 阶码（8 位）+ 尾数（23 位），则 $x = -2^{17}$；② 若 x 为 int 型，则 x 为带符号补码表示。因为符号位为 1，故 x 为负数。补码转换
>
> 成原码的规则为：负数符号位不变数值位取反加一；正数补码等于原码。所以 x 对应的原码为 1011 10000000 0000 0000 0000 0000 0000，则 x 的真值为  $-7 \times 2^{27}$。
>
> 【点评】常规题。综合考查了 IEEE 754 及补码的表示和运算。这些内容是 408 中必须要掌握的，几乎每年必考。

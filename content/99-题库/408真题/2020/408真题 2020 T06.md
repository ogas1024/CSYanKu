## 题干

6. 修改递归方式实现的图的深度优先搜索（DFS）算法，将输出（访问）顶点信息的语句移到退出递归前（即执行输出语句后立刻退出递归）。

采用修改后的算法遍历有向无环图 G，若输出结果中包含 G 中的全部顶点，则输出的顶点序列是 G 的（）

A. 拓扑有序序列

B. 逆拓扑有序序列

C. 广度优先搜索序列

D. 深度优先搜索序列

> [!note]- 原题截图
> ![[408真题 2020 T06.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 按照题目要求，对 DFS 算法进行修改后的代码如下：
>
> int visited[G.verNum] = {0}; // visited数组：1表已访问，0表未访问 void DepthFirstSearch(const Graph &G) { // 对每个极大连通子图分别调用一次DFS函数 for (int v = 0; v < G.verNum; ++v) { if (visited[v] != 1) // 过滤掉已经访问过的顶点 DFS(G, v); }
>
> void DFS(const Graph &G, int v) { for (int w = findFstN(G, v); w >= 0; w = findNextN(G, v, w)) { // 选取未被访问过的邻居顶点进行访问 if (visited[w] != 1) DFS(G, w); } visit(v); // 访问v顶点（根据实际需要定义visit函数） visited[v] = 1; // 注意：visited是全局变量，不传入DFS作为参数 }
>
> 上述代码的第15和16行（加粗部分的代码）原来在第10行之后，根据题目要求移动到函数末尾。这里以上图为例进行分析、从顶点A开始遍历：
>
> ①根据上述代码，对上图进行遍历，得到的遍历序列为 C, B, A。
>
> ②对上图进行拓扑排序，得到的拓扑序列为 A, B, C。
>
> ③对上图进行DFS遍历，得到的遍历序列为A,C,B或A,B,C。
>
> ④对上图进行BFS遍历，得到的遍历序列为A,C,B或A,B,C。
>
> C, B, A 是逆拓扑序列，故选 B。
>
> 【点评】难题。本题有一定创新性和综合性，要求熟悉BFS、DFS和拓扑排序。考生可结合具体的例子，画草图模拟，逐个排除各个选项。若单纯的推理分析很有难度，较难分析清楚，也容易出错。而且，这种题也没有通法，考查灵活运用，下次再考一个修改经典算法进行分析的题也是没问题的。

## 题干

47. （9分）某校园网有两个局域网，通过路由器R1、R2和R3互联后接入Internet,S1和S2为以太网交换机。

局域网采用静态IP地址配置，路由器部分接口以及各主机的IP地址如下图所示：

![[408真题-2020-T47-fig1.jpg]]

假设 NAT 转换表结构为:

| 外网 |  | 内网 |  |
| --- | --- | --- | --- |
| IP 地址 | 端口号 | IP 地址 | 端口号 |
|  |  |  |  |

请回答下列问题：

（1）为使  $H_{2}$ 和  $H_{3}$ 能够访问 Web 服务器（使用默认端口号），需要进行什么配置？

（2）若 H2 主动访问 Web 服务器时，将 HTTP 请求报文封装到 IP 数据报 P 中发送，则 H2 发送 P 的源 IP 地址和目的 IP 地址分别是什么？经过 R3 转发后，P 的源 IP 地址和目的 IP 地址分别是什么？经过 R2 转发后，P 的源 IP 地址和目的 IP 地址分别是什么？

> [!note]- 原题截图
> ![[408真题-2020-T47.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 只需在 R2 上配置静态 NAT（端口映射）：外网 `203.10.2.2:80` 映射到内网 Web 服务器 `192.168.1.2:80`。
> 2. H2 发出 P 时，源/目的 IP 为 `192.168.1.2`、`203.10.2.2`；经 R3 转发并完成源 NAT 后为 `203.10.2.6`、`203.10.2.2`；经 R2 转发并完成目的 NAT 后为 `203.10.2.6`、`192.168.1.2`。
>
> **解析：** 外部主机只知道 R2 的公网地址和服务器端口，因此 R2 需要固定的目的地址/端口映射。R3 对客户端报文改写源地址，R2 再依据静态表项把目的地址改写为内网服务器地址。

## 题干

44. （10分）假定主存地址为32位，按字节编址，指令Cache和数据Cache与主存之间均采用8路组相联映射方式，直写（Write Through）写策略和LRU替换算法，主存块大小为64B，数据区容量各为32KB。

开始时Cache均为空。

请回答下列问题

（1）Cache 每一行中标记（Tag）、LRU 位各占几位？是否有修改位？

（2）有如下C语言程序段：

```c
for (k = 0; k < 1024; k++)
    s[k] = 2 * s[k];
```

若数组 s 及其变量 k 均为 int 型，int 型数据占 4B, 变量 k 分配在寄存器中，数组 s 在主存中的起始地址为 0080 00C0H, 则该程序段执行过程中，访问数组 s 的数据 Cache 缺失次数为多少？

（3）若 CPU 最先开始的访问操作是读取主存单元 0001 0003H 中的指令，简要说明从 Cache 中访问该指令的过程，包括 Cache 缺失处理过程。

> [!note]- 原题截图
> ![[408真题 2020 T44.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) ①组相联映射地址结构为：主存块标记（Tag）组号 块内地址。由主存块大小为64B，可以得出块内地址占 $\log_2 64 = 6$位。由数据区容量为32KB，可得Cache组数为 $32KB \div 64B \div 8 = 64 = 2^6$组，因此Cache组号占6位。主存地址的Tag位占32-6-6=20位。②由8路组相联映射，每组8块，LRU位数为 $\log_2 8 = 3$位。③因为采取直写法（全写法），所以不需要附设修改位。
>
> (2) 0080 00C0H = 0000 0000 1000 0000 0000 0000 1100 0000B，该地址的末 6 位为 00 0000B，说明该地址位于一个主存块的起始位置。该程序段执行时，依次顺序访问数组元素：
>
> s[0], s[1], s[2],  $\cdots$, s[1023]。一个主存块中可存放  $64B \div 4B = 16$ 个数组元素，s 数组有 1024 个元素，共占  $1024 \div 16 = 64$ 个主存块。对于存放数组 s 的数据的每个主存块，首次访问时会发生 Cache 缺失，64 个主存块总共缺失了 64 次。
>
> (3) 0001 0003H = 0000 0000 0000 0001 0000 0000 0000 0011B。根据第一小问分析的地址结构，块内地址为：00 0011B，Cache 组号为：0000 00B，主存块标记 Tag 为：0000 0000 0000 0001 0000B。初始时，Cache 为空，访问会发生 Cache 缺失。因为组号为 0，将缺失的主存块存入 Cache 第 0 组中（组内任意一行），并同时修改 LRU 位和有效位，将 Cache 该行标记设置为：0000 0000 0000 0001 0000B，再根据块内地址 00 0011B 读取内容。
>

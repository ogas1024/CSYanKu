## 题干

41. （13分）定义三元组$(a,b,c)$（其中$a,b,c$均为正数）的距离$D=|a-b|+|b-c|+|c-a|$。

给定3个非空整数集合$S_1$、$S_2$、$S_3$，按升序分别存储在3个数组中。

设计一个尽可能高效的算法，计算并输出所有可能的三元组$(a,b,c)(a\in S_1,b\in S_2,c\in S_3)$中的最小距离。

例如$S_1=\{-1,0,9\}, S_2=\{-25,-10,10,11\}, S_3=\{2,9,17,30,41\}$，则最小距离为2，相应的三元组为$(9,10,9)$。

要求：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

（3）说明你所设计算法的时间复杂度和空间复杂度。

> [!success]- 答案与解析
> **解析：**
>
> 【暴力解】
>
> (1) 穷举出所有的三元组，求出最小距离。
>
> (2) 代码实现如下：
>
> int findMin(int s1[], int s2[], int s3[], int n1, int n2, int n3) { int temp; int minDist = INF; //将minDist初始化为最大的int型整数INF for (int i = 0; i < n1; i++) { for (int j = 0; j < n2; j++) { for (int k = 0; k < n3; k++) { temp = abs(s1[i]-s2[j])+abs(s2[j]-s3[k])+abs(s1[i]-s3[k]); if (temp < minDist) { minDist = temp; } } } } return minDist; }
>
> (3) 3 层循环，时间复杂度为  $O(n^{3})$，空间复杂度为  $O(1)$。
>
> 【最优解】
>
> (1) 用变量 minDist 记录当前的最小距离。由于  $S_1, S_2, S_3$ 按升序排列，遍历三个数组，计算当前三元组  $(a, b, c)$ 的距离 temp。若 temp < minDist，则令 minDist = temp。将  $(a, b, c)$ 中最小的数对应下标加一，重复之前步骤直到遍历结束。
>
> (2) 代码实现如下：
>
> int findMin(int s1[], int s2[], int s3[], int n1, int n2, int n3) { int temp, minDist = INF; // 将 minDist 初始化为最大的 int 型整数 INF int i = j = k = 0; while (i < n1 && j < n2 && k < n3) { temp = abs(s1[i] - s2[j]) + abs(s2[j] - s3[k]) + abs(s1[i] - s3[k]); // minDist 赋值为 minDist 和 temp 中的最小值 minDist = temp < minDist ? temp : minDist; if (s1[i] == min(s1[i], s2[j], s3[k])) { i++; } else if (s2[j] == min(s1[i], s2[j], s3[k])) { j++; } else {
>
> k++; } } return minDist; }
>
> (3) 设 n 为三个数组中元素数量的总和，时间复杂度为  $O(n)$，空间复杂度为  $O(1)$。

## 题干

41. （13分）定义三元组$(a,b,c)$（其中$a,b,c$均为正数）的距离$D=|a-b|+|b-c|+|c-a|$。

给定3个非空整数集合$S_1$、$S_2$、$S_3$，按升序分别存储在3个数组中。

设计一个尽可能高效的算法，计算并输出所有可能的三元组$(a,b,c)(a\in S_1,b\in S_2,c\in S_3)$中的最小距离。

例如$S_1=\{-1,0,9\}, S_2=\{-25,-10,10,11\}, S_3=\{2,9,17,30,41\}$，则最小距离为2，相应的三元组为$(9,10,9)$。

要求：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

（3）说明你所设计算法的时间复杂度和空间复杂度。

> [!note]- 原题截图
> ![[408真题-2020-T41.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 令三个下标分别指向 A、B、C 的当前元素，计算当前三元组距离并更新最小值；随后只推进三个当前元素中最小者的下标，直到任一数组耗尽或最小距离变为 0。
> 2. ```c
> #define INT_MAX 0x7fffffff
> int abs_(int x) { return x < 0 ? -x : x; }
> int is_min(int a, int b, int c) { return a <= b && a <= c; }
>
> int findMinofTrip(int A[], int n, int B[], int m, int C[], int p) {
>     int i = 0, j = 0, k = 0, dmin = INT_MAX;
>     while (i < n && j < m && k < p && dmin > 0) {
>         int d = abs_(A[i] - B[j]) + abs_(B[j] - C[k])
>               + abs_(C[k] - A[i]);
>         if (d < dmin) dmin = d;
>         if (is_min(A[i], B[j], C[k])) ++i;
>         else if (is_min(B[j], C[k], A[i])) ++j;
>         else ++k;
>     }
>     return dmin;
> }
> ```
> 3. 若三数组长度之和为 N，时间复杂度为 $O(N)$，额外空间复杂度为 $O(1)$。
>
> **解析：** 对三个有序数组，当前最小元素若不前移，不可能通过移动其余两个较大元素得到更小的极差；每次至少推进一个下标，因此总扫描次数为线性级。

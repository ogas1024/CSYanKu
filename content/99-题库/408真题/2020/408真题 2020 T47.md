## 题干

47. （9分）某校园网有两个局域网，通过路由器R1、R2和R3互联后接入Internet,S1和S2为以太网交换机。

局域网采用静态IP地址配置，路由器部分接口以及各主机的IP地址如下图所示：

![[408真题 2020 T47-fig1.webp]]

假设 NAT 转换表结构为:

| 外网 |  | 内网 |  |
| --- | --- | --- | --- |
| IP 地址 | 端口号 | IP 地址 | 端口号 |
|  |  |  |  |

请回答下列问题：

（1）为使  $H_{2}$ 和  $H_{3}$ 能够访问 Web 服务器（使用默认端口号），需要进行什么配置？

（2）若 H2 主动访问 Web 服务器时，将 HTTP 请求报文封装到 IP 数据报 P 中发送，则 H2 发送 P 的源 IP 地址和目的 IP 地址分别是什么？经过 R3 转发后，P 的源 IP 地址和目的 IP 地址分别是什么？经过 R2 转发后，P 的源 IP 地址和目的 IP 地址分别是什么？

> [!note]- 原题截图
> ![[408真题 2020 T47.webp]]

> [!success]- 答案与解析
> **解析：**
>
> （1）主机 H2、H3 和 Web 服务器不在同一个局域网中。要使得外部主机能访问内网中的 Web 服务器，必须进行 NAT 配置，在路由器 R2 的 NAT 转换表中配置外网地址到内网地址的映射。Web 服务器使用 HTTP 协议，而 HTTP 协议的默认端口是 80。当路由器 R2 的 80 端口收到请求时，将其转发到内网中的 Web 服务器。路由器 R2 唯一的外网 IP 地址为 203.10.2.2，Web 服务器的内网 IP 地址为 192.168.1.2。路由器 R2 的 NAT 转换表具体配置如下表所示。
>
> | 外网 | 外网 | 内网 | 内网 |
> |---|---|---|---|
> | IP 地址 | 端口号 | IP 地址 | 端口号 |
> | 203.10.2.2 | 80 | 192.168.1.2 | 80 |
>
> (2) R3 与 R2 是 NAT 路由器，对穿越内网外网的 IP 分组进行 IP 地址转换。① H2 发送的数据报 P 使用 192.168.1.2 作为源地址，使用 R2 的外网地址 203.10.2.2 作为目的地址。② 经过 R3 转发后，进入外网，源地址变为 R3 的外网地址 203.10.2.6，目的地址保持 203.10.2.2 不变。③ 经过 R2 转发后，进入 R2 的内网，源地址保持 R3 的外网地址 203.10.2.6 不变，目的地址改为 Web 服务器的内网地址 192.168.1.2。
>
> ▷【点评】常规题。本题考查 NAT 地址转换这个单一考点。一般的在教辅中都有对该考点的介绍，也有类似的练习题。

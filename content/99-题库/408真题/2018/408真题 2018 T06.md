## 题干

6. 已知二叉排序树如右图所示，元素之间应满足的大小关系是（）。

A. $x_1 < x_2 < x_5$

B. $x_1 < x_4 < x_5$

C. $x_3 < x_5 < x_4$

D. $x_4 < x_3 < x_5$

![[408真题 2018 T06-fig1.webp]]

> [!note]- 原题截图
> ![[408真题 2018 T06.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 二叉排序树的中序遍历序列是一个递增的有序序列（这也是判断一棵树是否为二叉树的常用算法），题目所示的二叉排序树的中序遍历为  $x_{1}, x_{3}, x_{5}, x_{4}, x_{2}$，所以  $x_{1} < x_{3} < x_{5} < x_{4} < x_{2}$。故选 C。
>
> 【点评】常规题。考查二叉排序树中序遍历的性质。

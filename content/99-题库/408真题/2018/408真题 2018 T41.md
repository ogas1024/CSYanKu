## 题干

41. （13分）给定一个含 $n$（ $n \geq 1$）个整数的数组，请设计一个在时间上尽可能高效的算法，找出数组中未出现的最小正整数。

例如，数组\{-5,3,2,3\}中未出现的最小正整数是1；

数组\{1,2,3\}中未出现的最小正整数是4。

要求：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

（3）说明你所设计算法的时间复杂度和空间复杂度。

> [!success]- 答案与解析
> **解析：**
>
> (1) 含有 $n$个整数的数组中，未出现的最小正整数一定落在区间$[1, n+1]$内：因为$1 \sim n$这$n$个正整数若全部出现，则数组恰好被占满，此时答案是$n+1$；否则 $[1, n]$中必有缺席者，最小缺席者即答案。
>
> 只需要用一个辅助数组$S[n+2]$记录$k$ 是否出现过即可。$S[k] = 1$表示$k$ 在原数组中出现过，$S[k] = 0$表示未出现过。遍历完原数组后只需再次遍历$S$查找最小未出现整数即可。
>
> (2) 代码实现如下：
>
> int findMissMin(int A[], int n) { int S[n+2] = {0}, i; // 辅助数组，记录A中元素是否出现过 for (i = 0; i < n; i++) { if (A[i] > 0 && A[i] <= n) { S[A[i]] = 1; } } for (i = 1; i <= n + 1; i++) { // 从1开始遍历是因为0不是正整数 if (S[i] == 0) { break; } } return i; }
>
> (3) 算法的时间复杂度为$ O(n) $，空间复杂度为  $O(n)$。
>
> 【提示】本题暴力解法思路：先对数组元素排序（采用快速排序或者冒泡排序等任意一种），设置一个变量整型 count，初值为 1。再从有序数组第一个非负元素的位置开始遍历，遍历时若数组元素当前值等于 count，则令 count++, 最后 count 的值即为所求值。时间复杂度为采用排序算法的时间复杂度。
>

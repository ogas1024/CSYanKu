## 题干

25. 属于同一进程的两个线程 thread1 和 thread2 并发执行，共享初值为 0 的全局变量 x。

thread1 和 thread2 实现对全局变量 x 加 1 的机器级代码描述如下：

| thread1 | thread2 |
| --- | --- |
| mov R1, x //(x) → R1 | mov R2, x //(x) → R2 |
| inc R1 //(R1) + 1 → R1 | inc R2 //(R2) + 1 → R2 |
| mov x, R1 //(R1) → x | mov x, R2 //(R2) → x |

在所有可能的指令执行序列中，使 x 的值为 2 的序列个数是（）。

A. 1

B. 2

C. 3

D. 4

> [!note]- 原题截图
> ![[408真题 2018 T25.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 两个线程 thread1 和 thread2 各执行 3 条指令（读 x 到寄存器、加 1、写回 x），每个线程内部的指令顺序执行，两线程的指令执行顺序可交错。最终 x 的值取决于两个“读 x”动作与两个“写 x”动作的先后关系：
>
> 若某线程的指令完整地先于另一线程执行，则后执行的线程读到的是前者已写回的1，再加1写回2，最终x=2。
>
> ◇ 只要两个线程的指令出现交错：即第二个读操作发生在第一个写操作之前，两个线程读到的都是0，各自算出1，两次写回的都是1，最终x=1。
>
> 因此，使 x=2 的执行顺序只有 2 种：thread1 先完整执行、thread2 后执行；或 thread2 先完整执行、thread1 后执行。故选 B。
>
> 【点评】常规题。考查多线程指令交错执行的原子性问题。要求考生枚举所有可能的指令交错序列，理解“inc”指令在机器级不是原子操作，类似的题在408真题中考过多次。

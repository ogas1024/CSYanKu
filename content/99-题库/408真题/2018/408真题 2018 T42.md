## 题干

42. （12分）拟建设一个光通信骨干网络连通BJ、CS、XA、QD、JN、NJ、TL和WH等8个城市，题42图中无向边上的权值表示两个城市间备选光纤的铺设费用。

![[408真题 2018 T42-fig1.webp]]

题42图

请回答下列问题。

（1）仅从铺设费用角度出发，给出所有可能的最经济的光纤铺设方案（用带权图表示），并计算相应方案的总费用。

（2）题42图可采用图的哪种存储结构？给出求解问题（1）所使用的算法名称。

（3）假设每个城市采用一个路由器按（1）中得到的最经济方案组网，主机 H1 直接连接在 TL 的路由器上，主机 H2 直接连接在 BJ 的路由器上。

若 H1 向 H2 发送一个 TTL=5 的 IP 分组，则 H2 是否可以收到该 IP 分组？

> [!note]- 原题截图
> ![[408真题 2018 T42.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) 求最经济的连接各个城市的光缆铺设方案，可抽象为求图的最小生成树问题。求解最小生成树有 Prim 算法和 Kruskal 算法，任选一种解决均可。如下图所示，因为本题图中存在多条权值相同的最小边，对应的最小生成树有 2 棵，对应的光缆铺设方案有 2 种。最小生成树的所有边权值之和均为 16，对应方案的总费用均为 16。
>
> (2) 该图是无向图，可采用邻接矩阵、邻接表或邻接多重表来存储。求解问题 (1) 的算法名称是 Prim 算法或 Kruskal 算法。
>
> (3) 对于方案一，H2 不能收到该 IP 分组；对于方案二，H2 可以收到该 IP 分组。
>
> ▷【提示】这里综合考查了计网中“生存时间TTL（TimeToLive）”的概念：路由器在转发IP分组前会将TTL减一。若减一后TTL为0，则丢弃该分组。
>
> ① 对于方案一，主机 H1 给 H2 发送 IP 分组的路由转发路径为：H1 → TL → JN → QD → WH → XA → BJ → H2。IP 分区每经过一个路由器转发，TTL 会减一，当路由器 BJ 收到该 IP 分组时，TTL = 0，所以该分组会被丢弃，故 H2 收不到该 IP 分组。
>
> ②对于方案二，主机H1给H2发送IP分组的路由转发路径为：H1→TL→BJ→H2。IP分区每经过一个路由器转发，TTL会减一，当路由器BJ收到该IP分组时，TTL=3，故H2可收到该IP分组。
>
> ▷【点评】创新题。最小生成树的应用题，并结合计算机网络考查（所以本套试卷计网部分总分只有23分，数据结构部分总共47分），考法较为新颖巧妙，创新程度高。而且，本题的答案不唯一：第(3)问两种方案对应的答案截然相反。这种陌生且开放性答案的题目，增加了不确定性，在考场高压环境下，会带来很大的心理压力。

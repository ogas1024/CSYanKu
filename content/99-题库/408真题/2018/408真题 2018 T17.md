## 题干

17. 假定 DRAM 芯片中存储阵列的行数为 r、列数为 c，对于一个  $2K \times 1$ 位的 DRAM 芯片，为保证其地址引脚数最少，并尽量减少刷新开销，则 r、c 的取值分别是（）。

A. 2048、1

B. 64、32

C. 32、64

D. 1、2048

> [!note]- 原题截图
> ![[408真题 2018 T17.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 对于一个  $2K \times 1$ 位的 DRAM 芯片， $2K = 2^{11} = 2048$，总共有 2048 个可独立寻址的存储单元，需满足  $r \times c = 2048$。根据 DRAM 芯片行列地址分时复用和按行刷新的特性，来分别分析各个选项。
>
> DRAM 芯片行地址和列地址 $\underline{\text{分时复用}}$同一组地址引脚，地址引脚数=max(log $_{2}$r,log $_{2}$c)。
>
> DRAM 芯片按行刷新，刷新开销和行数 r 成正比，行数越少，刷新开销越小。
>
> A选项： $r = 2048, c = 1$， $\max(\log_2 2048, \log_2 1) = 11$ 根引脚，行数 2048，刷新开销极大。
>
> B选项： $r = 64, c = 32$， $\max(\log_2 64, \log_2 32) = \max(6, 5) = 6$ 根引脚，行数64。
>
> C选项： $r = 32, c = 64$， $\max(\log_2 32, \log_2 64) = \max(5, 6) = 6$ 根引脚，行数 32。
>
> D选项： $r=1,c=2048,\max(\log_{2}1,\log_{2}2048)=11$ 根引脚。
>
> B 选项和 C 选项的地址引脚数相同，但 C 选项的行数更小，刷新开销更小。故选 C。
>
> 【点评】难题。考查DRAM地址复用和按行刷新的特性，要分析题目给出的4个选项求解。比较新颖，考生第一次接触时可能无从下手。

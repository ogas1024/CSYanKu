## 题干

44. （15分）某计算机采用页式虚拟存储管理方式，按字节编址。

CPU进行存储访问的过程如题44图所示。

根据题 44 图回答下列问题。

（1）主存物理地址占多少位？

（2）TLB采用什么映射方式？TLB是用SRAM还是用DRAM实现？

（3）Cache 采用什么映射方式？若 Cache 采用 LRU 替换算法和回写（Write Back）策略，则 Cache 每行中除数据（Data）、Tag 和有效位外，还应有哪些附加位？Cache 的总容量是多少？Cache 中有效位的作用是什么？

（4）若 CPU 给出的虚拟地址为 0008 C040H，则对应的物理地址是多少？是否在 Cache 中命中？说明理由。

若 CPU 给出的虚拟地址为 0007 C260H，则该地址所在主存块映射到的 Cache 组号是多少？

> [!success]- 答案与解析
> **解析：**
>
> (1) 访问 Cache 时使用物理地址，故图中与 Cache 直接相连的结构必为物理地址，观察图中对应地址结构可知，物理地址的位数 = 20 + 3 + 5 = 28 位。
>
> (2) ① TLB 采用全相联映射：图中 TLB 每个表项都有独立的比较器，虚页号同时与所有 Tag 并行比较，没有固定的映射规则，这是全相联映射的特征。
>
> ②TLB用SRAM实现：TLB是高速缓存，要求速度快，SRAM速度快但成本高，适合小容量高速缓存。
>
> (3) ① 图中 Cache 分为左右两列，每组 2 行，用多路选择器输出，所以 Cache 采用二路组相联映射。② 附加位：
>
> LRU 替换算法需要 1 位 LRU 位（2 路组相联每组 1 位即可记录哪路最近最少使用）；
>
> ◇ 回写策略需要1位修改位（脏位），标记该行是否被修改过，替换时决定是否写回主存。
>
> ③ Cache 参数：28 位物理地址中 Tag = 20 位，组索引 = 3 位（共  $2^3 = 8$ 组），块内偏移 = 5 位（每块  $2^5 = 32B$），每组 2 路。每行总位数 = 数据  $(32 \times 8 = 256$ 位) + Tag(20 位) + 有效位 (1 位) + 脏位 (1 位) + LRU 位 (1 位) = 279 位。
>
> Cache 总容量 = 8 组  $\times$ 2 路  $\times$ 279 位 = 4464 位 = 558B。
>
> ④有效位作用：标识 Cache 行中的数据是否有效。初始时或主存块被换出后有效位置 0，即使 Tag 匹配，若有效位为 0 也不能命中。
>
> (4) ① 虚拟地址 0008C040H：虚页号（高 20 位）= 0008CH，页内偏移（低 12 位）= 040H。查 TLB：Tag=0008CH，有效位=1，实页号 = 0040H，TLB 命中。将实页号和偏移拼接得到物理地址 = 0040040H。
>
> ② Cache 命中判断：根据图中给出的物理地址结构，将物理地址 0040040H 拆分为 Tag(20 位) + 组索引 (3 位) + 块内偏移 (5 位)。0040040H = 0000 0000 0100 0000 0000 0100 0000B，则 Tag = 00400H，组号 = 010B = 2，块内偏移 = 00000B。查图中 Cache 第 2 组：左路 Tag = 00400H 但有效位 = 0（无效）；右路 Tag = 01600H（不匹配）。故 Cache 未命中。
>
> ③ ▷根据图中给出的虚拟地址结构： $\underline{\text{虚页号 (20 位)}}$ ▶页内偏移 (12 位)，虚拟地址 0007C260H 的页内偏移（后 12 位）=260H=0010 0110 0000B。
>
> ▶根据图中给出的物理地址结构： $\underline{\text{Tag 标记 (20 位)}}$ ▶组号 (3 位) ▶块内偏移 (5 位)，Cache 组号是物理地址的第 6～8 位（块内偏移左边 3 位），而页内偏移在虚实地址转换中保持不变，因此直接取页内偏移的第 6～8 位：011B=3。该地址所在主存块映射到 Cache 第 3 组。
>
> 【拓展】在2022年408第16题考查了Cache比较器的个数、位数，其原理和本题出现的TLB比较器一致。所以，考生应仔细研究分析历年408真题，真的会遇到“原题”。以TLB为例，下面是关于比较器的个数结论：
>
> ☑ 直接映射：一个块只能映射到一个 TLB 行，故只需要一个比较器；
>
> ◇ 全相联映射：一个块可以映射到多个TLB行，为了加快映射速度，一般采用多个比较器，一个TLB行对应一个比较器；
>
> ☑ 组相联映射中需要的比较器个数为 TLB 一组中的行数。
>
> ▷【点评】难题。综合考查存储系统中页式虚拟存储、TLB、Cache 三大核心机制，信息量大、计算环节多。命题人要求考生从流程图中提取参数（虚拟地址结构、TLB 全相联、Cache 二路组相联、物理地址结构），然后完成物理地址计算、Cache 命中判断和组号计算。第（4）小问问的第二小问尤其巧妙——组索引来自页内偏移（虚拟地址低 12 位），而虚实地址的页内偏移是相同的，直接从虚拟地址 260H 中提取 6～8 位 =011B =3 即可。

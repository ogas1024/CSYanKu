## 题干

13. 假定带符号整数采用补码表示，若 int 型变量 x 和 y 的机器数分别是 FFFF FFDFH 和 0000 0041H，则 x、y 的值以及 x-y 的机器数分别是（）。

A. x=-65, y=41，x-y 的机器数溢出

B. x=-33, y=65，x-y 的机器数为 FFFF FF9DH

C. x=-33, y=65，x-y 的机器数为 FFFF FF9EH

D. x=-65, y=41，x-y 的机器数为 FFFF FF96H

> [!note]- 原题截图
> ![[408真题 2018 T13.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** ① 将 **负数补码**转换成原码的规则为：符号位不变，将数值位取反再加1。
>
> [x] 补码 = FFFF FFDFH = 1111 1111 1111 1111 1111 1111 1111 1111 1111 1111 1111 1111 1111 B  $\xrightarrow{[x]}$ 补除符号位外，其余各位取反
>
> 000 0000 0000 0000 0000 0000 0010 0000  $\xrightarrow{+1}$ [x] 原码 = 1 000 0000 0000 0000 0000 0000 0010 0001
>
> =-33 。② 正数的补码和原码相同，[y] 补码 = 0000 0041H = 0000 0000 0000 0000 0000 0100 0001B = 65 。③ [x-y] 补码 = [x] 补码 + [-y] 补码。[-y] 补码等于将 [y] 补码连同符号位在内，各位取反，再加1。则 [-y] 补码 = 1111 1111 1111 1111 1111 1111 1111 1111 1111 B = FFFF FFBFH。
>
> [x-y] 补码 = [x] 补码 + [-y] 补码 = FFFF FFDFH + FFFF FFBFH = FFFF FF9EH。计算过程如下：
>
> 【提示】求 x-y 的机器数也可以用如下方法：x-y = -33 - 65 = -98，-98 的 32 位十六进制补码为 FFFF FF9EH。32 位补码的表示范围为  $-2^{31} \sim 2^{31} - 1$，求出 x 和 y 的真值之后，可以很明显的看出未发生溢出。
>
> 【点评】常规题。考查补码运算、补码和十进制的相互转换，这些内容是备考408必须掌握的。

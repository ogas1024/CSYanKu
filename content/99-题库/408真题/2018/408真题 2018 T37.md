## 题干

37. 路由器 R 通过以太网交换机 S1 和 S2 连接两个网络，R 的接口、主机 H1 和 H2 的 IP 地址与 MAC 地址如下图所示。

若 H1 向 H2 发送 1 个 IP 分组 P，则 H1 发出的封装 P 的以太网帧的目的 MAC 地址、H2 收到的封装 P 的以太网帧的源 MAC 地址分别是（）

![[408真题 2018 T37-fig1.webp]]

A. `00-a1-b2-c3-d4-62, 00-1a-2b-3c-4d-52`

B. `00-a1-b2-c3-d4-62, 00-a1-b2-c3-d4-61`

C. `00-1a-2b-3c-4d-51, 00-1a-2b-3c-4d-52`

D. `00-1a-2b-3c-4d-51, 00-a1-b2-c3-d4-61`

> [!note]- 原题截图
> ![[408真题 2018 T37.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 封装 IP 分组的以太网帧每经过一个路由器就会被解封装并重新封装，帧的源/目的 MAC 地址只在本链路（本网络）内有效。
>
> 第一段链路（H1 → R，经 S1）：H1 发现目的 IP（192.168.4.2）与自己不在同一网络（H1 在 192.168.3.0/24 网），故将帧发往默认网关—路由器 R 的左接口。因此：
>
> ◇ H1 发出帧的目的 MAC = R 左接口的 MAC = 00-1a-2b-3c-4d-51
>
> ◇ H1 发出帧的源 MAC = H1 的 MAC = 00-1a-2b-3c-4d-52
>
> 第二段链路（R→H2，经S2）：路由器R取出IP分组P后重新封装，从右接口发出：
>
> ◇ 目的 MAC = H2 的 MAC = 00-a1-b2-c3-d4-62
>
> ◇ 源 MAC = R 右接口的 MAC = 00-a1-b2-c3-d4-61
>
> 题目问“H1 发出的帧的目的 MAC”与“H2 收到的帧的源 MAC”，即 00-1a-2b-3c-4d-51 和 00-a1-b2-c3-d4-61，对应选项 D。
>
> ▷【提示】在标准 IP 转发过程中，IP 数据报的源 IP 地址和目的 IP 地址在从源主机到目的主机的传输过程中保持不变，路由器仅根据目的 IP 地址进行转发。例外情况包括 NAT 设备、IP 隧道封装、移动 IP 等场景。
>
> 【点评】常规题。本题考查以太网帧的转发机制。

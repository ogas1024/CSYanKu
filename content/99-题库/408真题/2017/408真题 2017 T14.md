## 题干

14. 某 C 语言程序段如下：

```c
for(i=0;i<=9;i++) {
    temp = 1;
    for(j=0;j<=i;j++) temp *=a[j];
    sum += temp;
}
```

下列关于数组 `a` 的访问局部性的描述中，正确的是（）。

A. 时间局部性和空间局部性皆有

B. 无时间局部性，有空间局部性

C. 有时间局部性，无空间局部性

D. 时间局部性和空间局部性皆无

> [!note]- 原题截图
> ![[408真题 2017 T14.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** ①空间局部性。内层循环 for(j=0;j<=i;j++) temp *= a[j]; 中，j从0递增到i，依次访问a[0]、a[1]、a[2]、…，数组元素在内存中连续存放，访问的是相邻的存储单元，因此具有空间局部性。
>
> ②时间局部性。外层循环i从0到9执行10次：i=0时访问a[0]；i=1时访问a[0]、a[1]；i=2时访问a[0]、a[1]、a[2]；…。同一个元素，例如a[0]在外层循环中会被反复访问10次，a[1]被访问9次，…，即近期访问过的数据很快会再次被访问，因此具有时间局部性。故选A。
>
> 【提示】①时间局部性指程序中刚被访问过的存储单元，在不久的将来很可能再次被访问，其本质是同一个数据/指令被重复使用。例如：循环结构中的循环变量、循环体内的代码（指令）。
>
> ②空间局部性指程序中刚被访问过的存储单元，其附近（邻近）的存储单元在不久的将来很可能被访问，其访问地址连续或邻近。例如：顺序遍历数组、顺序执行指令。
>
> 【点评】概念题。本题考查时间局部性和空间局部性的概念。

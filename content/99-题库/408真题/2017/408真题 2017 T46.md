## 题干

46. （8分）某进程中有3个并发执行的线程 thread1、thread2 和 thread3，其伪代码如下所示：

```c
//复数的结构类型定义
typedef struct
{
    float a;
    float b;
} cnum;

cnum x, y, z; //全局变量

//计算两个复数之和
cnum add( cnum p, cnum q)
{
    cnum s;
    s.a=p.a+q.a;
    s.b=p.b+q.b;
    return s;
}
```

```c
thread1
{
    cnum w;
    w = add(x, y);
    ...
}
```

```c
thread2
{
    cnum w;
    w = add(y, z);
    ...
}
```

```c
thread3
{
    cnum w;
    w.a=1;
    w.b=1;
    z=add(z, w);
    y=add(y, w);
    ...
}
```

请添加必要的信号量和 P、V（或  $\text{wait}()$、 $\text{signal}()$）操作，要求确保线程互斥访问临界资源，并且最大限度地并发执行。

> [!note]- 原题截图
> ![[408真题 2017 T46.webp]]

> [!success]- 答案与解析
> **解析：**
>
> ①本题属于经典互斥问题，全局变量 x、y、z 是临界资源，需对其互斥访问。而三个线程中的三个 w 是局部变量（线程私有资源，相互独立），不是临界资源。
>
> ② 只有 thread1 涉及对临界资源 x 的读取，无需定义 x 的互斥信号量。而 thread1 读 y，thread3 读写 y，需实现互斥；
>
> ③ thread2 读 y，thread3 写 y，也需实现互斥，故定义两个互斥信号量 mutex_y_13 和 mutex_y_23。
>
> ④对于变量 z，thread2 读 z，thread3 读写 z，故定义互斥信号量 mutex_z。
>
> 对上述互斥信号量赋初值1。
>
> thread1 读取 y 时，应防止 thread3 改动 y，因此读取前后分别对 mutex_y_13 执行 P 和 V 操作；
>
> thread2 读取 y 和 z 时，应防止 thread3 改动 y 和 z，因此读取前后分别对 mutex_y_23 和 mutex_z 执行 P 和 V 操作；
>
> thread3 改动 z 时，应防止 thread2 读取 z，因此改动 z 前后分别对 mutex_z 执行 P 和 V 操作；
>
> thread3 改动 y 时，应防止 thread1 和 thread2 读取 y，因此改动 y 前后分别对 mutex_y_13 和 mutex_y_23 执行 PV 操作。
>
> 题干中的三个线程没有协同关系，故无需定义同步信号量。伪代码实现如下：
>
> semaphore mutex_y_13 = 1; //实现thread1与thread3对y的互斥访问 semaphore mutex_y_23 = 1; //实现thread2与thread3对y的互斥访问 semaphore mutex_z = 1; //实现thread2与thread3对z的互斥访问
>
> CoBegin{ thread1{ cnum w; P(mutex_y_13); // (互斥) 防止thread3读写y w = add(x, y); // 涉及对互斥资源y的读取 V(mutex_y_13); // (互斥) 允许thread3读写y ... thread2{ cnum w; P(mutex_y_23); // (互斥) 防止thread3读写y P(mutex_z); // (互斥) 防止thread3读写z w = add(y, z); // 涉及对互斥资源y和z的读取 V(mutex_z); // (互斥) 允许thread3读写z V(mutex_y_23); // (互斥) 允许thread3读写y } thread3{ cnum w; w.a = 1; w.b = 1; P(mutex_z); // (互斥) 防止读写z时thread2读z z = add(z, w); // 涉及对互斥资源z的读写 V(mutex_z); // (互斥) 读写完毕，允许thread2读z P(mutex_y_13); // (互斥) 防止读写y时thread1读y P(mutex_y_23); // (互斥) 防止读写y时thread2读y y = add(y, w); // 涉及对互斥资源y的读写 V(mutex_y_13); // (互斥) 读写完毕，允许thread1读y V(mutex_y_23); // (互斥) 读写完毕，允许thread2读y } } }
>
> CoEnd
>
> ▷【提示】有的考生可能 thread1、thread2、thread3 中对 y 都采用了一个互斥量来实现对 y 的互斥访问，该方案错误的原因是题目要求最大限度并发进行，而 thread1、thread2 都只是读取 y，可以并发进行，因此需要采用两个互斥量区分两个进程，使得二者可以并发读取 y。
>
> (1)  $t_{0}$ 到  $t_{1}$ 期间，乙方已经接收到了  $S_{0,0}$、 $S_{1,0}$、 $S_{2,0}$ 共三个数据帧，因此甲方可以确定乙方已经确认接收的数据帧数为 3。在  $t_{1}$ 之前甲方收到的最后一个乙方发来的帧为  $R_{3,3}$，即乙方希望甲方发送序号为 3 的帧，代表序号为 0～2 的帧已被正确接收。
>
> ▷【点评】难题。不同于经典的“生产者—消费者”类问题，本题属于难度相对较大的一类P/V题。需要分析的同步互斥关系比较多，在考场高压且时间紧张的环境下，较难分析清楚。考生平时需要多做一些各种类型的P/V练习题，做过的题型多了，才能应对此类比较新的题。

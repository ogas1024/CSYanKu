## 题干

46. （8分）某进程中有3个并发执行的线程 thread1、thread2 和 thread3，其伪代码如下所示：

```c
//复数的结构类型定义
typedef struct
{
    float a;
    float b;
} cnum;

cnum x, y, z; //全局变量

//计算两个复数之和
cnum add( cnum p, cnum q)
{
    cnum s;
    s.a=p.a+q.a;
    s.b=p.b+q.b;
    return s;
}
```

```c
thread1
{
    cnum w;
    w = add(x, y);
    ...
}
```

```c
thread2
{
    cnum w;
    w = add(y, z);
    ...
}
```

```c
thread3
{
    cnum w;
    w.a=1;
    w.b=1;
    z=add(z, w);
    y=add(y, w);
    ...
}
```

请添加必要的信号量和 P、V（或  $\text{wait}()$、 $\text{signal}()$）操作，要求确保线程互斥访问临界资源，并且最大限度地并发执行。

> [!note]- 原题截图
> ![[408真题 2017 T46.png]]

> [!success]- 答案与解析
> **答案：**
>
> ```c
> semaphore mutex_y1=1, mutex_y2=1, mutex_z=1;
>
> thread1: wait(mutex_y1); w=add(x,y); signal(mutex_y1);
> thread2: wait(mutex_y2); wait(mutex_z); w=add(y,z);
>          signal(mutex_z); signal(mutex_y2);
> thread3: w.a=1; w.b=1;
>          wait(mutex_z); z=add(z,w); signal(mutex_z);
>          wait(mutex_y1); wait(mutex_y2); y=add(y,w);
>          signal(mutex_y1); signal(mutex_y2);
> ```
>
> **解析：** thread1 与 thread3 对 y、thread2 与 thread3 对 y、thread2 与 thread3 对 z 分别构成读写互斥关系；读—读无需互斥，因此使用三把锁保留并发度。

## 题干

43. （13分）已知 $f(n)=\sum_{i=0}^{n}2^{i}=2^{n+1}-1=\overbrace{11\cdots11}^{n+1}\mathrm{B}$，计算 $f(n)$ 的 C 语言函数 `f1` 如下：

```c
int f1(unsigned n){
    int sum=1, power=1;
    for(unsigned i=0;i<=n-1;i++) {
        power *= 2;
        sum += power;
    }
    return sum;
}
```

将 `f1` 中的 `int` 都改为 `float`，可得到计算 $f(n)$ 的另一个函数 `f2`。

假设 `unsigned` 和 `int` 型数据都占 $32$ 位，`float` 采用 IEEE754 单精度标准。

请回答下列问题。

（1）当 $n=0$ 时，`f1` 会出现死循环，为什么？若将 `f1` 中的变量 `i` 和 `n` 都定义为 `int` 型，则 `f1` 是否还会出现死循环？为什么？

（2）`f1(23)` 和 `f2(23)` 的返回值是否相等？机器数各是什么（用十六进制表示）？

（3）`f1(24)` 和 `f2(24)` 的返回值分别为 $33\ 554\ 431$ 和 $33\ 554\ 432.0$，为什么不相等？

（4）$f(31)=2^{32}-1$，而 `f1(31)` 的返回值却为 $-1$，为什么？若使 `f1(n)` 的返回值与 $f(n)$ 相等，则最大的 $n$ 是多少？

（5）`f2(127)` 的机器数为 `7F80 0000H`，对应的值是什么？若使 `f2(n)` 的结果不溢出，则最大的 $n$ 是多少？若使 `f2(n)` 的结果精确（无舍入），则最大的 $n$ 是多少？

> [!success]- 答案与解析
> **解析：**
>
> (I) ① i 和 n 均为 unsigned 型，循环条件  $i \leq n - 1$ 是无符号比较。n = 0 时，无符号减法 n - 1 下溢，机器数为全 1，即  $2^{32} - 1$，是 unsigned 可表示的最大值，因此  $i \leq 2^{32} - 1$ 恒真，死循环。
>
> ② 若 i、n 都改为 int 型，则不会死循环。此时 n - 1 按带符号整数运算得 -1，i = 0 时  $0 \leq -1$ 不成立。循环一次都不执行，正常退出。
>
> (2) f1(23) 与 f2(23) 返回值相等，都等于  $2^{24} - 1$。f1(23) 机器数 = 00FF FFFFFH，f2(23) 机器数 = 4B7F FFFFFH。
>
> 根据公式  $f(n) = \sum_{i=0}^{n} 2^i = 2^{n+1} - 1 = \overbrace{11 \cdots 11}^{n+1 \text{位}}$ 可知， $f(23) = 2^{23+1} - 1 = 2^{24} - 1 = \overbrace{11 \cdots 1}^{24}$。
>
> f1(23): int 型（补码）足以表示  $2^{24} - 1$（远小于 int 类型能表示的最大值  $2^{31} - 1$）其机器数为：0000 0000 1111 1111 1111 1111 1111 1111 = 00FF FFFFH。
>
> f2(23): IEEE 754 单精度浮点数格式：符号位 (1 位) + 阶码 (8 位) + 尾数 (23 位)。
>
> float 类型尾数有 23 位小数位加 1 位隐含 1，共 24 位有效位，也能精确表示 24 个 1。
>
> f2(23) 计算结果的机器数计算过程如下：
>
> ① 规格化： $2^{24} - 1 = 1.11111111111111111111111111 \times 2^{23}$（23 位尾数全为 1）；
>
> ② 阶码 e = 23，偏置值 E = 23 + 127 = 150 = 1001 0110B；
>
> ③符号位 S=0（0 表示正数，1 表示负数）；
>
> ④ 按 IEEE 754 格式拼接：
>
> $$ 1\overbrace{0}^{1位符号位}\overbrace{10010110}^{8位阶码}\overbrace{11111111111111111}^{23位尾数}=4B7F FFFFH。 $$
>
> (3)  $f(24) = 2^{25} - 1$，二进制为25个连续1。int有32位可精确表示；但float只有24位有效位，第25位为1，按“就近偶数”舍入后进位，使尾数全变为0、阶码加1，结果变成 $2^{25} = 33554432.0$。比真实值大1。故不相等。
>
> (4)  $f(31) = 2^{32} - 1$，机器数为32个1。int型最高位为符号位，全1解释为补码-1，故返回值为-1。int型能表示的最大值为 $2^{31} - 1$（32位int表示范围为 $[-2^{31}, 2^{31} - 1]$），对应f30，故使f1n与fn相等的最大n为30。
>
> $$ 7F80\ 0000H=\overbrace{0}^{1 位符号位 }\overbrace{1111\ 1111}^{8 位阶码 }\overbrace{000\ 0000\ 0000\ 0000\ 0000\ 0000B}^{23 位尾数} $$
>
> (5) ① f2 的机器数 7F80 0000H = 11 000 0000 0000 0000 0000 0000B。
>
> 在 IEEE 单浮点数标准中，用一个特殊的指数值来表示正无穷和负无穷。阶码全为 1，尾数部分全为 0，表示  $+\infty$。
>
> ②不溢出的最大 $n$：当 $n=126$ 时，$f(126)=2^{127}-1=1.1\cdots1\times2^{126}$，舍入后为 $1.0\times2^{127}$，阶码 254，是单精度最大有限值（当 $n=127$时，则舍入到阶码 255 表示$+\infty$）。故 $n$ 最大为 126。
>
> ③结果精确（无舍入）的最大n：当n=23时f23为24个1，恰好24位有效位，无需舍入；当n=24起需舍入。故最大n为23。
>
> ▷【点评】难题。以一段C语言求和代码为载体，综合考查unsigned下溢、补码解释、IEEE754单精度的阶码/尾数结构、舍入与溢出。是一道“数据表示”的经典综合题。而且，本题有5个小问，每一问都有几个得分点，分析起来费时费力。408考场上时间紧张，考场桑分析这类题会带来很大的心理压力。

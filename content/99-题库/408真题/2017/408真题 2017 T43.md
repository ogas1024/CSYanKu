## 题干

43. （13分）已知 $f(n)=\sum_{i=0}^{n}2^{i}=2^{n+1}-1=\overbrace{11\cdots11}^{n+1}\mathrm{B}$，计算 $f(n)$ 的 C 语言函数 `f1` 如下：

```c
int f1(unsigned n){
    int sum=1, power=1;
    for(unsigned i=0;i<=n-1;i++) {
        power *= 2;
        sum += power;
    }
    return sum;
}
```

将 `f1` 中的 `int` 都改为 `float`，可得到计算 $f(n)$ 的另一个函数 `f2`。

假设 `unsigned` 和 `int` 型数据都占 $32$ 位，`float` 采用 IEEE754 单精度标准。

请回答下列问题。

（1）当 $n=0$ 时，`f1` 会出现死循环，为什么？若将 `f1` 中的变量 `i` 和 `n` 都定义为 `int` 型，则 `f1` 是否还会出现死循环？为什么？

（2）`f1(23)` 和 `f2(23)` 的返回值是否相等？机器数各是什么（用十六进制表示）？

（3）`f1(24)` 和 `f2(24)` 的返回值分别为 $33\ 554\ 431$ 和 $33\ 554\ 432.0$，为什么不相等？

（4）$f(31)=2^{32}-1$，而 `f1(31)` 的返回值却为 $-1$，为什么？若使 `f1(n)` 的返回值与 $f(n)$ 相等，则最大的 $n$ 是多少？

（5）`f2(127)` 的机器数为 `7F80 0000H`，对应的值是什么？若使 `f2(n)` 的结果不溢出，则最大的 $n$ 是多少？若使 `f2(n)` 的结果精确（无舍入），则最大的 $n$ 是多少？

> [!note]- 原题截图
> ![[408真题 2017 T43.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. unsigned 的 n=0 时 n-1 下溢为 $2^{32}-1$，循环条件恒真；把 i、n 改为 int 后 n-1=-1，循环不进入。
> 2. f1(23)=f2(23)，机器数分别为 `00FFFFFFH` 和 `4B7FFFFFH`。
> 3. n=24 时浮点舍入使 f2(24) 比 f1(24) 大 1。
> 4. f1 与数学值相等的最大 n 为 30；n=31 时 int 结果为 -1。
> 5. f2 不溢出的最大 n 为 126；结果精确的最大 n 为 23。
>
> **解析：** 整数移位受 32 位范围限制；单精度只有 24 位有效精度，较大整数发生舍入，阶码全 1 则成为无穷大。

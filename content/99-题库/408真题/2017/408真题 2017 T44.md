## 题干

44. （10分）在按字节编址的计算机 M 上，题 43 中 `f1` 的部分源程序（阴影部分）与对应的机器级代码（包括指令的虚拟地址）如下图所示。

```text
int f1(unsigned n)
 1  00401020  55        PUSH EBP
    ...       ...       ...
    for(unsigned i = 0; i <= n - 1; i++)
    ...       ...       ...
20  0040105E  39 4D F4  CMP DWORD PTR [EBP-0CH], ECX
    ...       ...       ...
    { power *= 2;
    ...       ...       ...
23  00401066  D1 E2     SHL EDX,1
    ...       ...       ...
    return sum;
    ...       ...       ...
35  0040107F  C3        RET
```

其中，机器级代码行包括行号、虚拟地址、机器指令和汇编指令。

请回答下列问题。

（1）计算机 M 是 RISC 还是 CISC?为什么？

（2）`f1` 的机器指令代码共占多少字节？要求给出计算过程。

（3）第 20 条指令 `cmp` 通过 $i$ 减 $n-1$ 实现对 $i$ 和 $n-1$ 的比较。

执行 `f1(0)` 过程中，当 $i=0$ 时，`cmp` 指令执行后，进/借位标志 CF 的内容是什么？要求给出计算过程。

（4）第 23 条指令 `shl` 通过左移操作实现了 `power*2` 运算，在 `f2` 中能否也用 `shl` 指令实现 `power*2`？为什么？

> [!note]- 原题截图
> ![[408真题 2017 T44.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) M 是 CISC。理由：从给出的机器代码可见指令长度不固定（例如：55H 为 1 字节、39 4D F4 为 3 字节、D1 E2 为 2 字节、C3 为 1 字节），指令长短不一，这是 CISC 的典型特征；RISC 指令长度固定统一。
>
> (2) 第一条指令 push ebp 地址为 0040 1020H，最后一条指令 ret 地址为 0040 107FH。代码长度 = 末地址 - 首地址 + 1 = 0040 107FH - 0040 1020H + 1 = 60H = 96B。
>
> (3) cmp 指令本质是做减法并只置标志位。按题意，该 cmp 通过计算  $i - (n-1)$ 来比较 i 与 n-1。执行 f1(0) 时，n=0 且 i=0（i、n 均为 32 位无符号数）：
>
> $$ \diamond i=0=00000000H,n-1=0-1=FFFF FFFFH。 $$
>
> $$ i-(n-1)=0000\;0000H-FFFF\;FFFFH。 $$
>
> ◇ 被减数小于减数，最高位需要借位，结果 = 0000 0001H，且产生借位。cmp/sub 运算中，最高位向前有借位时 CF 置 1，故 CF = 1。
>
> (4) 不能。shl 是整数左移指令，它把整数的所有有效位作为整体左移、低位补 0，从而实现整数乘 2。但 f2 中 power 是 float 型，其机器数由符号位、阶码和尾数组成，不包含隐含的最高位 1。若整体左移，会破坏阶码与尾数的域结构，无法实现浮点数乘 2。浮点数乘 2 应通过阶码加 1（在不溢出、非规格化时）或专门的浮点乘法指令完成。 【点评】难题。结合真实汇编代码，考查 CISC / RISC 判别、指令地址与长度计算、补码减法标志位 CF 的形成、以及整型与浮点型机器数的本质差异。第 (3) 小问难度较大，另外 3 个小问相对简单。

## 题干

1. 下列函数的时间复杂度是（）。

```c
int func (int n){
    int i=0,sum=0;
    while(sum<n)
        sum += ++i;
    return i;
}
```

A. $O(\log n)$

B. $O(n^{1/2})$

C. $O(n)$

D. $O(n \log n)$

> [!note]- 原题截图
> ![[408真题 2017 T01.png]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 第 t 次后 sum=1+2+…+t=t(t+1)/2；达到 n 时 t 与 $\sqrt n$ 同阶，故复杂度为 $O(n^{1/2})$。

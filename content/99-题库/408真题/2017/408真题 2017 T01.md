## 题干

1. 下列函数的时间复杂度是（）。

```c
int func (int n){
    int i=0,sum=0;
    while(sum<n)
        sum += ++i;
    return i;
}
```

A. $O(\log n)$

B. $O(n^{1/2})$

C. $O(n)$

D. $O(n \log n)$

> [!note]- 原题截图
> ![[408真题 2017 T01.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 时间复杂度指基本语句执行次数的数量级。该函数的基本语句是“sum += ++i”，该基本语句的执行次数受到 while 循环条件“sum < n”的制约。
>
> (1) 假设语句 “sum += ++i” 共执行了 t 次，当执行到  $t+1$ 次时，“sum $\ge$ n”。
>
> (2) 当语句 “sum += ++i” 执行到第 t 次时， $i = t$， $\text{sum} = 1 + 2 + 3 + \cdots + t = \frac{t(1 + t)}{2}$。结合 (1) 的假设可得， $\text{sum} = \frac{t(1 + t)}{2} \geq n$，解得  $t = \lceil \frac{\sqrt{8n + 1} - 1}{2} \rceil$，可知  $t$ 与  $\sqrt{8n + 1}$ （即  $n^{1/2}$）同数量级，所以该程序段的时间复杂度为  $O(n^{1/2})$。故选 B。
>
> 【点评】常规题。本题和2019年408第1题相似。如今408考试中考时间复杂度时，很少再出现一眼就能看出答案题目了，需要经过一定的推导计算。

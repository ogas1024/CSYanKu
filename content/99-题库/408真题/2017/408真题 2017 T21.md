## 题干

21. I/O 指令实现的数据传送通常发生在（）。

A. I/O 设备和 I/O 端口之间

B. 通用寄存器和 I/O 设备之间

C. I/O 端口和 I/O 端口之间

D. 通用寄存器和 I/O 端口之间

> [!note]- 原题截图
> ![[408真题 2017 T21.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** I/O 指令是 CPU 执行的、用于与 I/O 端口交换数据的指令，它完成的是数据在  $\underline{CPU}$ 的通用寄存器与 I/O 端口 （接口中的数据端口寄存器）之间传送。常见的 I/O 指令有 x86 的 IN/OUT 指令，或统一编址下的访存型 I/O 指令。I/O 设备与 I/O 端口之间的数据交换由接口逻辑和外设自行完成，不需要 I/O 指令直接参与。故选 D
>
> 【点评】易错题。本题考查 I/O 端口、I/O 接口的概念，以及数据传送。综合性较强，很容易混淆，若对概念不太清晰，很容易选错。

## 题干

41. （15分）请设计一个算法，将给定的表达式树（二叉树）转换为等价的中缀表达式（通过括号反映操作符的计算次序）并输出。

例如，当下列两棵表达式树作为算法的输入时，输出的等价中缀表达式分别为 $(a+b)*(c*(-d))$ 和 $(a*b)+(-(c-d))$。

![[408真题 2017 T41-fig1.webp]]

![[408真题 2017 T41-fig2.webp]]

二叉树结点定义如下：

```c
typedef struct node{
    char data[10];    //存储操作数或操作符
    struct node *left, *right;
} BTree;
```

要求：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

> [!note]- 原题截图
> ![[408真题 2017 T41.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) 算法思想：表达式树的中序遍历序列加上必要的括号，即为等价的中缀表达式。对二叉树进行中序遍历：访问叶结点时输出操作数；访问分支结点时，在其左右子树的遍历结果之间输出操作符。关键在于括号的添加规则：根结点对应的最外层表达式不加括号；每个非根分支结点所代表的子表达式在输出时用一对括号包裹，以反映其运算优先级。叶结点是操作数，不加括号。这样既能保证运算次序正确，又不会出现多余括号。
>
> (2) 代码如下：
>
> void infix(BTree* root,int depth = 1) { //depth = 1，表示从根结点开始递归 if (root == NULL) { return; }
>
> if (root -> left == NULL && root -> right == NULL) { cout << root -> data; //对于叶子结点，直接打印，不需要添加括号 } else { //对子表达式先添加左括号 if (depth > 1) cout << "("; //depth > 1表示表达式最外层不需要加上括号 //递归方向：分解为对左子表达式 + 操作符 + 右子表达式的求解 infix(root -> left, depth + 1); //非叶结点都是操作符。加括号的操作仅对子表达式进行，所以直接输出操作符 cout << root -> data; infix(root -> right, depth + 1); if (depth > 1) cout << "("); } }
>
> ▷【真题溯源】此题不是根据 LeetCode 上的题目改编而来，而是改编自经典教材的习题：《数据结构题集》（严蔚敏、吴伟民编）第6章“树和二叉树”，题号6.51。
>
> 【点评】难题。综合考查二叉树的递归遍历框架改造。这是408考试中第2次考查二叉树遍历的算法题（2014年408第41题是首次考查二叉树的算法题，但本题难度更大）难点主要在于：①不知道在哪里加括号；②难以理解递归思想。

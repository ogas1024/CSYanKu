## 题干

41. （13分）2023年10月26日，神舟十七号载人飞船发射取得圆满成功，再次彰显了中国航天事业的辉煌成就。

载人航天工程是包含众多子工程的复杂系统工程，为了保证工程的有序开展，需要明确各子工程的前导子工程，以协调各子工程的实施。

该问题可以简化、抽象为有向图的拓扑序列问题。

已知有向图G采用邻接矩阵存储，类型定义如下。

![[408真题 2024 T41-fig1.jpg]]

请设计算法：

```c
int uniquely（MGraqh G）
```

判定 G 是否存在唯一的拓扑序列，若是，则返回 $1$，否则返回 $0$。

要求如下。

（1）给出算法的基本设计思想。

（4分）

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

(9分)

> [!note]- 原题截图
> ![[408真题 2024 T41.png]]

> [!success]- 答案与解析
> **答案：**
>
> - **（1）** 先计算所有顶点的入度。每轮必须恰有一个入度为 $0$ 的未处理顶点；选取它，将其所有后继的入度减 $1$。若某轮没有或有多个零入度顶点，则拓扑序列不唯一；若恰处理完所有顶点，则唯一。
> - **（2）**
>
> ```c
> int uniquely(MGraph G) {
>     int degree[MAXV] = {0};
>     int count = 0;
>
>     for (int i = 0; i < G.numVertices; ++i)
>         for (int j = 0; j < G.numVertices; ++j)
>             degree[j] += G.Edge[i][j] != 0;
>
>     while (count < G.numVertices) {
>         int v = -1;
>         for (int i = 0; i < G.numVertices; ++i) {
>             if (degree[i] == 0) {
>                 if (v != -1) return 0;  // 同时有多个可选顶点
>                 v = i;
>             }
>         }
>         if (v == -1) return 0;          // 存在环
>         degree[v] = -1;                 // 标记已删除
>         ++count;
>         for (int j = 0; j < G.numVertices; ++j)
>             if (G.Edge[v][j] != 0) --degree[j];
>     }
>     return 1;
> }
> ```
>
> **解析：** Kahn 拓扑排序在每一步都只有一个零入度顶点时，选择才是被唯一确定的；最终处理顶点数还可用来排除有向环。

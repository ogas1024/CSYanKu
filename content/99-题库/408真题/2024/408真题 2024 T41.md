## 题干

41. （13分）2023年10月26日，神舟十七号载人飞船发射取得圆满成功，再次彰显了中国航天事业的辉煌成就。

载人航天工程是包含众多子工程的复杂系统工程，为了保证工程的有序开展，需要明确各子工程的前导子工程，以协调各子工程的实施。

该问题可以简化、抽象为有向图的拓扑序列问题。

已知有向图G采用邻接矩阵存储，类型定义如下。

![[408真题 2024 T41-fig1.webp]]

请设计算法：

```c
int uniquely（MGraqh G）
```

判定 G 是否存在唯一的拓扑序列，若是，则返回 $1$，否则返回 $0$。

要求如下。

（1）给出算法的基本设计思想。

（4分）

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

(9分)

> [!note]- 原题截图
> ![[408真题 2024 T41.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) 算法设计思想：用数组 degree 记录每个顶点的入度，用变量 count 记录入度 0 的顶点个数，变量 index 记录入度为 0 的顶点下标。首先，遍历邻接矩阵，计算每个顶点的入度，再进行  $n$（ $n = \text{G.numVertices}$）次迭代，在每次迭代中找到并从图中移除入度为 0 的顶点，并将入度为 0 的顶点的所有邻接点的入度减去 1。在每次迭代过程中，只要图中存在多个入度为 0 的顶点，则说明不存在唯一的拓扑序列，返回 0。若迭代过程中，图中始终不存在多个入度为 0（有且仅有一个）的顶点，则表示存在唯一的拓扑序列，返回 1。
>
> (2) 算法实现如下：
>
> int uniquely(MGraph G) { //判定有向图是否存在唯一的拓扑序列 int n = G.numVertices; int degree[n] = {0}; // 图的各顶点入度初始化为0 for(int i = 0; i < n; i++) { //计算每个顶点的入度 for(int j = 0; j < n; j++) { if(G.Edge[i][j] != 0) //存在顶点i指向顶点j的边，则顶点j的入度加1 degree[j]++; } } for(int i = 0; i < n; i++) { //如下过程重复n次 int count = 0, index = -1; // 每轮迭代开始，将degree和index初始化 for(int j = 0; j < n; j++) { // 依次遍历每个顶点 if(degree[j] == 0) { // 统计入度为0的顶点个数 count++; // 入度为0的顶点个数加1 index = j; // 记录入度为0的顶点下标 } } } if(count > 1 || (-1 == index)) return 0; // 入度为0的顶点不止一个，或不存在入度为0的顶点 degree[index] = -1; // 将入度为0的顶点标记为从图中移除 for(int j = 0; j < n; j++) { if(G.Edge[index][j] != 0) { 将顶点index的邻接点j的入度减1 degree[j]++; // 更新入度 } } return 1; // 程序执行到此，说明存在唯一的拓扑排序 }
>

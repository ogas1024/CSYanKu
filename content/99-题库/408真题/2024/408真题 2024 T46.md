## 题干

46. （8分）计算机系统中的进程之间往往需要相互协作以完成一个任务。

在某网络系统中，缓冲区B用于存放一个数据分组，对B的操作有 $C_1$、$C_2$ 和 $C_3$。

$C_{1}$将一个数据分组写入B， $C_{2}$从B中读出一个数据分组， $C_{3}$对B中的数据分组进行修改。

要求B为空时才能执行 $C_{1}$，B非空时才能执行 $C_{2}$和 $C_{3}$。

请回答下列问题。

1）假设进程 P1 和 P2 均需要执行 C1，实现 C1 的代码是否为临界区？为什么？（2分）

2）假设 B 初始为空，进程 P1 执行 C1 一次，进程 P2 执行 C2 一次。

请定义尽可能少的信号量，并用 wait()、signal() 操作描述进程 P1 和 P2 之间的同步或互斥关系，说明所用信号量的作用及其初值。

（3分）

3）假设 B 初始不为空，进程 P1 和 P2 各执行 C3 一次。

请定义尽可能少的信号量，并用 wait()、signal() 操作描述进程 P1 和 P2 之间的同步或互斥关系，说明所用信号量的作用及其初值。

（3分）

> [!success]- 答案与解析
> **解析：**
>
> (1) 两个进程 P1 和 P2 都需要执行 C1，而 C1 对 B 执行写操作。同一时刻只有一个进程能对 B 执行写操作，所以 B 是临界资源，实现访问临界资源 B 的代码 C1 是临界区。
>
> (2) 由于缓冲区初始为空，所以只有进程 P1 写了之后，进程 P2 才能读，P2 的操作应该在 P1 之后。所以，进程 P1 和 P2 为同步关系，实现同步关系的信号量 S 的初值为 0。进程 P1 和 P2 之间的同步关系描述如下：
>
> | Semaphore S = 0; //实现进程 P1 与 P2 的同步 | Semaphore S = 0; //实现进程 P1 与 P2 的同步 |
> |---|---|
> | P1 | P2 |
> | ... | ... |
> | C1; | wait(S); |
> | signal(S); | C2; |
> | ... | ... |
>
> ▷【提示】这题看似简单，其实还是有坑的。坑点在于题目要求“定义尽可能少的信号量”，主要有以下2个“坑点”：
>
> ①题目说“进程P1执行C1一次，进程P2执行C2一次”，因为只执行一次，就不用设置信号量考虑进程P1和进程P2执行多次的情况；
>
> ②题目说“缓冲区B只存放一个数据分组”，就不用设置专门信号量考虑进程P1和进程P2互斥访问缓冲区B。
>
> 考场时间紧张，很有可能考虑不周，写出如下答案。
>
> 克成 •
>
> Semaphore S = 0, mutex = 1;
>
> P1 ... wait(mutex); C1; signal(S); ... P2 ... wait(S); C2; signal(mutex); ...
>
> 上面的做法功能上没问题，只是不符合题目要求“定义尽可能少的信号量”。因为进程P1和P2只执行一次，所以无需设置信号量mutex用于互斥访问B。
>
> (3) 题目已说明“B 初始不为空”，说明 B 已经有数据了，不用考虑将数据写入 B 的情况，进程 P1 和 P2 均对缓冲区 B 执行修改操作，因此要互斥访问 B。所以，进程 P1 和 P2 为互斥关系，实现互斥关系的信号量 mutex 的初值为 1。进程 P1 和 P2 之间的互斥关系描述如下：
>
> Semaphore mutex = 1; //实现 P1 与 P2 互斥执行 C3
>
> P1 ... wait(mutex); C3; signal(mutex); ... P2 ... wait(mutex); C3; signal(mutex); ...
>
> 【提示】这一问3分很简单，命题人也没在这问上设置坑点，基本是送分题。但这题是这套试卷的倒数第2题的最后一问，考生可能在送分题上也没时间拿分。
>
> ▷【点评】常规题。简单的P/V操作题目，除了解析中的第(2)问已指出的一些坑点，其他的很简单。大部分考生应该至少能得5分。

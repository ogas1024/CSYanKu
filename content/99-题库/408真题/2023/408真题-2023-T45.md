## 题干

45. （7分）现要求学生使用 swap 指令和布尔型变量 lock 实现临界区互斥。

lock 为线程间共享的变量。lock 的值为 TRUE 时线程不能进入临界区，为 FALSE 时线程能进入临界区。某同学编写的实现临界区互斥的伪代码如下：

```c
bool lock = FALSE; // 共享变量
……
bool key = TRUE;
if (key == TRUE)
    swap key, lock; // 交换 key 和 lock 的值
临界区；
lock = TRUE; // 退出区
……
```

（a）

（1）图（a）的伪代码中哪些语句存在错误？将其改为正确的语句（不增加语句条数）。

（2）图（b）给出了交换两个变量值的函数 newSwap() 的代码，是否可以用函数调用语句 `newSwap(&key,&lock)` 代替指令 `swap key,lock`，以实现临界区的互斥？为什么？

```c
void newSwap(bool *a, bool *b) {
    bool temp = *a;
    *a = *b;
    *b = temp;
}
```

（b）

> [!note]- 原题截图
> ![[408真题-2023-T45.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 进入区应把 `if (key == TRUE) swap(key, lock)` 改为 `while (key == TRUE) swap(key, lock)`；退出区应把 `lock = TRUE` 改为 `lock = FALSE`。
> 2. 不能。`newSwap()` 接收共享变量 `lock` 的地址，内部读写不是不可分割的原子交换；并发切换时可能使两个线程都进入临界区。
>
> **解析：** 互斥锁为 TRUE 时线程必须持续自旋，退出临界区则释放锁。用普通读写模拟 swap 会在读、写之间暴露竞态，无法保证互斥。

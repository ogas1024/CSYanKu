## 题干

22. 下列关于 I/O 控制方式的叙述中，错误的是（）。

A. 查询方式下，通过 CPU 执行查询程序进行 I/O 操作

B. 中断方式下，通过 CPU 执行中断服务程序进行 I/O 操作

C. DMA 方式下，通过 CPU 执行 DMA 传送程序进行 I/O 操作

D. 对于 SSD、网络适配器等高速设备，采用 DMA 方式输入/输出

> [!note]- 原题截图
> ![[408真题 2023 T22.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** DMA 是一种特殊的 I/O 控制方式，它允许外设直接与主存进行数据传输。DMA 数据传输过程由硬件（DMA 控制器）完成，无需 CPU 的干预，CPU 仅在 DMA 预处理和 DMA 后处理阶段介入。故 C 错。
>
> 【点评】常规题。考查 I/O 控制方式相关的基本概念，即使考生对本题 D 选项稍感陌生，但 C 选项的错误很明显，基本属于送分题。

## 题干

41. （13 分）二叉树的带权路径长度（WPL）是二叉树中所有叶结点的带权路径长度之和。

给定一棵二叉树 $T$，采用二叉链表存储，其结点结构为：

| `left` | `weight` | `right` |
| --- | --- | --- |

其中叶结点的 `weight` 域保存该结点的非负权值。

设 `root` 为指向 $T$ 的根结点的指针，请设计求 $T$ 的 WPL 的算法，要求：

1. 给出算法的基本设计思想。

2. 使用 C 或 C++ 语言，给出二叉树结点的数据类型定义。

3. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

> [!note]- 原题截图
> ![[408真题 2014 T41.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) 算法的基本设计思想：①二叉树的带权路径长度（WPL）是树中所有叶结点的带权路径长度之和。叶结点的带权路径长度 = 该叶结点的权值 × 根结点到该叶结点的路径长度（路径上的边数），其中叶结点的权值存储在结点结构体的 weight 成员中。
>
> ②求解时，可通过“任意一种二叉树的遍历算法”（本题采用中序遍历）统计每个叶结点的路径长度：遍历时维护一个变量h，二叉树每向下一层深度h加1，每回溯一层深度h减1（如果用层序遍历算法则不用回溯）；遇到叶结点时，用其权值weight与当前深度h相乘并累加到总和WPL中。遍历完整棵二叉树即可求得WPL。
>
> (2) 二叉树结点的数据类型定义如下：
>
> typedef struct BiTNode { int weight; struct BiTNode *left, *right; } BiTNode, *BiTree;
>
> (3) C 语言算法代码实现如下：
>
> void InOrderCalWPL(BiTNode *T,int h,int *wpl) { if(T == NULL) { return ; // 空结点，递归直接返回 } InOrderCalWPL(T->left, h+1, wpl); // 递归遍历左子树，下层深度+1 if(T->left == NULL && T->right == NULL) {
>
> *wpl += T->weight * h; // 计算叶结点的带权路径长度 }
>
> InOrderCalWPL(T->right, h+1, wpl); // 递归遍历右子树，下层深度+1
>
> int GetTreeWPL(BiTree root) { //函数调用入口，输入根指针，返回树的WPL int wpl = 0; // 初始化wpl为0 InOrderCalWPL(root, 0, &wpl); // 根结点初始深度为0 return wpl; }
>
> ▲【注意】在子函数 InOrderCalWPL() 中，形参 wpl 必须定义成指针，否则就是错的。或者通过引用传参也行。考生若不熟悉 C 语言函数的形参和实参，或者 C++ 中的引用，建议去看下竟成《数据结构考研复习全书》第 1 章【编程基础】部分（在该章 1.5 小节），该章对 408 考试中所需要的前置的编程基础知识进行了补充介绍，助力考生 0 基础入门 408。

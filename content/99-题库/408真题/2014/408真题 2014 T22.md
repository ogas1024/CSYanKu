## 题干

22. 若某设备中断请求的响应和处理时间为 100 ns，每 400 ns 发出一次中断请求，中断响应所允许的最长延迟时间为 50 ns，则在该设备持续工作过程中，CPU 用于该设备的 I/O 时间占整个 CPU 时间的百分比至少是（）。

A. 12.5%

B. 25%

C. 37.5%

D. 50%

> [!note]- 原题截图
> ![[408真题 2014 T22.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** ① CPU 用于该设备的 I/O 时间：“中断请求的响应和处理时间为 100ns”，这就是 CPU 用于该设备的 I/O 时间。② 中断请求周期：设备每 400ns 发起一次中断请求，也就是每隔 400ns，CPU 就要花费 100ns 处理该设备的中断（其余 400ns-100ns = 300ns，CPU 不是在服务该设备）。CPU 用于该设备的 I/O 时间占比 =  $\frac{CPU 用于该设备的 I/O 时间}{中断请求周期} = \frac{100ns}{400ns} = 25\%$。故选 B。
>
> ▶【提示】题目中“中断响应所允许的最长延迟时间为 50ns”，这句话如何理解，是本题最大的难点。中断响应延迟指：从设备发出中断请求到 CPU 响应和处理该设备发出的中断请求所经过的时间。产生中断响应延迟的原因可能是：CPU 正在执行一段不可打断的原子指令、或 CPU 正在处理更高优先级中断，只能等当前操作结束后才能响应该设备发出的中断。在中断响应延迟的这段时间内， **CPU 在运行其他程序（不是在服务该设备）**、不属于给本设备服务的 I/O 时间。例如：在一个完整周期 400ns 的时间里，若该设备在第 0ns 发出中断请求，此时 CPU 被其他程序占用、无法响应中断。第 40ns～140ns：CPU 花 100ns 响应和处理该设备中断请求（服务该设备）。第 140ns～400ns：CPU 继续运行其他程序。该设备的 I/O 时间占比 = 100ns ÷ 400ns = 25%。在这个例子中，第 0ns～40ns 就是“中断响应延迟”（40ns，不超过最大延迟时间 50ns）。
>
> 【点评】概念题。本题对中断响应的过程考的深入且细致。本题难点在于：“中断响应所允许的最长延迟时间为 50ns”，这个干扰信息极具迷惑性，容易造成误选。

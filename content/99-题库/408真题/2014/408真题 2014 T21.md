## 题干

21. 下列有关 I/O 接口的叙述中，错误的是（）。

A. 状态端口和控制端口可以合用同一个寄存器

B. I/O 接口中 CPU 可访问的寄存器称为 I/O 端口

C. 采用独立编址方式时，I/O 端口地址和主存地址可能相同

D. 采用统一编址方式时，CPU 不能用访存指令访问 I/O 端口

> [!note]- 原题截图
> ![[408真题 2014 T21.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** A 正确：为节省 I/O 接口芯片的面积和引脚，状态端口与控制端口通常可合用同一寄存器，这也是实际设计中的常见做法。例如，寄存器中的某些位只读（用作状态位），另一些位只写（用作控制位），两者互不干扰。B 正确：I/O 接口中供 CPU 读写访问的寄存器（数据寄存器、状态寄存器、控制寄存器等）统称为 I/O 端口。
>
> C 正确：独立编址指主存和 I/O 端口使用两套完全独立、互不干涉的地址空间，主存地址和 I/O 端口地址各自独立编码。CPU 提供专门的 I/O 访问指令（例如：IN / OUT 指令），访存指令无法访问 I/O 端口。独立编址需在硬件上增设专门的 I/O 读写控制信号，和主存读写信号分开。其优点是 I/O 专用指令短小，执行速度更快，且内存与 I/O 控制逻辑互不干扰。其缺点是 CPU 必须额外实现一套 I/O 指令，硬件需要额外译码与控制信号线。
>
> D 错误：统一编址指将 I/O 端口寄存器和主存单元放在同一个地址空间内统一分配地址，I/O 端口被视作一块特殊的主存单元。其优点是：
>
> 地址共享：主存地址和 I/O 端口地址共享同一地址空间。
>
> 指令共用：CPU 使用普通访存指令（LOAD/STORE、MOV 等）读写 I/O 端口，无需专用 I/O 指令集。
>
> 简化硬件设计：不需要区分内存与 I/O 的读写控制信号，控制逻辑简单。
>
> 其缺点是：I/O 端口占用部分主存地址空间，访存指令长度更长，I/O 操作速度略慢。故选 D。
>
> 【点评】概念题。考查 I/O 接口和 I/O 端口的相关常见易混概念。

## 题干

45. （11 分）假设对于 44 题中的计算机 M 和程序 P 的机器代码，M 采用页式虚拟存储管理；

P 开始执行时，$(R1)=(R2)=0$，$(R6)=1000$，其机器代码已调入主存但不在 Cache 中；

数组 A 未调入主存，且所有数组元素在同一页，并存储在磁盘同一个扇区。

请回答下列问题并说明理由。

1. P 执行结束时，R2 的内容是多少？

2. M 的指令 Cache 和数据 Cache 分离。

若指令 Cache 共有 16 行，Cache 和主存交换的块大小为 32 字节，则其数据区的容量是多少？若仅考虑程序段 P 的执行，则指令 Cache 的命中率为多少？

3. P 在执行过程中，哪条指令的执行可能发生溢出异常？哪条指令的执行可能产生缺页异常？对于数组 A 的访问，需要读磁盘和 TLB 至少各多少次？

> ![[408真题 2014 T45.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) 常量 N 保存在寄存器 R6 中，故  $\mathrm{N} = (\mathrm{R}6) = 1000$。当程序 P 执行结束时，跳出 for 循环，此时  $i = \mathrm{N} = (\mathrm{R}6) = 1000$。变量 i 保存在寄存器 R2 中，故 R2 的内容是 1000。
>
> (2) ① 由于 Cache 有 16 行，每行的大小为 32B，所以 Cache 数据区容量 = 16 × 32B = 512B。② 由于程序 P 有 6 条指令，总共占 6 × 4B = 24B < 32B，所以 P 的所有指令都在同一块主存块中。在 1000 次循环中，每次循环读取 6 条指令。在第一次循环读取第一条指令时，由于程序 P 所在的主存块还没有调入 Cache 中，发生 Cache 缺失，操作系统将程序 P 所在主存块调入 Cache 块中，此后每次读取指令时 Cache 都能命中。Cache 命中率 =  $\frac{1000 \times 6 - 1}{1000 \times 6} \approx 99.98\%$。
>
> (3) ① 编号为 4 的指令执行 “sum += A[i]” 操作，可能会因为 sum 的值过大而发生溢出异常。
>
> ②编号为3的指令是访存指令，可能会发生缺页异常。
>
> ③ 第一次访问数组 A 时，会先查一次 TLB，由于数组 A 初始未调入主存，所以发生缺页，要从磁盘上读取数组 A，因为数组 A 存储在磁盘的同一扇区中，只需要读 1 次磁盘。
>
> ④当缺页异常处理完后，CPU会重新执行触发异常的指令，会查一次TLB。此后访问A[1]～A[999]时，每访问一个数组元素会查一次TLB，访问TLB的总次数=1+1+999=1001。
>
> ▷【提示】★①缺页异常处理完后， **重新执行被中断的指令**，所以必须“再查一次TLB”。②Cache缺失（不命中）处理完后， **不需要再访问一次Cache**。因为Cache缺失是纯硬件自动处理，此过程对CPU来说是透明的（即：CPU感知不到Cache缺失的处理过程）。Cache缺失的完整处理过程是：CPU发出一个物理地址→Cache缺失→硬件读取主存块送入Cache→数据交给CPU（从主存中取或从Cache中取）→指令继续执行。
>
> ③ Cache 缺失后，现代主流通用 CPU 都是将缺失的主存块写入 Cache 的同时，将所需数据送往 CPU。在早期 CPU 设计中，查 Cache 标记发现 Cache 缺失后，先读取主存数据块写入 Cache 块，再从 Cache 块中读取所需数据送往 CPU，这个过程（先查 Cache 标记 → 写入 Cache 块 → 从 Cache 块中取数据送 CPU）属于  $\underline{\text{Cache 的内部读写}}$，不改变外部访问 Cache 的计数，所以这个过程属于“一次访问 Cache”，不是两次访问 Cache，这点很容易混淆。
>
> 【点评】常规题。本题属于计组大题最简单的一类考法之一。

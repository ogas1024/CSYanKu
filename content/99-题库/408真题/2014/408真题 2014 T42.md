## 题干

题 42 图 R1 构造的网络拓扑

请回答下列问题。

1. 本题中的网络可抽象为数据结构中的哪种逻辑结构？

2. 针对题 42 表中的内容，设计合理的链式存储结构，以保存题 42 表中的链路状态信息（LSI）。

要求给出链式存储结构的数据类型定义，并画出对应题 42 表的链式存储结构示意图（示意图中可仅以 ID 标识结点）。

3. 按照迪杰斯特拉（Dijkstra）算法的策略，依次给出 R1 到达题 42 图中子网 `192.1.x.x` 的最短路径及费用。

> [!note]- 原题截图
> ![[408真题 2014 T42.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) 本题中的网络可抽象为图结构。
>
> 【提示】408 考试涉及的逻辑结构主要是3种：“线性结构”、“树形结构”和“图形结构”。本题很明显是图结构。看题目图形也能猜出来，这一问基本是送分的。
>
> (2) ① 链式存储结构的数据类型定义如下：
>
> typedef struct { unsigned int ID; unsigned int IP;
>
> 如何存储小数点呢？IPv4 地址在计算机中，存的是 32 位二进制（0/1）比特串，点分十进制（例如 10.1.1.1）只是为了方便人类书写阅读而进行的格式化表示，计算机本身不识别小数点。③ArcNode 结构体定义时用到了 C 语言中的 union 类型。可能有考生不熟悉，建议自行回顾 union 类型语法。union 中多个成员共享同一片内存，同一时刻只能有一个成员有效。ArcNode 中通过 Flag 来标记 LinkORNet（union 类型）中哪个成员有效。计算结果如下表所示。
>
> |  | 目的网络 | 路径 | 代价（费用） |
> |---|---|---|---|
> | 步骤1 | 192.1.1.0/24 | 直接到达 | 1 |
> | 步骤2 | 192.1.5.0/24 | R1→R3→192.1.5.0/24 | 3 |
> | 步骤3 | 192.1.6.0/24 | R1→R2→192.1.6.0/24 | 4 |
> | 步骤4 | 192.1.7.0/24 | R1→R2→R4→192.1.7.0/24 | 8 |
>
> 【提示】①题目问“R1到达上图中子网192.1.x.x的最短路径及费用”，题目中给出的4个子网192.1.1.0/24、192.1.5.0/24、192.1.6.0/24、192.1.7.0/24都是192.1.x.x这种格式，所以，题目意思就是“ **问路由器R1到达图中4个子网的最短路径及费用**”，“题目这里卖了个关子”，可能很多同学卡在这里，不知道题目表达的是什么意思。但如果题目直接问“R1到达图中4个子网的最短路径及费用”，此题的难度又大大降低，就太简单了。②题目要求用Dijkstra算法策略求最短路径。目的是求最短路径，Dijkstra算法只是求最短路径的一种方法而已，无论用哪种方法，最终求的最短路径都一样。所以，考场上时间紧张，Dijkstra算法推导最短路径过程较为复杂费时间，本题的网络拓扑简单，直接“人工肉眼”就可以看出路由器R1到达图中各个子网的最短路径。
>
> ▷【点评】难题。 $^{①}$本题是本套试卷中难度最大的一个题。大部分同学在考场上、本题应该只有第(1)问能得2分。本题最大的难点在于“理解题意”，考场上时间紧张，一眼看到此题阅读量这么大，描述的背景又很陌生，一眼看下去没有思路，很有可能就慌了。
>
> ②本题以计算机网络的知识为背景，第(2)问难度最大，其实是在“邻接表”的基础上拓展的。这里也提醒考生， $\underline{\text{邻接矩阵、邻接表、多重邻接表、十字链表的数据结构定义，要能动手默写}}$。
>
> ③本题的难点其实不在具体的知识点掌握层面，最难点在于理解题意。本题给出的R1的链路状态信息表，信息看起来很杂乱，很多考生应该也是首次接触OSPF路由协议具体的链路状态信息，天然的陌生感。但题目为了降低难度，在“备注”栏进行了提示。其实，题目给出的链路状态信息（LSI）是贴合OSPF原生规范的应试简化版本。OSPF协议里，点对点链路固定的两个关键字段LinkID和LinkData，正好对应表格里的ID和IP列：
>
> ◇ Link ID 取值是下一跳的 IP，作用是在拓扑层面 **定位邻居路由器**。
>
> ◇ Link Data 取值是本地接口 IP，作用是路由计算完成后，确定 IP 数据包的转发接口。
>
> 例如，以下是一段思科或华为设备的真实 OSPF 链路状态（LSA）报文：
>
> Link connected to: another Router (point-to-point) (Link ID) Neighboring Router ID: 10.1.1.2 ← 对应题目 ID 列 (Link Data) Local Interface IP address: 10.1.1.1 ← 对应题目 IP 列 Metric: 3
>
> ④客观的说，很难评价此题出的好或者不好。但此题给阅卷带来极大的不便：第（2）问万千考生的手写代码命名可能“五花八门”、示意图可能画的“鬼画桃符”，增加了阅卷的工作量、影 响阅卷的准确性。而且，考场上答题卡空间有限，第(2)问答题空间很有可能不够。而且，即使此题能完整做出来，也将耗费大量时间（从形成思路到完整在答题卡上写出来至少要20分钟），影响后续其他题目的作答时间，本套试卷除了本题，其他题目还是挺常规的。
>
> ⑤有一个很现实的问题：如何才能做对本题？或者说尽可能的拿分呢？其实，从过来人的角度来看，我的建议是“适度放弃”。本题第(1)问是送分题，第(3)问也相对简单，但第(2)问即使会做，也非常耗时，考场上时间紧张， $\underline{\text{“死磕”第(2)问得不偿失}}$，后面简单容易拿分的题就没时间做了。所以，放弃本题第(2)问、第(1)问和第(3)问做对，本题拿一半分是最优解。408考试是选拔性考试，每套试卷中都会有一些区分度高的难题。考生的目标应该是 $\underline{\text{“总分值最大化”}}$，不要在一些难题上“死磕到底”。先把容易拿分的题做了，难题等会做的题都做完了再做。
>
> ⑥本题在命制上也存在“考虑不周”之处：本题当年的得分率应该极低的，第(2)问即使会做也太费时间。这体现早些年408命题不规范不成熟（此题应该没人真正动手做一遍，或者是看着答案做题的）。而且在2009～2026这18年408考试中，这是 **唯一**一次出此类题。

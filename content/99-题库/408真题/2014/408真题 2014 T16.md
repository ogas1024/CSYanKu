## 题干

16. 采用指令 Cache 与数据 Cache 分离的主要目的是（）。

A. 降低 Cache 的缺失损失

B. 提高 Cache 的命中率

C. 降低 CPU 平均访存时间

D. 减少指令流水线资源冲突

> [!note]- 原题截图
> ![[408真题 2014 T16.png]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 分离指令 Cache 和数据 Cache 可使取指与取数同时访问不同 Cache，从而减少流水线结构冲突，故 D。

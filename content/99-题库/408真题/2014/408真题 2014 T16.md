## 题干

16. 采用指令 Cache 与数据 Cache 分离的主要目的是（）。

A. 降低 Cache 的缺失损失

B. 提高 Cache 的命中率

C. 降低 CPU 平均访存时间

D. 减少指令流水线资源冲突

> [!note]- 原题截图
> ![[408真题 2014 T16.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 指令 Cache 与数据 Cache 分离时，在指令流水线中，取指令阶段访问指令 Cache，执行阶段访问数据 Cache。采用两套独立存储、两套独立访问通路， **取指令和读写数据可同时并行访问各自 Cache**，消除端口争抢，减少流水线资源冲突。
>
> 若指令、数据共用同一个 Cache，在指令流水线中，同一时钟周期内取指令和读写数据会争抢唯一的 Cache 访问端口，引发资源冲突、造成流水线停顿。故选 D。
>
> ◇ A 选项：Cache 缺失损失主要取决于主存速度、替换策略等。
>
> B 选项：Cache 分离后，指令 Cache 和数据 Cache 各自容量减半，反而可能降低命中率。这是分离式设计的一个代价，而非目的。
>
> C选项：Cache分离后可能因命中率下降而增加访存时间。
>
> 【拓展】①“冯·诺依曼架构”的核心设计思想是“存储程序”，指令和数据以同等地位存于同一存储器。即：指令和数据共享同一存储空间和总线。其优点是结构简单、成本低、通用性强，其缺点是取指令和访存操作无法并行执行，存在理论层面的访存冲突瓶颈（现代CPU通过Cache等技术已大幅缓解）。
>
> ②“哈佛架构”的核心设计思想是指令和数据分开存储，并且各自拥有独立的存储器（指令存放在程序存储器中，数据存放在数据存储器）和总线。其优点是可同时取指令、读写数据，并行执行（适合流水线），吞吐率高。缺点是硬件复杂度高、 $\underset{\cdot}{不}\underset{\cdot}{支}\underset{\cdot}{持}$程序自我修改（因为“哈佛架构”程序必须预先固化在指令ROM中）和动态加载（指程序运行时，才把代码从外存调入内存执行），难以运行现代通用操作系统。
>
> ③ “改进型哈佛架构”是上述两种架构的折中方案：在CPU内部指令Cache和数据Cache分离，在CPU外部指令和数据统一存储。 **“改进型哈佛架构”兼顾性能与灵活性，是现代CPU的事实标准，目前主流的手机CPU（例如：高通骁龙、联发科、苹果A系列和M系列）都是采用“改进型哈佛架构”**。
>
> 【点评】常规题。本题考查“哈佛架构”的设计思想。

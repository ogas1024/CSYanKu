## 题干

1. 下列程序段的时间复杂度是（）。

```c
count = 0;
for (k = 1; k <= n; k *= 2)
    for (j = 1; j <= n; j++)
        count++;
```

A. $O(\log_2 n)$

B. $O(n)$

C. $O(n \log_2 n)$

D. $O(n^2)$

> [!note]- 原题截图
> ![[408真题 2014 T01.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 外层循环“for(k = 1; k <= n; k * = 2)”的执行是  $[\log_2 n]$。内存循环“for(j = 1; j <= n; j++)”，每次执行  $n$ 次。时间复杂度是基本语句执行次数的数量级。本题的基本语句是“count++”，其执行次数为： $n[\log_2 n]$。故时间复杂度为  $O(n\log_2 n)$。故选 C。
>
> 【点评】常规题。常规的考查时间复杂度的题目。

## 题干

1. 下列程序段的时间复杂度是（）。

```c
count = 0;
for (k = 1; k <= n; k *= 2)
    for (j = 1; j <= n; j++)
        count++;
```

A. $O(\log_2 n)$

B. $O(n)$

C. $O(n \log_2 n)$

D. $O(n^2)$

> [!note]- 原题截图
> ![[408真题 2014 T01.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 把内层循环按外层 k 的各个取值展开，每层均执行 n 次；外层幂次最多为 $\log_2 n$，总时间为 $O(n\log n)$，故 C。

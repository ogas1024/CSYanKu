## 题干

47. （9 分）系统中有多个生产者进程和多个消费者进程，共享一个能存放 1000 件产品的环形缓冲区（初始为空）。

当缓冲区未满时，生产者进程可以放入其生产的一件产品，否则等待；

当缓冲区未空时，消费者进程可以从缓冲区取走一件产品，否则等待。

要求一个消费者进程从缓冲区连续取出 10 件产品后，其他消费者进程才可以取产品。

请使用信号量 P、V（或 `wait()`、`signal()`）操作实现进程间的互斥与同步，要求写出完整的过程，并说明所用信号量的含义和初值。

> [!note]- 原题截图
> ![[408真题 2014 T47.webp]]

> [!success]- 答案与解析
> **解析：**
>
> 本题改编自经典的生产者－消费者问题。 $^{①}$ 定义互斥信号量 mutex_consumer，用于实现在一个消费者进程进入缓冲区，且尚未取出 10 件产品之前，其他消费者进程不可以进入缓冲区取产品； $^{②}$ 定义互斥信号量 mutex_buffer，用于实现对缓冲区的互斥访问； $^{③}$ 定义信号量 empty 和 full，分别表示缓冲区的空位数和已存放的产品数量。伪代码描述如下：
>
> semaphore mutex_consumer = 1; //实现消费者进程之间的互斥操作 semaphore mutex_buffer = 1; //实现对缓冲区的互斥访问 semaphore empty = 1000; //缓冲区可用空位数量 semaphore full = 0; //缓冲区已存放的产品数量
>
> 生产者进程
>
> while(1){ 生产一件产品； P(empty); //占用一个缓冲区，如剩余容量不足则等待 P(mutex_buffer); //（互斥）阻止他人访问缓冲区 把产品放入缓冲区； V(mutex_buffer); //（互斥）允许他人访问缓冲区 V(full); //（同步）缓冲区的已用容量加1 }
>
> 消费者进程
>
> while(1){ P(mutex_consumer); //申请进入缓冲区取走10件产品 for(int i = 0; i < 10; i++) { //用这个循环描述连续取走10件 P(full); // 申请从缓冲区取走一件产品，若缓冲区为空则等待 P(mutex_buffer); //（互斥）阻止他人访问缓冲区 从缓冲区取走一件产品； V(mutex_buffer); //（互斥）允许他人访问缓冲区 V(empty); //缓冲区空位+1 }
>
> V(mutex_consumer); //从缓冲区连续取走10件产品后，其他消费者可取产品
>
> ▷【提示】★①上述伪代码实现中，默认生产者和消费者不能同时访问缓冲区（经典的“生产者-消费者”问题也是这样要求的）。但本题官方给出的参考答案中，默认生产者和消费者可以同时访问缓冲区。而且，本题也未明确说明：“生产者和消费者是否可以同时访问缓冲区”，所以，两种写法都可以。而且，更推荐我们这里的这种写法。
>

>
> 【点评】常规题。本题根据教材上常见的“生产者-消费者”问题改编，主要改编点在于加了约束条件“一个消费者进程从缓冲区 $\underline{\text{连续}}$取走10件产品”，考查灵活运用。根据经典例题改编，此类考查方向，变种很多，且“死记硬背”没有用，需要考生平时多练习（提高熟练度），多见一些题型（开拓视野），多积累总结，增进理解。

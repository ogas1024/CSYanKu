## 题干

45. （8 分）某银行提供 $1$ 个服务窗口和 $10$ 个供顾客等待的座位。

顾客到达银行时，若有空座位，则到取号机上领取一个号，等待叫号。

取号机每次仅允许一位顾客使用。

当营业员空闲时，通过叫号选取一位顾客，并为其服务。

顾客和营业员的活动过程描述如下：

```text
cobegin
{
    process 顾客 i
    {
        从取号机获取一个号码;
        等待叫号;
        获取服务;
    }
    process 营业员
    {
        while (TRUE)
        {
            叫号;
            为客户服务;
        }
    }
}
coend
```

请添加必要的信号量和 P、V（或 `wait()`、`signal()`）操作，实现上述过程中的互斥与同步。

要求写出完整的过程，说明信号量的含义并赋初值。

> [!note]- 原题截图
> ![[408真题 2011 T45.webp]]

> [!success]- 答案与解析
> **解析：**
>
> ①定义同步信号量 call_custom，初始为 0，实现顾客与营业员之间叫号的同步；②定义互斥信号量 mutex，初始为 1，实现对取号机这一互斥资源的互斥访问；③定义一对信号量 seats_empty = 10 和 seats_full = 0，分别表示空余座位数和已用座位数，有空余座位才可落座。具体实现如下：
>
> semaphore seats_empty = 10; // 空座位数量，初始为10 semaphore seats_full = 0; // 座位的已用数量 semaphore mutex = 1; // 实现对取号机这一互斥资源的互斥访问 semaphore call_custom = 0; // 实现顾客与营业员之间叫号的同步 CoBegin { process 顾客i { P(seats_empty); // 申请空座位 P(mutex); // (互斥) 防止他人使用取号机 从取号机获取一个号码; V(mutex); // (互斥) 允许他人使用取号机 V(seats_full); // (同步) 通知营业员，有顾客在等待被服务 P(call_custom); // (同步) 等待营业员叫号 获取服务; } process 营业员 { while (TRUE) { P(seats_full); // (同步) 若没有顾客在等待被服务，则营业员休息叫号; V(call_custom); // (同步) 通知顾客，已被叫号 V(seats_empty); // 顾客去服务窗口，释放一个座位，空座位数量加为顾客服务; } } } CoEnd
>
> ▷【提示】①P/V题有一个基本思路是：先找出同步或互斥关系，同步关系信号量初值为0；互斥关系，信号量初值为1。②此题是较难的一类P/V题，是经典P/V场景的变式，考生如果感觉无从下手，在竟成《操作系统考研复习全书》进程同步小节中、有大量的各类P/V题，考生可强化练习。
>
> ▷【点评】常规题。本题是经典的P/V操作题，不同于哲学家进餐、读写者等套路强的题，此类经典P/V做题套路性不强、灵活性高，这也是它的难点所在。操作系统的P/V操作题类似数据结构的算法题，需要考生多加练习，保持手感。

## 题干

42. （15 分）一个长度为 $L$（$L\geq1$）的升序序列 $S$，处在第 $\lfloor L/2\rfloor$ 个位置的数称为 $S$ 的中位数。

例如，若序列 $S_1=(11,13,15,17,19)$，则 $S_1$ 的中位数是 $15$。两个序列的中位数是含它们所有元素的升序序列的中位数。

例如，若 $S_2=(2,4,6,8,20)$，则 $S_1$ 和 $S_2$ 的中位数是 $11$。

现在有两个等长升序序列 $A$ 和 $B$，试设计一个在时间和空间两方面都尽可能高效的算法，找出两个序列 $A$ 和 $B$ 的中位数。

要求：

（1）给出算法的基本设计思想。
（2）根据设计思想，采用 C、C++ 或 Java 语言描述算法，关键之处给出注释。
（3）说明你所设计算法的时间复杂度和空间复杂度。

> [!success]- 答案与解析
> **解析：**
>
> (1) A 和 B 是等长（记长度为 n）的升序序列，求出序列 A 的中位数  $A_{m}$，序列 B 的中位数  $B_{m}$。设 S 为序列 A 和 B 合并后升序序列，关于 S 的中位数，有如下 3 种情况：
>
> 长度为 n 的升序序列  $A = \overbrace{A_0, A_1, \cdots, A_{m-1}}^{n-1-\lfloor n/2\rfloor} \overbrace{A_m}^{1} \overbrace{A_{m+1}, A_{m+2}, \cdots, A_{n-1}}^{[n/2]} \overbrace{B_0, B_1, \cdots, B_{m-1}}^{n-1-\lfloor n/2\rfloor} \overbrace{B_m}^{1} \overbrace{B_{m+1}, B_{m+2}, \cdots, B_{n-1}}^{[n/2]}$
>
> 若  $A_{m}=B_{m}$，则  $A_{m}$ 即为所求中位数。
>
> 若  $A_m < B_m$，则  $A_0 \sim A_{m-1} < A_m < B_m < B_{m+1} \sim B_{n-1}$。 $A_0 \sim A_{m-1}$ 是 S 中最小的部分（S 中最靠前 [n/2] 个元素）， $B_{m+1} \sim B_{n-1}$ 是 S 中最大的部分（S 中最靠后的 [n/2] 个元素），而中位数位于 S 中第 [2n/2] = n 个位置，故中位数位于序列  $A_{m+1} \sim A_{n-1}, B_0 \sim B_{m-1}$ （长度为 n）中。而  $A_{m+1} \sim A_{n-1}$ 和  $B_0 \sim B_{m-1}$ 都是升序序列。将问题转化为求跟原来等价但规模更小的同类问题。
>
> ◇ 若  $A_m > B_m$，则  $B_0 \sim B_{m-1} < B_m < A_m < A_{m+1} \sim A_{n-1}$。同理，则中位数位于序列  $A_0 \sim A_{m-1}$， $B_{m+1} \sim B_{n-1}$（长度为  $n$）中。
>
> 重复此过程，直到两个序列中位数相等或两个序列中都只含一个元素时为止，较小者即为所求中位数。
>
> (2) 代码实现如下：
>
> int middle(int A[], int B[], int n) { int start1 = 0, end1 = n-1, start2 = 0, end2 = n-1, m1, m2; while (start1 != end1 || start2 != end2) { m1 = (start1 + end1)/2, m2 = (start2 + end2)/2; if (A[m1] == B[m2]) return A[m1]; if (A[m1] < B[m2]) { if ((start1 + end1) % 2 == 0) { // 说明序列长度n为奇数 start1 = m1; end2 = m2; } else { // 说明序列长度n为偶数 start1 = m1 + 1; end2 = m2; } } if (A[m1] > B[m2]) { if ((start1 + end1) % 2 == 0) { // 说明序列长度n为奇数 end1 = m1; start2 = m2; } else { // 说明序列长度n为偶数 end1 = m1; start2 = m2 + 1;
>
> } } return A[start1] < B[start2] ? A[start1] : B[start2];
>
> (3) 时间复杂度为  $O(\log_{2}n)$，空间复杂度  $O(1)$。
>

>
> https://leetcode.cn/problems/median-of-two-sorted-arrays
>
> 【提示】本题还有一种容易想到的暴力解思路，该思路跟二路归并排序算法思想一致：设两个等长升序序列为 A 和 B，长度均为 n。将 A、B 合并，合并后的序列长度为 2n，根据题目定义，中位数是第  $[2n/2] = n$ 个位置的元素（即从小到大排序后的第 n 小元素）。

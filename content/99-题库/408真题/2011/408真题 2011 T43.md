## 题干

43. （11 分）假定在一个 $8$ 位字长的计算机中运行如下 C 程序段：

```c
unsigned int x=134;
unsigned int y=246;
int m=x;
int n=y;
unsigned int z1=x-y;
unsigned int z2=x+y;
int k1=m-n;
int k2=m+n;
```

若编译器编译时将 $8$ 个 $8$ 位寄存器 R1～R8 分别分配给变量 `x`、`y`、`m`、`n`、`z1`、`z2`、`k1` 和 `k2`。

请回答下列问题（提示：带符号整数用补码表示）。

（1）执行上述程序段后，寄存器 R1、R5 和 R6 的内容分别是什么（用十六进制表示）？
（2）执行上述程序段后，变量 `m` 和 `k1` 的值分别是多少（用十进制表示）？
（3）上述程序段涉及带符号整数加/减、无符号整数加/减运算，这四种运算能否利用同一个加法器辅助电路实现？简述理由。
（4）计算机内部如何判断带符号整数加/减运算的结果是否发生溢出？上述程序段中，哪些带符号整数运算语句的执行结果会发生溢出？

> [!success]- 答案与解析
> **解析：**
>
> (1) ① 无符号整数 x = 134 = 10000110B = 86H，R1 中存放无符号整数 x 的机器数，故  **R1 的内容为 86H**。
>
> ②关于无符号数减法，这里用2种方法求解：
>
> ◇ 人类视角：n 位无符号数减法计算公式为  $x - y = (x + (2^n - y)) \mod 2^n$。 $x - y = (134 + (2^8 - 246)) \mod 2^8 = 144\% 256 = 144 = 10010000\text{B} = 90\text{H}$。
>
> 计算机底层实现：计算机硬件只有加法器，没有减法器，用加法器实现所有减法。 $x-y=[x-y]_{\text{补}}=[x]_{\text{补}}+[-y]_{\text{补}}$。无符号整数  $y=[y]_{\text{补}}=246=11110110B$。 $[-y]_{\text{补}}$ 可由  $[y]_{\text{补}}$（1111 0110B）连同符号位在内，按位取反，末位加 1 而得。所以  $[-y]_{\text{补}}=00001010$。则  $x-y=1000\ 0110B+0000\ 1010B=1001\ 0000B=90H$。
>
> R5 中存放无符号数 x - y 的运算结果，故 R5 的内容为 90H。
>
> ③ n 位无符号数加法计算公式为  $x + y = (x + y) \mod 2^n$。在计算机底层中计算规则为：二进制位逐位相加，溢出进位直接舍弃。 $x + y = 1000\ 0110B + 1111\ 0110B = (1)0111\ 1100B = 7CH$（舍弃高位的进位 1），故  **R6 的内容为 7CH**。
>
> (2) 有符号整数和无符号整数相互转换时，机器数不变，仅改变翻译（解释）方式。 $^{①}$ m 的机器数与 x 的机器数相同，均为  $86H = 1000\,0110B$ （此为带符号整数的补码），转换成原码为  $1111\,1010B$ （除符号位外，各位取反，末位加 1），故  $m = -122$。 $^{②}$ k1 的机器数与 z1 的机器数相同，均为  $1001\,0000B$ （此为带符号整数的补码），转换成原码为  $1111\,0000B$ （除符号位外，各位取反，末位加 1），故  $k1 = -112$。
>
> (3) 能。理由如下：① 编码基础：计算机中带符号整数采用补码表示，无符号整数本质就是正数的补码形式（原码）。② 减法统一变加法：无论有符号还是无符号减法，都可以统一转换为加法运算： $A - B = A + [-B]_{\text{补}} = A + (\sim B + 1)$。 $[-B]_{\text{补}}$ 可由  $[B]_{\text{补}}$ 连同符号位在内，按位取反，末位加 1 而得（即： $\sim B + 1$）。③ 共用加法器硬件：以 n 位逐位进位加法器为核心，配合取反控制电路即可实现。
>
> ◇ 加法：在输入端 A 和 B，直接相加。
>
> ◇ 减法：对 B 按位取反， **通过将“最低位进位输入端置1”来实现“+1”操作**。 ④带符号整数加/减、无符号整数加/减运算，这四种运算共用加法器得到运算结果，仅溢出/进位标志的判断逻辑不同。运算主体电路完全复用，无需两套独立加法器。
>
> ☐ 无符号数：用进位标志 CF 判断溢出：
>
> ☐ 带符号数：用溢出标志 OF 判断溢出；
>
> 所以，现代 CPU 的 ALU 通常只设计一个加法器核心，配合少量控制逻辑，即可处理所有整数加减运算。
>
> (4) 带符号整数加 / 减运算的溢出判断规则为: 加法器完成加法操作时, 若最高位的进位 (  **符号位向外的进位** ) 和次高位的进位 (  **数值最高位向符号位的进位** ) 不同, 则发生溢出, 否则不溢出。执行  $k2 = m + n$ 时会发生溢出。因为 10000110B + 11110110B = (1) 01111100B, 最高位的进位为 1 (括号中的 1), 次高位进位为 0, 故发生溢出。
>
> ▷【点评】难题。考查计算机中的加减运算、无符号数和有符号数之间的转化，考查灵活运用，限定在8位字长的场景下，而不是常见的32位字长。本题的考点是408中的高频考点，虽然学起来费劲、难理解，但属于备考408必须掌握的内容。

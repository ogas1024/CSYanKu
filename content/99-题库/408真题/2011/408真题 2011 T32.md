## 题干

32. 有两个并发执行的进程 $P_1$ 和 $P_2$，共享初值为 $1$ 的变量 $x$。$P_1$ 对 $x$ 加 $1$，$P_2$ 对 $x$ 减 $1$。加 $1$ 和减 $1$ 操作的指令序列分别如下所示。

加 $1$ 操作：

```asm
load R1,x    // 取 x 到寄存器 R1 中
inc R1
store x,R1   // 将 R1 的内容存入 x
```

减 $1$ 操作：

```asm
load R2,x
dec R2
store x,R2
```

两个操作完成后，$x$ 的值（）。

A. 可能为 $-1$ 或 $3$

B. 只能为 $1$

C. 可能为 $0$、$1$ 或 $2$

D. 可能为 $-1$、$0$、$1$ 或 $2$

> [!note]- 原题截图
> ![[408真题 2011 T32.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 两个进程并发执行时，指令序列可能被打断、交叉执行，从而导致不同的结果。如下所示，为了方便分析，对每行代码进行编号。
>
> //加1操作
>
> ① load R1, x //取x到寄存器R1中
>
> ② inc R1
>
> ③ store x, R1 //将R1的内容存入x
>
> //减1操作
>
> ④ load R2, x
>
> ⑤ dec R2
>
> ⑥ store x, R2
>
> 40
>
> 【情况1】若进程P1和P2各自执行完，中间没有被打断，即按代码编号为①②③④⑤⑥或者④⑤⑥①②③的顺序执行，则x=1。
>
> 【情况2】若进程P1和P2交叉执行，按代码编号为①②④⑤⑥③的顺序执行，则x=2。
>
> 【情况3】若进程P1和P2交叉执行，按代码编号为④⑤①②③⑥的顺序执行，则x=0。
>
> 【点评】常规题。此类题的易错点在于，可能漏掉了一些情况导致误选。

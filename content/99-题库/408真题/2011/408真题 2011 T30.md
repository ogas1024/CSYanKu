## 题干

30. 在虚拟内存管理中，地址变换机构将逻辑地址变换为物理地址，形成该逻辑地址的阶段是（）。

A. 编辑

B. 编译

C. 链接

D. 装载

> [!note]- 原题截图
> ![[408真题 2011 T30.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 每个阶段的主要工作如下表所示。故选D。这里以2个C语言程序为例，简要介绍“从写代码到内存运行”的完整过程。2个C语言源文件如下所示。main.c是主文件，调用add()函数。在add.c文件中实现add()函数。
>
> ①编辑阶段：这一步只是用C语言编写纯文本代码，和地址完全无关。
>
> ◇ 在 main.o 中，main() 函数的指令地址是从 0x0000 开始排的，它调用 add() 时，只知道这是一个外部符号，不知道 add() 的具体地址，会先留一个空地址。
>
> ◇ 在 add.o 中，add() 函数的指令地址也是从 0x0000 开始排的。
>
> ③链接阶段：链接器把 main.o 和 add.o 合并成一个可执行文件 a.out，这一步才形成了程序完整的逻辑地址空间。
>
> ◇ 给整个程序分配统一的逻辑地址空间：main() 被放到 0x08048000 开始的地址，add() 被放到 0x08048100 开始的地址。
>
> ◇ 重定位符号：把 main() 里调用 add() 的空地址，改成 0x08048100。
>
> ④装载阶段：操作系统把a.out加载到内存，为它分配物理内存页框，并建立页表。程序运行时，CPU取指令时，MMU会：拿到逻辑地址（比如0x08048000），查页表，把它转换成对应的物理地址（比如0x00123000），再去物理内存中读取指令执行。
>
> | 阶段 | 主要工作内容 |
> |---|---|
> | 编辑 | 开发者使用编程语言编写 **源代码文本**。 |
> | 编译 | 把高级语言源程序，翻译成机器语言 **目标文件**。编译完成后，每个目标文件都有自己独立的、从0开始的局部地址，但没有形成程序整体的逻辑地址空间。 |
> | 链接 | 将多个目标文件的地址整合、重定位，形成程序运行时的完整逻辑地址（虚拟地址）空间，得到 **可执行文件**。 |
> | 装载 | 把链接好的可执行文件，加载到内存中，让操作系统可以执行。把逻辑地址映射为物理地址。 |
>
> | //C 语言源文件 main.c | //C 语言源文件 add.c |
> |---|---|
> | #include &lt;stdio.h&gt; int add(int a, int b); int main() { int x = 1, y = 2; int z = add(x, y); printf(&quot;%$d\n$&quot;, z); return 0; } | int add(int a, int b) { return a + b; } |
>
> 【点评】概念题。考查程序加载到内存的过程，建议考生结合本题所举实例，熟悉整个过程。

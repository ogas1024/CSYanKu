## 题干

32. 有两个并发执行的进程 $P_1$ 和 $P_2$，共享初值为 $1$ 的变量 $x$。$P_1$ 对 $x$ 加 $1$，$P_2$ 对 $x$ 减 $1$。加 $1$ 和减 $1$ 操作的指令序列分别如下所示。

加 $1$ 操作：

```asm
load R1,x    // 取 x 到寄存器 R1 中
inc R1
store x,R1   // 将 R1 的内容存入 x
```

减 $1$ 操作：

```asm
load R2,x
dec R2
store x,R2
```

两个操作完成后，$x$ 的值（）。

A. 可能为 $-1$ 或 $3$

B. 只能为 $1$

C. 可能为 $0$、$1$ 或 $2$

D. 可能为 $-1$、$0$、$1$ 或 $2$

> [!note]- 原题截图
> ![[408真题-2011-T32.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 枚举两个进程读写交错次序，x 最终可能为 0、1、2，故 C。

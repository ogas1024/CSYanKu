## 题干

27. 进程 $P_0$ 和 $P_1$ 的共享变量定义及其初值为：

```c
boolean flag[2];
int turn=0;
flag[0]=FALSE; flag[1]=FALSE;
```

若进程 $P_0$ 和 $P_1$ 访问临界资源的类 C 伪代码实现如下：

```c
void P0()  // 进程 P0
{
    while(TRUE)
    {
        flag[0]=TRUE; turn=1;
        while(flag[1]&&(turn==1));
        临界区;
        flag[0]=FALSE;
    }
}

void P1()  // 进程 P1
{
    while(TRUE)
    {
        flag[1]=TRUE; turn=0;
        while(flag[0]&&(turn==0));
        临界区;
        flag[1]=FALSE;
    }
}
```

则并发执行进程 $P_0$ 和 $P_1$ 时产生的情形是（）。

A. 不能保证进程互斥进入临界区，会出现“饥饿”现象

B. 不能保证进程互斥进入临界区，不会出现“饥饿”现象

C. 能保证进程互斥进入临界区，会出现“饥饿”现象

D. 能保证进程互斥进入临界区，不会出现“饥饿”现象

> [!note]- 原题截图
> ![[408真题-2010-T27.png]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 题给两个进程通过 turn 和 flag 协调临界区，属于 Peterson 互斥算法，故选 D。

## 题干

44. （12 分）某计算机的主存地址空间大小为 $256\ \mathrm{MB}$，按字节编址。指令 Cache 和数据 Cache 分离，均有 $8$ 个 Cache 行，每个 Cache 行大小为 $64\ \mathrm{B}$，数据 Cache 采用直接映射方式。

现有两个功能相同的程序 A 和 B，其伪代码如下：

程序 A：

```c
int a[256][256]
.....
int sum_array1()
{
    int i,j,sum=0;
    for(i=0;i<256;i++)
        for(j=0;j<256;j++)
            sum+=a[i][j];
    return sum;
}
```

程序 B：

```c
int a[256][256]
.....
int sum_array2()
{
    int i,j,sum=0;
    for(j=0;j<256;j++)
        for(i=0;i<256;i++)
            sum+=a[i][j];
    return sum;
}
```

假定 int 类型数据用 $32$ 位补码表示，程序编译时 $i$、$j$、sum 均分配在寄存器中，数组 $a$ 按行优先方式存放，其首地址为 $320$（十进制数）。

请回答下列问题，要求说明理由或给出计算过程。

（1）若不考虑用于 Cache 一致性维护和替换算法的控制位，则数据 Cache 的总容量为多少？
（2）数组元素 `a[0][31]` 和 `a[1][1]` 各自所在的主存块对应的 Cache 行号分别是多少（Cache 行号从 $0$ 开始）？
（3）程序 A 和 B 的数据访问命中率各是多少？哪个程序的执行时间更短？

> [!success]- 答案与解析
> **解析：**
>
> (1) ① 一行 Cache 的内容包括辅助位和 Cache 块数据（存储对应的主存块数据）。辅助位包括 Tag 位、有效位、脏位、LRU 标记位等，其中 Tag 位和有效位是任何 Cache 所必需的。题目已说明“不考虑 Cache 一致性维护和替换算法的控制位”，则 Cache 行内容如下表所示。
>
> ②每个 Cache 块占 64B，有效位为 1bit，接下来求标记位的位数。直接映射的物理地址结构
>
> | 有效位 | 标记位 | Cache块数据 |
> |---|---|---|
>
> 如下表所示。
>
> | 标记 | Cache 块号 | 块内地址 |
> |---|---|---|
>
> Cache行数为8，则Cache块号占 $\log_{2}8=3$位。主存块和Cache块大小相等，均为64B，则块内地址占 $\log_{2}64=6$位。主存地址空间为256MB，按字节编址，则主存地址占 $\log_{2}\frac{256MB}{B}=28$位。所以，标记位占28-3-6=19位。
>
> ③ 物理地址中的标记位数和 Cache 行中的标记位数相等，均为 19 位。综上所述，每一行 Cache 中，有效位为 1bit，标记位为 19bit，Cache 块为  $64B = 64 \times 8 = 512$bit。数据 Cache 有 8 行，则总容量为  $8 \times (1 + 19 + 512) = 532 \times 8$bit = 532B。即：数据 Cache 的总容量为 532B。
>
> (2) 第(1)问已经求出直接映射的物理地址结构各部分所占位数如下表所示。
>
> | 标记（19位） | Cache 块号（3位） | 块内地址（6位） |
> |---|---|---|
>
> ① 数组 a 首地址为 320，数组 a 按行优先存储，按字节编址，每个 int 类型数据占 4B，则数组元素 a[0][31] 的地址为  $320 + 4 \times 31 = 444 = 0001$ 1011 1100B，根据物理地址结构可知，Cache 块号为 110B = 6。即： $\underline{\text{数组元素 a[0][31] 所在的主存块对应的 Cache 行号为 6}}$。
>
> ②同理，因为数组 a 按行优先存储，一行有 256 个元素，则数组元素 a[1][1] 的地址为 320 + 4 × 256 + 4 × 1 = 1348 = 0101 0100 0100B，根据物理地址结构可知，Cache 块号为 101B = 5。即：数组元素 a[1][1] 所在的主存块对应的 Cache 行号为 5。
>
> (3) ① 【解法一】程序 A 中，数组 a 的访问顺序和存储顺序完全一致，连续访问同一行的元素。访问数组 a 的次数为  $256 \times 256 = 2^{16}$。数组 a 占  $\frac{256 \times 256 \times 4B}{64B} = 2^{12}$ 个主存块。访问每个主存块中的第一个元素时，因为该主存块还未调入 Cache，导致 Cache 未命中，将该主存块调入 Cache，随后再访问该主存块中的其他元素时，Cache 均命中。则 Cache 不命中次数为  $2^{12}$，命中次数为  $2^{16} - 2^{12}$，Cache 命中率为  $\frac{2^{16} - 2^{12}}{2^{16}} = 1 - \frac{1}{16} = \frac{15}{16} = 93.75\%$。
>
> 【解法二】每个int类型数组元素占4B，Cache行大小为64B，则一个Cache行可存放 $\frac{04B}{4B}=16$个数组元素。程序A中，数组a的访问顺序和存储顺序完全一致，连续访问同一行的元素。则每访问16个连续元素，仅第1个不命中，Cache不命中后，会将该主存块未调入Cache（调入相邻的16个元素），则后续15个均命中，Cache命中率为 $\frac{15}{16}=93.75\%$。
>
> ②数组a按行优先方式存放，程序B中按列访问数组a，依次访问a[0][0]、a[1][0]、a[2][0]、…、a[255][0]。程序B中，连续访问数组a中的2个元素，中间间隔256个数组元素（例如：a[0][0]和a[1][0]中间间隔256个元素）， $256\times4=1024$B，每个Cache行占64B，1024%64=0，数据Cache采用直接映射，说明这2个元素映射到同一个Cache行。则每次访问都会发生Cache冲突失效：新块覆盖旧块，下一次访问同一列的下一个元素时，原块已被替换，必须重新加载。所有访问Cache均不命中，Cache命中率为0%。
>
> ③执行程序A时，Cache命中率高；执行程序B时，Cache命中率为0。所以程序A的执行时间更短。
>
> ▷【点评】难题。本题综合性很强，全面考查了 Cache 相关考点，也有一定的计算量，做起来很费时间。

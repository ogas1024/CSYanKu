## 题干

44. （12 分）某计算机的主存地址空间大小为 $256\ \mathrm{MB}$，按字节编址。指令 Cache 和数据 Cache 分离，均有 $8$ 个 Cache 行，每个 Cache 行大小为 $64\ \mathrm{B}$，数据 Cache 采用直接映射方式。

现有两个功能相同的程序 A 和 B，其伪代码如下：

程序 A：

```c
int a[256][256]
.....
int sum_array1()
{
    int i,j,sum=0;
    for(i=0;i<256;i++)
        for(j=0;j<256;j++)
            sum+=a[i][j];
    return sum;
}
```

程序 B：

```c
int a[256][256]
.....
int sum_array2()
{
    int i,j,sum=0;
    for(j=0;j<256;j++)
        for(i=0;i<256;i++)
            sum+=a[i][j];
    return sum;
}
```

假定 int 类型数据用 $32$ 位补码表示，程序编译时 $i$、$j$、sum 均分配在寄存器中，数组 $a$ 按行优先方式存放，其首地址为 $320$（十进制数）。

请回答下列问题，要求说明理由或给出计算过程。

（1）若不考虑用于 Cache 一致性维护和替换算法的控制位，则数据 Cache 的总容量为多少？
（2）数组元素 `a[0][31]` 和 `a[1][1]` 各自所在的主存块对应的 Cache 行号分别是多少（Cache 行号从 $0$ 开始）？
（3）程序 A 和 B 的数据访问命中率各是多少？哪个程序的执行时间更短？

> [!note]- 原题截图
> ![[408真题 2010 T44.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 主存地址 28 位，块内地址 6 位，Cache 行号 3 位，所以标记 19 位。每行含 1 位有效位、19 位标记和 512 位数据，总容量为
> $$8\times(1+19+512)=4256\text{ bit}=532\text{ B}。$$
> 2. `a[0][31]` 地址为 $320+31\times4=444$，所在主存块号为 6，映射到 Cache 第 6 行。`a[1][1]` 地址为 $320+256\times4+4=1348$，主存块号为 21，映射到 Cache 第 $21\bmod8=5$ 行。
> 3. 程序 A 按行访问，每个 64 B 块容纳 16 个 int，第一次不命中、随后 15 次命中，命中率为 $15/16=93.75\%$。程序 B 按列访问，相邻访问跨 1 KB，映射到同一 Cache 行并相互替换，每次均不命中，命中率为 0。因此程序 A 更快。
>
> **解析：** 容量计算需同时计入有效位和标记位；直接映射行号等于主存块号模 8，命中率则由两种遍历次序的空间局部性和冲突替换决定。

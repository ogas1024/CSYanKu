## 题干

42. （13 分）设将 $n$（$n>1$）个整数存放到一维数组 $R$ 中。试设计一个在时间和空间两方面都尽可能高效的算法，将 $R$ 中保存的序列循环左移 $p$（$0<p<n$）个位置，即将 $R$ 中的数据由

$$
(X_0,X_1,\cdots,X_{n-1})
$$

变换为

$$
(X_p,X_{p+1},\cdots,X_{n-1},X_0,X_1,\cdots,X_{p-1})
$$。

要求：

（1）给出算法的基本设计思想。
（2）根据设计思想，采用 C、C++ 或 Java 语言描述算法，关键之处给出注释。
（3）说明你所设计算法的时间复杂度和空间复杂度。

> [!success]- 答案与解析
> **解析：**
>
> (1) 将  $\overbrace{x_0, x_1, \cdots, x_{p-1}}^{p \text{ 个元素}}$,  $\overbrace{x_p, x_{p+1}, \cdots, x_{n-2}, x_{n-1}}^{n-p \text{ 个元素}}$ 倒置，得到  $\overbrace{x_{n-1}, x_{n-2}, \cdots, x_{p+1}, x_p}^{n-p \text{ 个元素}}$,  $\overbrace{x_{p-1}, \cdots, x_1, x_0}^{p \text{ 个元素}}$ 再以  $x_p$ 为界，分别将两边倒置，即将  $(x_{n-1}, x_{n-2}, \cdots, x_p)$ 倒置得到  $(x_p, x_{p+1}, \cdots, x_{n-1})$，将  $(x_{p-1}, x_{p-2}, \cdots, x_0)$ 倒置得到  $(x_0, x_1, \cdots, x_{p-1})$。即可得到题目要求的结果。
>
> (2) 代码实现如下：
>
> //reverse函数的功能是将序列原地倒置，start和end序列的开始和结束位置 void reverse(int R[], int start, int end) { int temp, i; // 作为交换的临时变量 for (i = 0; i < (end - start + 1) / 2; i++) { //将首尾位置的元素交换 temp = R[start + i]; R[start + i] = R[end - i]; R[end - i] = temp; } } void move(int R[], int p, int n) { reverse(R, 0, n - 1); //将全部n个数据倒置 reverse(R, 0, n - p - 1); //将前n-p个数据倒置 reverse(R, n - p, n - 1); //将后p个数据倒置 }
>
> (3) 时间复杂度为 O(n)，空间复杂度为 O(1)。

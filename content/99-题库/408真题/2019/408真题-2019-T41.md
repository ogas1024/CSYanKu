## 题干

41. （13分）设线性表 $L=\left(a_{1},a_{2},a_{3},\cdots,a_{n-2},a_{n-1},a_{n}\right)$采用带头结点的单链表保存，链表中的结点定义如下：

typedef struct node
{ int data;
    struct node*next;
} NODE;

请设计一个空间复杂度为$O(1)$且时间上尽可能高效的算法，重新排列$L$中的各结点，得到线性表$L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\cdots)$。

要求：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

（3）说明你所设计的算法的时间复杂度。

> [!note]- 原题截图
> ![[408真题-2019-T41.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 用快慢指针找到链表中点，将后半段原地逆置，再交替取前、后两段结点重排。
> 2. ```c
> void change_list(Node *h) {
>     Node *p=h, *q=h, *r, *s;
>     while (q->next) { p=p->next; q=q->next; if (q->next) q=q->next; }
>     q=p->next; p->next=NULL;
>     while (q) { r=q->next; q->next=p->next; p->next=q; q=r; }
>     s=h->next; q=p->next; p->next=NULL;
>     while (q) { r=q->next; q->next=s->next; s->next=q; s=q->next; q=r; }
> }
> ```
> 3. 时间复杂度 $O(n)$，额外空间复杂度 $O(1)$。
>
> **解析：** 目标序列是从原链表前半段和逆序后的后半段交替取结点；三次线性扫描分别完成找中点、逆置和合并。

## 题干

44. （14 分）某计算机采用 $16$ 位定长指令字格式，其 CPU 中有一个标志寄存器，其中包含进位/借位标志 CF、零标志 ZF 和符号标志 NF。

假定为该机设计了条件转移指令，其格式如下：

![[408真题 2013 T44-fig2.webp|500]]

其中，`00000` 为操作码 OP；C、Z 和 N 分别为 CF、ZF 和 NF 的对应检测位，某检测位为 $1$ 时表示需检测对应标志位，需检测的标志位中只要有一个为 $1$ 就转移，否则不转移。

例如，若 $C=1$，$Z=0$，$N=1$，则需检测 CF 和 NF 的值，当 $\mathrm{CF}=1$ 或 $\mathrm{NF}=1$ 时发生转移；

OFFSET 是相对偏移量，用补码表示。

转移执行时，转移目标地址为 $(\mathrm{PC})+2+2\times\mathrm{OFFSET}$；

顺序执行时，下条指令地址为 $(\mathrm{PC})+2$。

请回答下列问题。

（1）该计算机存储器按字节编址还是按字编址？该条件转移指令向后（反向）最多可跳转多少条指令？
（2）某条件转移指令的地址为 `200CH`，指令内容如下图所示。若该指令执行时 $\mathrm{CF}=0$，$\mathrm{ZF}=0$，$\mathrm{NF}=1$，则该指令执行后 PC 的值是多少？若该指令执行时 $\mathrm{CF}=1$，$\mathrm{ZF}=0$，$\mathrm{NF}=0$，则该指令执行后 PC 的值又是多少？请给出计算过程。

（3）实现“无符号数比较小于等于时转移”功能的指令中，C、Z 和 N 应各是什么？

> [!success]- 答案与解析
> **解析：**
>
> (1) ① PC 是根据 “ **当前指令的长度**” 来自增的。PC 自增后指向下一条要执行指令的地址。题目已说明 “采用 16 位定长指令”、“顺序执行时，下条指令地址为 (PC) + 2”。根据题目条件，PC 每次地址增量为 2，说明 16 位指令占 2 个地址单元，所以每个地址单元占  $\frac{16bit}{2}$ = 8 位，即存储器按字节编址。
>
> 【提示】该考点408中反复考过多次，原理都是一样的。
>
> ② n 位补码表示范围是  $-2^{n-1} \sim 2^{n-1} - 1$。相对偏移 OFFSET 用 8 位补码表示，则表示范围为 -128 ~ 127。当 OFFSET = -128 时（取最小值），向后跳转的指令条数最多，代入题目给出的转移目标地址公式： $(PC) + 2 + 2 \times (-128) = (PC) + 2 \times (-127)$。每条指令长度为 2B，按字节编址，则对应每条指令，PC 增量为 2。则相对于当前指令，条件转移指令最多向后跳转 127 条指令。
>
> (2) 根据题目给出的指令内容，该指令的检测位 C=0, Z=1, N=1。则需要检测 ZF 和 NF 的值。
>
> ① 当 CF = 0, ZF = 0, NF = 1 时，根据题目条件，NF = 1 是发生转移，且转移目标地址为：(PC) + 2 + 2 × OFFSET。根据题目给出的指令内容，OFFSET = 1110 0011。此时 (PC) = 200CH，代入上述公式，则该指令执行后 PC 的值 = 200CH + 2 + 2 × 1110 0011B。计算上式的值有如下 3 种方法：
>
> ▶ 转化成十六进制计算（推荐用此方法解题）：[1110 0011]补 = -29， $2 + 2 \times (-29) = -56 = -38$H，则  $200 CH + 2 + 2 \times 1110\ 0011$ B = 200 CH - 38 H = 1FD4H。
>
> ◇ 转化成十进制计算（计算量较大，太费时间）：200CH = 8204，[1110 0011]补 = -29，则 8204 + 2 - 58 = 8148 = 1FD4H。
>
> ◇ 移位运算（符号扩展易错）：补码乘以2，等价于左移1位。将1110 0011B除符号
>
> 位外左移 1 位，低位补 0，得到 1100 0110B = C6H。将 C6H 进行符号扩展为 FFC6H（位数不一致，不能直接相加，先进行符号扩展。补码符号扩展，高位填充符号位）。200CH + 2 + FFC6H = 200EH + FFC6H = 1FD4H（补码加法运算，最高位产生的进位直接丢弃）。
>
> ②当 CF=1, ZF=0, NF=0 时，根据题目条件，ZF 和 NF 均为 0，则不转移。顺序执行时，下条指令地址为 (PC) + 2 = 200CH + 2 = 200EH。
>
> (3) C=1, Z=1, N=0。理由如下：无符号数比较，跟符号标志 NF 无关，则不检测标志位 NF，所以检测位 N=0。在计算机中，两个数 a, b 比较大小是转化为 a-b 的减法运算。题目要求实现“小于等于时转移”：
>
> ◇ 若两个数相等，则零标志 ZF = 1，需要检测标志位 ZF，所以检测位 Z = 1。
>
> ◇ ①若  $a - b > 0$，则不借位  $\Rightarrow CF = 0 \Rightarrow A > B$。
>
> ②若 a - b < 0，则必须借位  $\Rightarrow CF = 1 \Rightarrow A < B$。
>
> 综上，实现“无符号数比较小于等于时转移”功能的指令中，C=1，Z=1，N=0。
>
> 【提示】★①因为无符号数没有符号位。所以，无符号数比较大小时，无需考虑符号位。
>
> ②本题和2011年408第17题考点相同，考生可对比学习。
>
> (4) (a) 部件 ① 中有指令的操作码 OP、检测位、偏移量 OFFSET，很明显部件 ① 是指令寄存器，用来存放指令。(b) 指令的偏移量 OFFSET，经过符号扩展后，送入部件 ②，结合转移指令目标地址的计算公式 (PC) + 2 + 2 × OFFSET，所以部件 ② 是移位寄存器，用于实现 2 × OFFSET。(c) 部件 ③ 的两个输入端分别是 (PC) + 2 和 2 × OFFSET，所以部件 ③ 是加法器 ALU，用于实现地址相加，得到转移目标地址。
>
> ▷【点评】难题。综合考查标志位的生成和转移指令。以考查计组第2章的内容为主。很符合最近几年408的考查方向。值得考生举一反三，仔细研究。另外，关于加减运算标志位取值，在竟成《计算机组成原理复习全书》第2章最后一个小节“运算方法和运算电路”部分，有专门的总结。本题考查“无符号数比较”的情况，关于“有符号数比较”也是很有可能考到的。

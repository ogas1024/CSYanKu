## 题干

43. （9 分）某 $32$ 位计算机，CPU 主频为 $800\,\mathrm{MHz}$，Cache 命中时的 CPI 为 $4$，Cache 块大小为 $32$ 字节；

主存采用 $8$ 体交叉存储方式，每个体的存储字长为 $32$ 位、存储周期为 $40\,\mathrm{ns}$；

存储器总线宽度为 $32$ 位，总线时钟频率为 $200\,\mathrm{MHz}$，支持突发传送总线事务。

每次读突发传送总线事务的过程包括：送首地址和命令、存储器准备数据、传送数据。

每次突发传送 $32$ 字节，传送地址或 $32$ 位数据均需要一个总线时钟周期。

请回答下列问题，要求给出理由或计算过程。

（1）CPU 和总线的时钟周期各为多少？总线的带宽（即最大数据传输率）为多少？
（2）Cache 缺失时，需要用几个读突发传送总线事务来完成一个主存块的读取？
（3）存储器总线完成一次读突发传送总线事务所需的时间是多少？
（4）若程序 BP 执行过程中，共执行了 $100$ 条指令，平均每条指令需进行 $1.2$ 次访存，Cache 缺失率为 $5\%$，不考虑替换等开销，则 BP 的 CPU 执行时间是多少？

> [!success]- 答案与解析
> **解析：**
>
> (1) ① CPU 时钟周期是主频的倒数，CPU 时钟周期 =  $\frac{1}{800MHz} = 1.25ns$。② 总线时钟周期是总线时钟频率倒数，总线时钟周期 =  $\frac{1}{200MHz} = 5ns$。③ 存储器总线宽度为 32bit = 4B，即：每个总线时钟周期可传输 4B 数据，则总线带宽 = 4B × 200MHz = 800MB/s。
>
> 【提示】总线带宽 = 总线宽度 ÷ 总线时钟周期 = 总线宽度 × 总线时钟频率
>
> (2) 每次突发传送 32B，Cache 块大小为 32B，主存块和 Cache 块大小相等，所以读取一个主存块需要  $\underline{1}$ 个读突发传送总线事务。
>
> (3) 一次突发总线事务过程包括：
>
> ◇ 送首地址和命令：1 个总线时钟周期 = 5ns
>
> ◇ 存储器准备数据：主存为8体交叉存储，存储周期40ns，每隔5ns启动一个存储体，交叉存储器是流水线式并行存储。读取32B数据的时间为40ns+（8-1）×5ns = 75ns。
>
> ▷【提示】4体交叉存储器读取6个存储字长示意图如下图所示。交叉存储器默认是低位交叉。关于交叉存储器的数据存取时间，考生若不熟悉，可再回顾学习一遍，这里限于篇幅，不再重复讲述。
>
> 传送数据：题目已说明“传送32位数据需要一个总线时钟周期（5ns）”，传送32B数据需要8个总线时钟周期= $8 \times 5ns = 40ns$。读取数据和传送数据可并行。读完第一个存储体之后，读取后续存储体数据的同时，可在总线上传送已读取的上一个存储体的数据，可并行7个总线时钟周期（35ns）。
>
> 总线完成一次突发传送总线事务需要  $(5+75+40-35)$ns = 85ns。
>
> (4) CPU 执行时间 = Cache 命中时的 CPU 执行时间 + Cache 缺失时的额外访存时间。
>
> ①题目中说明“Cache命中时的CPI为4”：意思是当所有访存都命中Cache时（这里已经考虑了Cache命中率），平均每条指令的CPI是4。Cache命中时的执行时间=100×4×1.25ns=500ns。②Cache缺失次数=100×1.2×5%=6次。题目第(2)和(3)问已经求出，每次Cache缺失访存需要读取一个主存块，需要完成一次突发总线传送，时间为85ns。则Cache缺失时的额外访存时间=85ns×6=510ns。
>
> CPU执行时间=500ns+510ns=1010ns。
>
> ▷【点评】概念题。本题前两问容易得分，比较简单。第（3）问难点在于交叉存储器的读取和数据在总线上的传送可并行。第（4）问要用到第（3）问的结论，易错点在于利用“Cache 命中时的 CPI 为 4”的结论时，不用再乘以 Cache 命中率 95%，这点极易出错。
>
> 从最新的408命题趋势来看，单纯像此题这样考查概念，并且在概念考查上处处挖坑，此前没做过类似题首次遇到很难做对的题，408如今考的很少了。

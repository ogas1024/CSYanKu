## 题干

45. （7 分）某博物馆最多可容纳 $500$ 人同时参观，有一个出入口，该出入口一次仅允许一个人通过。

参观者的活动描述如下：

```text
cobegin
    参观者进程 i:
    {
        ...
        进门;
        ...
        参观;
        ...
        出门;
        ...
    }
coend
```

请添加必要的信号量和 P、V（或 `wait()`、`signal()`）操作，以实现上述过程中的互斥与同步。

要求写出完整的过程，说明信号量的含义并赋初值。

> [!note]- 原题截图
> ![[408真题 2013 T45.webp]]

> [!success]- 答案与解析
> **解析：**
>
> 定义互斥信号量 mutex，实现对博物馆出入口这一互斥资源的互斥访问。定义信号量 empty，实现对参观人数的限制。具体实现如下：
>
> semaphore mutex = 1; // 实现对博物馆出入口的互斥使用 semaphore empty = 500; // 博物馆剩余可容纳人数，初值为500 cobegin 参观者进程i: { P(empty); // 申请场馆名额，满500则阻塞等待 P(mutex); // 申请出入口使用权，互斥进门 进门; V(mutex); // 释放出入口 参观; P(mutex); // 申请出入口使用权，互斥出门 出门; V(mutex); // 释放出入口 V(empty); // 释放1个参观场馆的名额 } CoEnd
>
> 【点评】常规题。本题算是考查 P/V 操作最简单的一类题目。做题时不要忽略“最多可容纳 500 人同时参观”这个限制条件。

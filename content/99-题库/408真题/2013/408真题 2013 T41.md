## 题干

41. （13 分）已知一个整数序列 $A=(a_0,a_1,\cdots,a_{n-1})$，其中 $0\leq a_i<n$（$0\leq i<n$）。

若存在 $a_{p_1}=a_{p_2}=\cdots=a_{p_m}=x$ 且 $m>n/2$（$0\leq p_k<n,1\leq k\leq m$），则称 $x$ 为 $A$ 的主元素。

例如 $A=(0,5,5,3,5,7,5,5)$，则 $5$ 为主元素；又如 $A=(0,5,5,3,5,1,5,7)$，则 $A$ 中没有主元素。

假设 $A$ 中的 $n$ 个元素保存在一个一维数组中，请设计一个尽可能高效的算法，找出 $A$ 的主元素。

若存在主元素，则输出该元素；否则输出 $-1$。

要求：

（1）给出算法的基本设计思想。
（2）根据设计思想，采用 C、C++ 或 Java 语言描述算法，关键之处给出注释。
（3）说明你所设计算法的时间复杂度和空间复杂度。

> [!success]- 答案与解析
> **解析：**
>
> (1) 本题考查“摩尔投票算法”，这是面试、算法题里非常经典、高频的中等难度算法。该算法解决的问题是： **查找在数组中出现次数超过数组长度一半的元素**（称该元素为“主元素”）。关键思想是：利用“多数元素的数量优势”，让不同元素相互抵消，最终筛选出候选元素，再验证候选元素是否满足要求。该算法基本设计思想主要分为两步：
>
> 1. 候选主元素筛选：
>
> ◇ 用变量 majorElem 记录当前候选主元素，用 count 作为临时变量。
>
> ☐ 遍历数组，遍历过程中：
>
> 若 count == 0，则将当前元素设为 majorElem，并令 count = 1；
>
> 若当前元素与 majorElem 相同，则 count++;
>
> 若当前元素与 majorElem 不同，则 count--。
>
> ◇ 若数组中存在主元素（出现次数 >  $\frac{n}{2}$），则经过上述步骤遍历完数组后，majorElem 就是主元素。但数组有可能不存在主元素，所以需要再次遍历数组验证。
>
> 2. 验证候选元素：再次遍历数组，统计 majorElem 出现的次数。若次数 >  $\frac{n}{2}$，则 majorElem 是主元素；否则输出 -1。
>
> (2) 算法实现如下：
>
> int findMajorElem(int A[], int n) { int majorElem = A[0], count = 1; //变量初始化 for (int i = 1; i < n; i++) { if (A[i] == majorElem) { count++; } else { count--; if (count == 0) { majorElem = A[i]; count = 1; } } } if (count <= 0) { //若count小于等于0说明不可能有主元素 return -1; } count = 0; //这一步不要漏了：将临时变量count清零 for (int i = 0; i < n; i++) { //统计候选主元素个数 if (A[i] == majorElem) { count++; } } if (count > n/2) { return majorElem; } else { return -1; } }
>
> (3) 时间复杂度为  $O(n)$，空间复杂度为  $O(1)$。
>

> https://leetcode.cn/problems/majority-element
>
> ▷【点评】常规题。本题的最优解比较难理解。但暴力解非常直白好理解：利用哈希表的思想，定义一个辅助数组 map[n]（题目中已说明数组中每个元素均小于 n），数组元素 map[key] 表示元素 key 出现次数。遍历数组，逐个计数 map[key]++。数组遍历完后，再遍历哈希表 map[n]，若 map[i] > n/2，则输出元素 i，否则输出 -1。

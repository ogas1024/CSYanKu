## 题干

45. （7 分）某博物馆最多可容纳 $500$ 人同时参观，有一个出入口，该出入口一次仅允许一个人通过。

参观者的活动描述如下：

```text
cobegin
    参观者进程 i:
    {
        ...
        进门;
        ...
        参观;
        ...
        出门;
        ...
    }
coend
```

请添加必要的信号量和 P、V（或 `wait()`、`signal()`）操作，以实现上述过程中的互斥与同步。

要求写出完整的过程，说明信号量的含义并赋初值。

> [!note]- 原题截图
> ![[408真题-2013-T45.png]]

> [!success]- 答案与解析
> **答案：**
>
> ```text
> semaphore empty=500;  // 馆内剩余容量
> semaphore mutex=1;    // 出入口互斥
>
> cobegin
> 参观者进程 i:
> {
>     ...
>     P(empty);
>     P(mutex); 进门; V(mutex);
>     ...
>     参观;
>     P(mutex); 出门; V(mutex);
>     V(empty);
>     ...
> }
> coend
> ```
>
> **解析：** empty 限制馆内人数不超过 500；唯一出入口在进门和出门时均需由 mutex 互斥保护。

## 题干

37. 下列关于 IP 路由器功能的描述中，正确的是（）。

I. 运行路由协议，设置路由表

II. 监测到拥塞时，合理丢弃 IP 分组

III. 对收到的 IP 分组头进行差错校验，确保传输的 IP 分组不丢失

IV. 根据收到的 IP 分组的目的 IP 地址，将其转发到合适的输出线路上

A. 仅 III、IV

B. 仅 I、II、III

C. 仅 I、II、IV

D. 仅 I、II、III、IV

> [!note]- 原题截图
> ![[408真题-2012-T37.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 路由器转发和拥塞时合理丢弃属于其功能；IP 只做首部校验且不保证不丢失，故 C。

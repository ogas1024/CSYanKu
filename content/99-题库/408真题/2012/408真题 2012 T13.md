## 题干

13. 假定编译器规定 int 和 short 型长度分别为 32 位和 16 位，执行下列 C 语言语句：

```c
unsigned short x = 65530;
unsigned int y = x;
```

得到 y 的机器数为（）。

A. 0000 7FFAH

B. 0000 FFFAH

C. FFFF 7FFAH

D. FFFF FFFAH

> [!note]- 原题截图
> ![[408真题 2012 T13.png]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 16 位无符号 x=FFFAH，扩展为 32 位时高位补 0，y=`0000FFFAH`，故 B。

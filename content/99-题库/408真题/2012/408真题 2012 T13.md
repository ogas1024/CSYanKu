## 题干

13. 假定编译器规定 int 和 short 型长度分别为 32 位和 16 位，执行下列 C 语言语句：

```c
unsigned short x = 65530;
unsigned int y = x;
```

得到 y 的机器数为（）。

A. 0000 7FFAH

B. 0000 FFFAH

C. FFFF 7FFAH

D. FFFF FFFAH

> [!note]- 原题截图
> ![[408真题 2012 T13.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** $x = 65530 = 65535 - 5 = 1111\ 1111\ 1111\ 1010B = \text{FFFAH}$。低精度无符号数转化为高精度无符号数时，高位全部填充0。unsigned short转换成unsigned int，高位直接补充16个0即可。故 $v = 0000$ FFFAH。
>
> ▷【点评】常规题。关于低精度整数向高精度整数转换，高位填充规则补充如下：
>
> ▷【点评】常规题。关于低精度整数同高精度。对于有符号数，“高位填充符号位”：若是负数，则高位全部填充1；若是正数，则高位全部填充0。
>
> ◇ 无符号数没有符号位，可视为正数，故高位全部填充 0。
>
> 另外，65535 是一个特殊的数，考生需要了解。65535 =  $2^{16} - 1$ = FFFFH。若考场现场推导则浪费时间。

## 题干

1. 求整数 $n$（$n \geq 0$）阶乘的算法如下，其时间复杂度是（　）。

```c
int fact(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * fact(n - 1);
}
```

A. $O(\log_2 n)$

B. $O(n)$

C. $O(n \log_2 n)$

D. $O(n^2)$

> [!note]- 原题截图
> ![[408真题 2012 T01.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 时间复杂度是基本语句执行次数的数量级。本题基本语句是“n*fact(n-1)”，该语句会执行n-1次。故时间复杂度为 $O(n)$。故选B。
>
> 【点评】常规题。考查时间复杂度的计算。

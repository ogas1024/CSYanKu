## 题干

1. 求整数 $n$（$n \geq 0$）阶乘的算法如下，其时间复杂度是（　）。

```c
int fact(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * fact(n - 1);
}
```

A. $O(\log_2 n)$

B. $O(n)$

C. $O(n \log_2 n)$

D. $O(n^2)$

> [!note]- 原题截图
> ![[408真题 2012 T01.png]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 递归每次把 n 减 1，基本语句共执行 n 次，时间复杂度为 O(n)，故 B。

## 题干

38. ARP 协议的功能是（）

A. 根据 IP 地址查询 MAC 地址

B. 根据 MAC 地址查询 IP 地址

C. 根据域名查询 IP 地址

D. 根据 IP 地址查询域名

> [!note]- 原题截图
> ![[408真题 2012 T38.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** ①选项 A：ARP（地址解析协议）的核心功能就是将网络层的 IP 地址解析为数据链路层的 MAC 地址。②选项 B：RARP（反向地址解析协议）根据 MAC 地址查询 IP 地址，但 RARP 协议如今已被彻底淘汰、完全被 DHCP 协议取代。③选项 C：DNS 协议根据域名查询 IP 地址。④选项 D：反向 DNS 解析根据 IP 地址查询域名。但反向 DNS 解析不是独立新协议，底层使用标准 DNS 协议。例如：在 Windows 中，nslookup 命令既能根据域名查询 IP（正向 DNS 解析），也能根据 IP 反向查域名（反向 DNS 解析）。故选 A。
>
> 【点评】概念题。考查 ARP 协议的功能。

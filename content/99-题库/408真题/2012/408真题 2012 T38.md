## 题干

38. ARP 协议的功能是（）

A. 根据 IP 地址查询 MAC 地址

B. 根据 MAC 地址查询 IP 地址

C. 根据域名查询 IP 地址

D. 根据 IP 地址查询域名

> [!note]- 原题截图
> ![[408真题 2012 T38.png]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 实际链路层传输需 MAC 硬件地址，ARP 把 IP 地址解析为 MAC 地址，故 A。

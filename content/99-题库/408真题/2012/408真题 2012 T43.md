## 题干

43. （11 分）假定某计算机的 CPU 主频为 $80\,\mathrm{MHz}$，CPI 为 $4$，平均每条指令访存 $1.5$ 次，主存与 Cache 之间交换的块大小为 $16\,\mathrm{B}$，Cache 的命中率为 $99\%$，存储器总线宽度为 $32$ 位。

请回答下列问题。

（1）该计算机的 MIPS 数是多少？平均每秒 Cache 缺失的次数是多少？在不考虑 DMA 传送的情况下，主存带宽至少达到多少才能满足 CPU 的访存要求？
（2）假定在 Cache 缺失的情况下访问主存时，存在 $0.0005\%$ 的缺页率，则 CPU 平均每秒产生多少次缺页异常？若页面大小为 $4\,\mathrm{KB}$，每次缺页都需要访问磁盘，访问磁盘时 DMA 传送采用周期挪用方式，磁盘 I/O 接口的数据缓冲寄存器为 $32$ 位，则磁盘 I/O 接口平均每秒发出的 DMA 请求次数至少是多少？
（3）CPU 和 DMA 控制器同时要求使用存储器总线时，哪个优先级更高？为什么？
（4）为了提高性能，主存采用四体低位交叉存储模式，工作时每 $1/4$ 个存储周期启动一个体。若每个体的存储周期为 $50\,\mathrm{ns}$，则该主存能提供的最大带宽是多少？

> [!success]- 答案与解析
> **解析：**
>
> (1) ① CPU 主频指每秒有多少个时钟周期，CPI 指执行一条指令平均需要多少个时钟周期，MIPS 指每秒执行百万条指令数。CPU 每秒有 80M 个时钟周期，而执行一个指令平均要 4 个时钟周期，故 CPU 平均每秒能执行 80M ÷ 4 = 20M 条指令，故  **MIPS = 20**。
>
> ② CPU 平均每秒执行 20M 条指令，平均每条指令访存 1.5 次，则 CPU 平均每秒访存 20M × 1.5 = 30M 次。每次访存先访问 Cache，Cache 命中率为 99%，则 Cache 缺失率为 1-99% = 1%， **则平均每秒 Cache 缺失次数为 30M × 1% = 3 × 10^5 次**。③ 每次 Cache 缺失时，需要从读取 16B 数据写入 Cache， **则主存带宽至少为 3 × 10^5 × 16B = 4.8MB/s**。
>
> (2) CPU 平均每秒产生的缺页次数为  $3 \times 10^5 \times 0.0005\% = 1.5$ 次。
>
> 每页 DMA 请求次数  $= \frac{\text{页面大小}}{\text{总线宽度}} = \frac{4\text{KB}}{32\text{bit}} = 1\text{K}$，每秒 DMA 请求次数  $= \text{每秒缺页次数} \times \text{每页 DMA 请求次数} = 1.5 \times 1\text{K} = 1.5 \times \frac{1024}{1536}$ 次（注意不是 1500 次，这里  $1\text{K} \neq 1000$）。
>
> (3) DMA 控制器优先级更高。原因：DMA 用于高速外设（例如：磁盘）与主存间的数据传输，若不及时响应，外设数据会丢失（例如：磁盘缓冲区溢出）；而 CPU 访问主存的请求可以等待，不会导致数据永久性丢失。
>
> (4) 每 1/4 个存储周期启动一个体，每个存储体传输 32 位数据，则一个存储周期（50ns）内可传输  $4 \times 32\text{bit} = 128\text{bit} = 16\text{B}$ 数据，带宽  $=\frac{16\text{B}}{50\text{ns}} = 320\text{MB/s}$。
>
> ▷【提示】需注意单位。K、M 在表示数量、速度时， $1K = 10^3$、 $1M = 10^6$。K、M 在表示存储空间大小、文件大小时， $1K = 2^{10}$、 $1M = 2^{20}$。
>
> ▷【点评】概念题。①本题综合考查计组中的基本概念，后一问要用到前一问的结论（后一问在前一问的基础上计算），很容易一步错导致步步错。②另外，第(2)问“假定在 Cache 缺失的情况下访问主存时，存在 0.0005% 的缺页率”，这句话的表述很不严谨，很不妥当：缺页发生在虚实地址转换过程中，Cache 缺失发生在根据物理地址去访问主存的过程中， **只可能先发生“缺页”再发生“Cache 缺失”**。题目把顺序说反了，会让人感觉莫名其妙。

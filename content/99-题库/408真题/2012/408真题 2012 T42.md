## 题干

42. （13 分）假定采用带头结点的单链表保存单词，当两个单词有相同的后缀时，则可共享相同的后缀存储空间。例如，“loading”和“being”的存储映像如下图所示。

![[408真题 2012 T42-fig1.webp|500]]

设 `str1` 和 `str2` 分别指向两个单词所在单链表的头结点，链表结点结构为 $\boxed{\text{data}\mid\text{next}}$，请设计一个时间上尽可能高效的算法，找出由 `str1` 和 `str2` 所指向两个链表共同后缀的起始位置（如图中字符 `i` 所在结点的位置 `p`）。

要求：

（1）给出算法的基本设计思想。
（2）根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。
（3）说明你所设计算法的时间复杂度。

> [!note]- 原题截图
> ![[408真题 2012 T42.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) 算法的基本设计思想：① 计算链表长度：分别遍历两个单链表，得到它们的长度 len1 和 len2。
>
> ② 两个链表尾端对齐：设两个指针 p 和 q 分别指向两个链表的头结点。若 len1 > len2，则 p 先向后移动 len1 - len2 个结点；若 len2 > len1，则 q 先向后移动 len2 - len1 个结点。使得 p 和 q 两个指针到链表尾端的距离相等。③ 同步遍历找公共结点：让 p 和 q 同时向后移动，每次移动一个结点，直到 p 和 q 指向同一个结点，该结点即为共同后缀的起始位置。
>
> (2) 代码实现如下：
>
> // 定义单链表结点结构 typedef struct LinkNode { char data; struct LinkNode *next; } LinkNode, *LinkList; // 求单链表的表长 int getLen(LinkList L) { int count = 0; for(LinkNode *cur = L->next; cur != NULL; cur = cur->next) count++; return count; } // 查找两个单链表共同后缀起始位置 LinkNode *findCommon(LinkList str1, LinkList str2) { int len1 = getLen(str1), len2 = getLen(str2); for(LinkNode *p = str1->next; len1 > len2; len1--) // 若str1更长 p = p->next; for(LinkNode *q = str2->next; len1 < len2; len2--) // 若str2更长 q = q->next; while(p != NULL && p != q) { // 同时向后遍历，直到遍历完或指向相同结点 p = p->next; q = q->next; } return p; }
>
> (3) 时间复杂度为  $O(\max(len1, len2))$。其中，len1 和 len2 分别指两个单链表长度。

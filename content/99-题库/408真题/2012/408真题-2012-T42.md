## 题干

42. （13 分）假定采用带头结点的单链表保存单词，当两个单词有相同的后缀时，则可共享相同的后缀存储空间。例如，“loading”和“being”的存储映像如下图所示。

![[408真题-2012-T42-fig1.jpg|500]]

设 `str1` 和 `str2` 分别指向两个单词所在单链表的头结点，链表结点结构为 $\boxed{\text{data}\mid\text{next}}$，请设计一个时间上尽可能高效的算法，找出由 `str1` 和 `str2` 所指向两个链表共同后缀的起始位置（如图中字符 `i` 所在结点的位置 `p`）。

要求：

- **（1）** 给出算法的基本设计思想。
- **（2）** 根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。
- **（3）** 说明你所设计算法的时间复杂度。

> [!note]- 原题截图
> ![[408真题-2012-T42.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 先求两链表长度 m、n；让较长链表的指针先走长度差，使两指针到表尾距离相同；随后同步后移，首次指向同一结点即共同后缀起点。
> 2. ```c
> typedef struct Node { char data; struct Node *next; } SNode;
> int listlen(SNode *h){ int n=0; while(h->next){++n;h=h->next;} return n; }
> SNode *findlist(SNode *s1,SNode *s2){
>     int m=listlen(s1),n=listlen(s2); SNode *p=s1,*q=s2;
>     while(m>n){p=p->next;--m;}
>     while(n>m){q=q->next;--n;}
>     while(p->next && p->next!=q->next){p=p->next;q=q->next;}
>     return p->next;
> }
> ```
> 3. 时间复杂度 O(m+n)，空间复杂度 O(1)。
>
> **解析：** 共享后缀意味着从首个公共结点到表尾完全重合；先对齐剩余长度后同步扫描即可在线性时间找到该点。

## 题干

37. 下列关于 IP 路由器功能的描述中，正确的是（）。

I. 运行路由协议，设置路由表

II. 监测到拥塞时，合理丢弃 IP 分组

III. 对收到的 IP 分组头进行差错校验，确保传输的 IP 分组不丢失

IV. 根据收到的 IP 分组的目的 IP 地址，将其转发到合适的输出线路上

A. 仅 III、IV

B. 仅 I、II、III

C. 仅 I、II、IV

D. 仅 I、II、III、IV

> [!note]- 原题截图
> ![[408真题 2012 T37.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 路由器提供路由选择和分组转发功能。
>
> ①Ⅰ和Ⅳ正确 ✓：路由选择即运行路由协议并维护路由表，分组转发即依据IP分组目的地址，在转发表中查找下一跳进行转发。
>
> ②Ⅱ正确 ✓：当网络出现拥塞，路由器可合理丢弃分组。
>
> ③Ⅲ错误×：路由器通过重新计算IP分组首部的校验和来进行差错校验，主要是为了保证与路由相关信息（例如：目的地址）的正确性，但并不保证分组不丢失。TCP/IP网络层提供尽最大努力的数据报交付服务，分组丢失重传由上层协议（例如：传输层的TCP协议）完成。故选C。
>
> 【点评】概念题。考查路由器的功能。

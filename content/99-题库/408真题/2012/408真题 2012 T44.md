## 题干

44. （12 分）某 $16$ 位计算机中，带符号整数用补码表示，数据 Cache 和指令 Cache 分离。

题 44 表给出了指令系统中部分指令格式，其中 Rs 和 Rd 表示寄存器，mem 表示存储单元地址，（x）表示寄存器 x 或存储单元 x 的内容。

指令系统中部分指令格式

| 名称 | 指令的汇编格式 | 指令功能 |
|:---:|:---:|:---:|
| 加法指令 | `ADD Rs, Rd` | $(\mathrm{Rs})+(\mathrm{Rd})\to\mathrm{Rd}$ |
| 算术/逻辑左移 | `SHL Rd` | $2\times(\mathrm{Rd})\to\mathrm{Rd}$ |
| 算术右移 | `SHR Rd` | $(\mathrm{Rd})/2\to\mathrm{Rd}$ |
| 取数指令 | `LOAD Rd, mem` | $(\mathrm{mem})\to\mathrm{Rd}$ |
| 存数指令 | `STORE Rs, mem` | $(\mathrm{Rs})\to\mathrm{mem}$ |

该计算机采用 5 段流水方式执行指令，各流水段分别是取指（IF）、译码/读寄存器（ID）、执行/计算有效地址（EX）、访问存储器（M）和结果写回寄存器（WB），流水线采用 “按序发射，按序完成” 方式，没有采用转发技术处理数据相关，并且同一个寄存器的读和写操作不能在同一个时钟周期内进行。

请回答下列问题：

（1）若 `int` 型变量 $x$ 的值为 $-513$，存放在寄存器 R1 中，则执行指令 `SHR R1` 后，R1 的内容是多少？（用十六进制表示）
（2）若某个时间段中，有连续的 $4$ 条指令进入流水线，在其执行过程中没有发生任何阻塞，则执行这 $4$ 条指令所需的时钟周期数为多少？
（3）若高级语言程序中某赋值语句为 $x=a+b$，$x$、$a$ 和 $b$ 均为 `int` 型变量，它们的存储单元地址分别表示为 $[x]$、$[a]$ 和 $[b]$。该语句对应的指令序列及其在指令流水线中的执行过程如下图所示。

  则这 $4$ 条指令执行过程中，$I_3$ 的 ID 段和 $I_4$ 的 IF 段被阻塞的原因各是什么？
（4）若高级语言程序中某赋值语句为 $x=x\times2+a$，$x$ 和 $a$ 均为 `unsigned int` 类型变量，它们的存储单元地址分别表示为 $[x]$、$[a]$，则执行这条语句至少需要多少个时钟周期？要求模仿题 44 图画出这条语句对应的指令序列及其在流水线中的执行过程示意图。

> [!success]- 答案与解析
> **解析：**
>
> (I) ▷【解法一】 $x = -513$， $[x]_{\text{补}} = 1111\ 1101\ 1111\ 1111B$。指令“SHR R1”表示算术右移一位。算术右移，低位移出，高位补符号位（负数补1，正数补0），得到1111111011111111 = FEFFH。执行指令之后R1的内容为 FEFFH。
>
> ▷【解法二】 $x = -513$,  $x/2 = -257$,  $[-257]_{\text{补}} = 1111$ 1110 1111 1111H = FEFFH。
>
> ◇ 若 x 是正整数，则和普通除法一样（向零取整），例如：x = 513，则 x/2 = 256。
>
> ◇ 若 x 是负整数，则向负无穷取整，例如：x = -513，则 x/2 = -257（不是 -256）。
>
> ②逻辑右移和算术右移不同：逻辑右移无论正负，右边移出丢弃，左边补0。即：逻辑右移当成无符号数整体右移，和除法无关！算术右移，低位移出，高位补符号位（0正1负）。
>
> (2) 5段流水线，执行第1条指令需要5个时钟周期，之后每个时钟周期都会执行完1条指令。连续4条指令进入该流水线，执行完毕需要 $5 + (4 - 1) = 8$个时钟周期。
>
> ▷【拓展】m段流水线稳定之后（无阻塞的理想情况下），执行n条指令需要 $m+(n-1)$个时钟周期。
>
> (3) ① I3 与 I1、I2 存在数据相关。I3 必须等 I2 将数据写入寄存器 R2 后（WB 阶段之后），再从
>
> 64
>
> 寄存器 R2 中读取操作数，所以 I3 的 ID 段（读寄存器）被阻塞。
>
> ②14的IF段被阻塞，是因为13的ID段被阻塞，导致13的后一条指令14无法取指而阻塞。
>
> ▷【拓展】①传统单周期CPU，只有一个指令寄存器IR，用于存当前指令。而流水线CPU中，为了实现多指令并行执行，每段流水线之间设有独立的暂存寄存器。以5段流水线为例，段间寄存器包括IF/ID、ID/EX、EX/MEM、MEM/WB，这些寄存器不仅暂存指令，还会传递指令的完整上下文（操作数、控制信号、地址信息等），本质上替代了全局IR的作用。流水线段间寄存器完整的数据流如下（此部分内容目前教辅书中都没有，考生需 **重视**）：
>
> IF 阶段：取指令并计算 PC + 4，将指令和 PC + 4 的值送入 IF / ID 寄存器；
>
> ◇ ID 阶段：从 IF/ID 寄存器取出指令，完成译码、读寄存器堆，生成控制信号，将源操作数、目的寄存器号、控制信号等送入 ID/EX 寄存器；
>
> ◇ EX 阶段：从 ID/EX 寄存器取出数据，ALU 完成运算或地址计算，将结果和控制信号送入 EX/MEM 寄存器；
>
> ◇ MEM 阶段：从 EX/MEM 寄存器取出数据，完成内存读写（RISC 架构只有 load / store 指令能读写内存），将访存结果或 ALU 结果送入 MEM/WB 寄存器；
>
> WB 阶段：从 MEM / WB 寄存器取出数据并写回寄存器堆，完成指令的最后一步。
>
> ②例如：本题中指令I3因数据相关无法进入ID阶段，停留在IF/ID寄存器中不动。下一个时钟周期，在IF阶段若要取指令I4，则新指令无处可存：因为IF/ID寄存器还被I3占用。
>

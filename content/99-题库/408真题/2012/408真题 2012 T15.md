## 题干

15. 某计算机存储器按字节编址，采用小端方式存放数据。

假定编译器规定 int 型和 short 型长度分别为 32 位和 16 位，并且数据按边界对齐存储。

某 C 语言程序段如下：

```c
struct {
    int a;
    char b;
    short c;
} record;
record.a = 273;
```

若 record 变量的首地址为 0xC008，则地址 0xC008 中内容及 record.c 的地址分别为（）

A. 0x00、0xC00D

B. 0x00、0xC00E

C. 0x11、0xC00D

D. 0x11、0xC00E

> [!note]- 原题截图
> ![[408真题 2012 T15.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** C语言中int类型占4B、char类型占1B、short类型占2B。按字节编址，则一个字节占一个地址单元。结构体按边界对齐，包括两个方面：
>
> ◇ 结构体整体对齐：要求结构体总长 = 最大成员大小的整数倍（否则在末尾继续填充）；
>
> ◇ 结构体数据成员对齐：每个数据成员的起始地址 = 自身大小整数倍，可能导致结构体成员之间要填充若干字节，使得成员对齐。
>
> 因为 record.c 是 short 类型（2B），所以 record.c 的起始地址必须是 2 的整数倍，所以 record.b 和 record.c 之间要填充一个字节。273 = 0000 0111H。按小端方式存放，则低地址存放低位字节，高地址存放高位字节。最终存储结果如下图所示。故选 D。
>
> | 地址 | C008H | C009H | C00AH | C00BH | C00CH | C00DH | C00EH | C00FH |
> |---|---|---|---|---|---|---|---|---|
> | 变量 | a | a | a | a | b | 填充 | c | c |
> | 机器数 | 11H | 01H | 00H | 00H |  |  |  |  |
>
> ▷【提示】结构体填充只可能发生在结构体成员之间和末尾，不可能发生在结构体开头。因为结构体的起始地址，就是第一个成员的起始地址。
>
> 【点评】难题。本题全面考查了C语言结构体在计算机中的存储，综合考查了边界对齐、小端方式、不同类型变量所占字节等多个考点。适合作为典型例题理解记忆。2020年408第14题是本题的改编，会做此题，那题也会。

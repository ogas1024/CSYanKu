## 题干

42. （15 分）已知一个带有表头结点的单链表，结点结构为：

| data | link |
|:---:|:---:|

假设该链表只给出了头指针 $list$。在不改变链表的前提下，请设计一个尽可能高效的算法，查找链表中倒数第 $k$ 个位置上的结点（$k$ 为正整数）。若查找成功，算法输出该结点的 $data$ 域的值，并返回 $1$；否则，只返回 $0$。要求：

（1）描述算法的基本设计思想。
（2）描述算法的详细实现步骤。
（3）根据设计思想和实现步骤，采用程序设计语言描述算法（使用 C、C++ 或 Java 语言实现），关键之处请给出简要注释。

> [!success]- 答案与解析
> **解析：**
>
> (1) 算法思想：定义两个指针 p 和 q，初始均指向头结点的下一个结点。当 p 指针移动到链表第 k 个结点时，p 和 q 指针开始同步移动。当 p 指针遍历到链表最后一个结点时，q 指针正好指向链表的倒数第 k 个结点。
>
> (2) 算法步骤如下：
>
> (a) 初始化  $p = \text{list}-\text{next}$,  $q = \text{list}-\text{next}$, count = 0;
>
> (b) p = p -> next, count++, 若 p -> next 为空，跳转至 (f);
>
> (c) 如果 count < k，跳转 (b)，否则跳转 (d);
>
> (d) p = p -> next, q = q -> next;
>
> (e) 如果 p 为空，则跳转 (f)，否则跳转 (d);
>
> (f) 如果 count == k，输出 q->data，返回 1，否则返回 0。
>
> (3) 代码实现如下：
>
> typedef struct LinkNode { ElemType data; LinkNode *link; } LinkNode, *LinkList; int findK(LinkList L, int k) { LinkNode *p = L->link, *q = L->link; int count = 0; for (; p != NULL; p = p->link) { if (count < k) { count++; } else { q = q->link; } } if (count < k) return 0; else { printf("%d", q->data); return 1; } }
>

>
> ▷【点评】常规题。本题考查链表的遍历。双指针遍历常用对线性表的处理，尤其是链表。考生应当熟练掌握双指针，以及其变式（比如快慢指针）。

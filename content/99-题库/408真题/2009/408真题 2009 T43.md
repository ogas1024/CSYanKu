## 题干

43. （8 分）某计算机的 CPU 主频为 $500\,\mathrm{MHz}$，CPI 为 $5$（即执行每条指令平均需 $5$ 个时钟周期）。假定某外设的数据传输率为 $0.5\,\mathrm{MB/s}$，采用中断方式与主机进行数据传送，以 $32$ 位为传输单位，对应的中断服务程序包含 $18$ 条指令，中断服务的其他开销相当于 $2$ 条指令的执行时间。

请回答下列问题，要求给出计算过程。

（1）在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？
（2）当该外设的数据传输率达到 $5\,\mathrm{MB/s}$ 时，改用 DMA 方式传送数据。假定每次 DMA 传送块大小为 $5000\,\mathrm{B}$，且 DMA 预处理和后处理的总开销为 $500$ 个时钟周期，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少（假设 DMA 与 CPU 之间没有访存冲突）？

> [!note]- 原题截图
> ![[408真题 2009 T43.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 32 位即 4 B，每秒中断次数为
> $$\frac{0.5\times10^6}{4}=125000。$$
> 每次中断耗时相当于 $18+2=20$ 条指令，即 $20\times5=100$ 个时钟周期。每秒占用 $12.5\times10^6$ 周期，占 500 MHz CPU 的
> $$\frac{12.5M}{500M}=2.5\%。$$
>
> 2. 每秒 DMA 次数为
> $$\frac{5\times10^6}{5000}=1000。$$
> CPU 每秒用于预处理和后处理的周期为 $1000\times500=0.5M$，占比
> $$\frac{0.5M}{500M}=0.1\%。$$
>
> **解析：** 分别把数据率换成每秒中断次数或 DMA 块次数，再乘每次 CPU 开销；DMA 传输本身与 CPU 并行且题设排除了访存冲突。

## 题干

43. （8 分）某计算机的 CPU 主频为 $500\,\mathrm{MHz}$，CPI 为 $5$（即执行每条指令平均需 $5$ 个时钟周期）。假定某外设的数据传输率为 $0.5\,\mathrm{MB/s}$，采用中断方式与主机进行数据传送，以 $32$ 位为传输单位，对应的中断服务程序包含 $18$ 条指令，中断服务的其他开销相当于 $2$ 条指令的执行时间。

请回答下列问题，要求给出计算过程。

（1）在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？
（2）当该外设的数据传输率达到 $5\,\mathrm{MB/s}$ 时，改用 DMA 方式传送数据。假定每次 DMA 传送块大小为 $5000\,\mathrm{B}$，且 DMA 预处理和后处理的总开销为 $500$ 个时钟周期，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少（假设 DMA 与 CPU 之间没有访存冲突）？

> ![[408真题 2009 T43.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) 外设的数据传输率是 0.5MB/s。采用中断进行数据传输时，每次为 32 位 (4B)。外设如果想要达到 0.5MB/s 的数据传输率，外设每秒的中断次数为 0.5MB/4B = 125000 = 0.125M，CPU 在中断方式下每次用于数据传送的时钟周期为 (18 + 2) × 5 = 100，则 1s 内用于中断的时间为 100 × 125000 = 12.5M 个时钟周期。所以 CPU 用于外设 I/O 的时间占整个 CPU 时间的百分比，等于 1s 内用于中断的时间开销 ÷ 整个 CPU 时间 = 12.5M ÷ 500M = 2.5%。
>
> (2) DMA 方式每次传送的大小是 5000B，当数据传输率为 5MB/s 时，每秒 DMA 的次数为 5MB ÷ 5000B = 1000。CPU 每秒用于 DMA 处理的总开销：每次 DMA 总开销 × 每秒 DMA 次数 = 500 × 1000 = 500000 = 0.5M 个时钟周期。则 CPU 在 DMA 方式下，用于外设的时间占整个 CPU 时间的百分比为 0.5M ÷ 500M = 0.1%。
>
> ▷【点评】概念题。本题分别考查中断方式、DMA方式下的计算，比较基础。

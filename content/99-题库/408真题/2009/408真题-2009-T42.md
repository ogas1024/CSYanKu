## 题干

42. （15 分）已知一个带有表头结点的单链表，结点结构为：

| data | link |
|:---:|:---:|

假设该链表只给出了头指针 $list$。在不改变链表的前提下，请设计一个尽可能高效的算法，查找链表中倒数第 $k$ 个位置上的结点（$k$ 为正整数）。若查找成功，算法输出该结点的 $data$ 域的值，并返回 $1$；否则，只返回 $0$。要求：

- **（1）** 描述算法的基本设计思想。
- **（2）** 描述算法的详细实现步骤。
- **（3）** 根据设计思想和实现步骤，采用程序设计语言描述算法（使用 C、C++ 或 Java 语言实现），关键之处请给出简要注释。

> [!success]- 答案与解析
> **答案：**
>
> 设计两个指针，只扫描链表一次。先让 `fast` 从首元结点向前走 $k$ 步；若途中到达空指针，则链表长度小于 $k$，返回 0。再令 `slow` 指向首元结点，使两指针同步前进，直到 `fast == NULL`，此时 `slow` 正好指向倒数第 $k$ 个结点。
>
> ```c
> int SearchK(LinkList list, int k) {
>     if (list == NULL || k <= 0) return 0;
>     LNode *fast = list->link;
>     LNode *slow = list->link;
>     for (int i = 0; i < k; ++i) {
>         if (fast == NULL) return 0;
>         fast = fast->link;
>     }
>     while (fast != NULL) {
>         fast = fast->link;
>         slow = slow->link;
>     }
>     printf("%d", slow->data);
>     return 1;
> }
> ```
>
> 时间复杂度为 $O(n)$，辅助空间复杂度为 $O(1)$，且不修改链表。
>
> **解析：** 先保持两指针间距为 k，再同步移动；fast 到表尾时，slow 到表尾的结点数恰为 k。显式检查 k 和空链表可避免越界。

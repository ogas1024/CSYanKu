## 题干

45. （7 分）三个进程 $P_1$、$P_2$、$P_3$ 互斥使用一个包含 $N$（$N>0$）个单元的缓冲区。$P_1$ 每次用 `produce()` 生成一个正整数并用 `put()` 送入缓冲区某一空单元中；$P_2$ 每次用 `getodd()` 从该缓冲区中取出一个奇数并用 `countodd()` 统计奇数个数；$P_3$ 每次用 `geteven()` 从该缓冲区中取出一个偶数并用 `counteven()` 统计偶数个数。

请用信号量机制实现这三个进程的同步与互斥活动，并说明所定义信号量的含义（要求用伪代码描述）。

> [!note]- 原题截图
> ![[408真题 2009 T45.png]]

> [!success]- 答案与解析
> **答案：**
>
> 设 `empty=N` 表示空单元数，`odd=0`、`even=0` 分别表示缓冲区内可取的奇数、偶数个数，`mutex=1` 保护缓冲区。
>
> ```text
> P1: while true {
>     x = produce();
>     P(empty); P(mutex); put(x); V(mutex);
>     if (x % 2) V(odd); else V(even);
> }
>
> P2: while true {
>     P(odd); P(mutex); x = getodd(); V(mutex); V(empty);
>     countodd(x);
> }
>
> P3: while true {
>     P(even); P(mutex); x = geteven(); V(mutex); V(empty);
>     counteven(x);
> }
> ```
>
> 先等待类别计数、再申请互斥锁，消费者不会在持锁时等待尚不存在的数据；取出后释放一个空单元。
>
> **解析：** empty 约束总容量，odd/even 将不同消费者与生产结果精确配对，mutex 使 put/get 对共享缓冲区互斥；P/V 次序避免消费者持锁等待。

## 题干

39. 假设客户 C 和服务器 S 已建立一个 TCP 连接，通信往返时间 RTT=50ms，最长报文段寿命 MSL=800ms，数据传输结束后，C 主动请求断开连接。

若从 C 主动向 S 发出 FIN 段时刻算起，则 C 和 S 进入 CLOSED 状态所需的时间至少分别是（）

A. 850ms, 50ms

B. 1650ms, 50ms

C. 850ms, 75ms

D. 1650ms, 75ms

> [!note]- 原题截图
> ![[408真题 2022 T39.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 本题示意图如下图所示。本题考查 TCP 连接释放的特殊情况。题目要求的是所需的最短时间，故第2次和第3次挥手 $\underset{\cdot}{同}\underset{\cdot}{时}$进行，即服务器 S 同时发出 ACK 确认报文和 FIN 连接释放报文，且服务器收到客户 C 的连接释放请求后，不再发送数据。也就是忽略下图中客户 C 的 FIN-WAIT-2 状态，忽略服务器 S 的 CLOSE-WAIT 状态。客户 C 收到服务器 S 的连接释放确认报文后，还需要经历 2MSL 时间的最后等待才进入 CLOSED 状态（这段时间是为了防止已经失效的报文重新出现在网络中）。①客户 C 从发送 FIN 连接释放报文到收到服务器 S 发出 ACK 确认报文，需要 1RTT，故客户 C 进入 CLOSED 状态至少需要 1RTT + 2MSL =
>
> 50ms + 1600ms = 1650ms。②当服务器 S 收到客户 C 的连接释放确认报文后，进入 CLOSED 状态。服务器 S 收到客户 C 的 FIN 连接释放报文需要 0.5RTT，服务器 S  $\underset{\cdot}{同}$时发出的 ACK 确认报文和 FIN 连接释放报文 $\underset{\cdot}{到}\underset{\cdot}{达}$客户 C 需要 0.5RTT，服务器 S 收到客户 C 发出的 ACK 确认报文需要 0.5RTT，故服务器 S 至少需要 0.5RTT + 0.5RTT + 0.5RTT = 75ms 进入 CLOSED 状态。
>
> ▷【点评】难题。一般来说，TCP 连接释放需要经历 4 次挥手，所有 408 相关的教材教辅中都会介绍这个考点。然而本题却考查 TCP 连接释放的特殊情况，这些特殊情况在常见教辅中没有，甚至一些教材中都没有介绍。首次遇到这种题的话，确实容易出错。但在 2024 年 408 又考到了类似的特殊情况！

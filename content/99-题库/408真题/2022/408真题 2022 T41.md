## 题干

41. （13分）已知非空二叉树 T 的结点值均为正整数，采用顺序存储方式保存，数据结构定义如下：

```c
typedef struct {    //MAX_SIZE 为已定义常量
        int SqBiTNode[MAX_SIZE];    //保存二叉树结点值的数组
        int ElemNum;     //实际占用的数组元素个数
} SqBiTree;
```

T 中不存在的结点在数组 SqBiTNode 中用 -1 表示。

例如，对于下图所示的两棵非空二叉树 T1 和 T2：

![[408真题 2022 T41-fig1.jpg]]

二叉树 T1

![[408真题 2022 T41-fig2.jpg]]

二叉树 T2

T1 的存储结果如下:

T1.SqBiTNode

| 40 | 25 | 60 | -1 | 30 | -1 | 80 | -1 | -1 | 27 |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

T1.ElemNum=10

T2 的存储结果如下:

T2.SqBiTNode

| 40 | 50 | 60 | -1 | 30 | -1 | -1 | -1 | -1 | -1 | 35 |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

T2.ElemNum=11

请设计一个尽可能高效的算法，判定一棵采用这种方式存储的二叉树是否为二叉搜索树，若是，则返回 true，否则，返回 false.

要求：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

> [!note]- 原题截图
> ![[408真题 2022 T41.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 二叉搜索树的中序遍历序列严格递增。按顺序存储下标递归进行中序遍历，用 `val` 记录已访问结点的最大值；若当前值不大于 `val`，立即返回 `false`，否则更新 `val` 并继续右子树。
> 2. ```c
> bool judgeInOrderBST(SqBiTree bt, int k, int *val) {
>     if (k >= bt.ElemNum || bt.SqBiTNode[k] == -1) return true;
>     if (!judgeInOrderBST(bt, 2*k + 1, val)) return false;
>     if (bt.SqBiTNode[k] <= *val) return false;
>     *val = bt.SqBiTNode[k];
>     return judgeInOrderBST(bt, 2*k + 2, val);
> }
>
> bool judgeBST(SqBiTree bt) {
>     int val = -1;  // 结点值均为正整数
>     return judgeInOrderBST(bt, 0, &val);
> }
> ```
>
> **解析：** 顺序存储中下标 $k$ 的左右孩子分别为 $2k+1$、$2k+2$。对存在的结点做一次中序遍历即可，时间复杂度 $O(n)$，递归栈空间 $O(h)$。

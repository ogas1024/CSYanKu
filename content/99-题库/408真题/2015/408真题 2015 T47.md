## 题干

47. （9 分）某网络拓扑如下图所示，其中路由器内网接口、DHCP 服务器、WWW 服务器与主机 1 均采用静态 IP 地址配置，相关地址信息见图中标注；

主机 2～主机 N 通过 DHCP 服务器动态获取 IP 地址等配置信息。

![[408真题 2015 T47-fig1.webp|500]]

请回答下列问题。

- **（1）** DHCP 服务器可为主机 2～主机 N 动态分配 IP 地址的最大范围是什么？主机 2 使用 DHCP 协议获取 IP 地址的过程中，发送的封装 DHCP Discover 报文的 IP 分组的源 IP 地址和目的 IP 地址分别是什么？

- **（2）** 若主机 2 的 ARP 表为空，则该主机访问 Internet 时，发出的第一个以太网帧的目的 MAC 地址是什么？封装主机 2 发往 Internet 的 IP 分组的以太网帧的目的 MAC 地址是什么？

- **（3）** 若主机 1 的子网掩码和默认网关分别配置为 `255.255.255.0` 和 `111.123.15.2`，则该主机是否能访问 WWW 服务器？是否能访问 Internet？请说明理由。

> [!note]- 原题截图
> ![[408真题 2015 T47.webp]]

> [!success]- 答案与解析
> **解析：**
>
> (1) DHCP 服务器所在网络为 111.123.15.0/24，除去网络地址 111.123.15.0、已分配的静态地址 111.123.15.1～111.123.15.4 以及广播地址 111.123.15.255，可分配给主机 2～主机 N 的 IP 地址范围是 111.123.15.5～111.123.15.254。
>
> DHCP Discover 报文的 IP 分组的源 IP 地址和目的 IP 地址分别是 0.0.0.0、255.255.255.255。主机目前没有分配到 IP 地址，所以源 IP 地址为 0.0.0.0；因为主机不知道网络中 DHCP 服务器的 IP 地址是什么，所以广播发送 DHCP Discover 报文，即目的 IP 地址为 255.255.255.255，让本地网络所有主机都能收到该报文，但只有 DHCP 服务器才对此报文做出回应。
>
> (2) 主机 2 发出的第一个以太网帧封装的是 ARP 请求报文，使用 MAC 广播地址 ff-ff-ff-ff-ff-ff。由于是访问 Internet，路由器对 ARP 请求报文做出应答。随后封装主机 2 发往 Internet 的 IP 分组的以太网帧的目的 MAC 地址是路由器的 MAC 地址，即 00-a1-a1-a1-a1-a1。
>
> (3) ① 该主机能访问 WWW 服务器。WWW 服务器与主机 1 在同一子网（111.123.15.0/24），主机 1 通过 ARP 直接获取 WWW 服务器的 MAC 地址，不需要经过网关，因此网关配置错误不影响同子网通信。
>
> ②该主机不能访问 Internet**。访问 Internet 需要将 IP 分组发送给默认网关转发，但主机 1 配置的网关 111.123.15.2 是 DHCP 服务器而非路由器，该主机不会将分组转发到外网，因此无法访问 Internet。
>
> 【点评】常规题。综合考查DHCP工作过程、ARP协议、MAC地址封装、子网划分与网关作用，是一道常规的计网综合题，是常见考点的常规考法。

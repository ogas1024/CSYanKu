## 题干

16. 假定编译器将赋值语句 `x=x+3;` 转换为指令 `add xaddr, 3`，其中 `xaddr` 是 `x` 对应的存储单元地址。

若执行该指令的计算机采用页式虚拟存储管理方式，并配有相应的 TLB，且 Cache 使用直写（Write Through）方式，则完成该指令功能需要访问主存的次数至少是（）。

A. 0

B. 1

C. 2

D. 3

> [!note]- 原题截图
> ![[408真题 2015 T16.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 指令“add xaddr,3”的功能：将x对应存储单元处的数据加3后，再写回x对应的存储单元。执行过程如下：
>
> ① 取指：CPU 根据虚拟地址去访存，TLB 命中，完成虚拟地址到物理地址的转换。根据物理地址访存时，Cache 命中，从 Cache 中获取指令内容。若 TLB 和 Cache 均命中，则取指阶段无需访问内存。
>
> ②取数：从主存取出操作数x。若x已在Cache中（Cache命中），则直接从Cache读取，不访问主存；题目问“至少”，按Cache命中情形考虑，此步访存0次。
>
> ③运算：加法在CPU内部ALU中完成，不访问主存。
>
> ④ 写回：将运算结果写入 x 对应的存储单元。直写法（Write Through）的特点是：写 Cache 命中的同时必须把数据写入主存，以保证 Cache 与主存内容一致。因此即使写 Cache 命中，也必须访问主存 1 次。
>
> 故整个过程至少访问主存1次，故选B。
>
> 【提示】若本题改为回写法（Write Back），写命中时只更新 Cache 并置脏位，不立即写主存，则至少访存 0 次。
>
> 【点评】难题。综合考查指令执行过程中的访存分析，涉及 Cache、TLB 和写策略，难度较大。

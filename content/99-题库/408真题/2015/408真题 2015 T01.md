## 题干

1. 已知程序如下：

```cpp
int S(int n)
{
    return (n <= 0) ? 0 : s(n - 1) + n;
}
void main()
{
    cout << S(1);
}
```

程序运行时使用栈来保存调用过程的信息，自栈底到栈顶保存的信息依次对应的是（）。

A. `main()` → `S(1)` → `S(0)`

B. `S(0)` → `S(1)` → `main()`

C. `main()` → `S(0)` → `S(1)`

D. `S(1)` → `S(0)` → `main()`

> [!note]- 原题截图
> ![[408真题 2015 T01.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 递归函数的调用顺序与执行顺序相反。最先执行 main() 函数，main() 函数里调用了 S(1)，S(1) 里面又递归调用了 S(0)，即 main()、S(1)、S(0) 依次进栈，故选 A。
>
> 【点评】常规题。考查栈“后进先出”的特点。

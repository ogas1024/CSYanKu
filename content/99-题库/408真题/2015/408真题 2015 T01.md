## 题干

1. 已知程序如下：

```cpp
int S(int n)
{
    return (n <= 0) ? 0 : s(n - 1) + n;
}
void main()
{
    cout << S(1);
}
```

程序运行时使用栈来保存调用过程的信息，自栈底到栈顶保存的信息依次对应的是（）。

A. `main()` → `S(1)` → `S(0)`

B. `S(0)` → `S(1)` → `main()`

C. `main()` → `S(0)` → `S(1)`

D. `S(1)` → `S(0)` → `main()`

> [!note]- 原题截图
> ![[408真题 2015 T01.png]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 递归调用时活动记录依次压栈。执行到 S(0) 时，栈底到栈顶依次为 main()、S(1)、S(0)，故 A。

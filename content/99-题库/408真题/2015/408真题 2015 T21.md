## 题干

21. 在采用中断 I/O 方式控制打印输出的情况下，CPU 和打印控制接口中的 I/O 端口之间交换的信息不可能是（）。

A. 打印字符

B. 主存地址

C. 设备状态

D. 控制命令

> [!note]- 原题截图
> ![[408真题 2015 T21.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 在程序中断 I/O 方式下，CPU 通过 I/O 端口与打印机交互，交换的信息包括：
>
> ◇ 数据信息：例如，要打印的字符、从键盘读入的代码等，经数据总线在接口的数据缓冲寄存器与 CPU 之间传送。
>
> ◇ 状态信息：接口向 CPU 报告设备“就绪”、“忙”、“出错”等状态，供 CPU 查询或在中断服务中判断处理。
>
> ◇ 命令信息（控制信息）：CPU 向接口发出的启动、停止、读写方式等控制命令，写入接口的控制寄存器。
>
> 中断 I/O 方式下，数据的最终去向由 CPU 执行传送指令决定，并不需要在 I/O 接口与 CPU 之间专门传送主存地址。只有 DMA 方式中，DMA 控制器需要接管总线、自行向主存发出地址以完成数据块的直接传送，主存地址寄存器才成为 DMA 接口的核心部件。故选 D。
>
> 【点评】易错题。本题考查中断 I/O 方式中 CPU 与 I/O 端口交换的信息类型，考的很细致。

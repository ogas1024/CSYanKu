## 题干

47. （9 分）某网络拓扑如下图所示，其中路由器内网接口、DHCP 服务器、WWW 服务器与主机 1 均采用静态 IP 地址配置，相关地址信息见图中标注；

主机 2～主机 N 通过 DHCP 服务器动态获取 IP 地址等配置信息。

![[408真题-2015-T47-fig1.jpg|500]]

请回答下列问题。

- **（1）** DHCP 服务器可为主机 2～主机 N 动态分配 IP 地址的最大范围是什么？主机 2 使用 DHCP 协议获取 IP 地址的过程中，发送的封装 DHCP Discover 报文的 IP 分组的源 IP 地址和目的 IP 地址分别是什么？

- **（2）** 若主机 2 的 ARP 表为空，则该主机访问 Internet 时，发出的第一个以太网帧的目的 MAC 地址是什么？封装主机 2 发往 Internet 的 IP 分组的以太网帧的目的 MAC 地址是什么？

- **（3）** 若主机 1 的子网掩码和默认网关分别配置为 `255.255.255.0` 和 `111.123.15.2`，则该主机是否能访问 WWW 服务器？是否能访问 Internet？请说明理由。

> [!note]- 原题截图
> ![[408真题-2015-T47.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. DHCP 可分配的主机地址范围为 `111.123.15.5`～`111.123.15.254`；DHCP Discover 的源 IP 为 `0.0.0.0`，目的 IP 为 `255.255.255.255`。
> 2. 首个以太网帧的目的 MAC 为 `ff-ff-ff-ff-ff-ff`；访问 Internet 时发往默认网关，目的 MAC 为 `00-a1-a1-a1-a1-a1`。
> 3. 主机 1 能访问同一子网内的 WWW 服务器，但不能访问 Internet，因为其默认网关错配为 `.2`，正确网关应为 `.1`。
>
> **解析：** 初始 DHCP 客户端尚无地址且不知道服务器位置，故使用本地广播；跨网段通信的二层目的地址是默认网关 MAC，网关配置错误会阻断外网访问。

## 题干

41. （15分）已知无向连通图G由顶点集V和边集E组成，|E|>0，当G中度为奇数的顶点个数为不大于2的偶数时，G存在包含所有边且长度为|E|的路径（称为EL路径）。

设图G采用邻接矩阵存储，类型定义如下：

```c
typedef struct {              // 图的类型定义
    int numVertices, numEdges; // 图中实际的顶点数和边数
    char VerticesList[MAXV];   // 顶点表，MAXV 为已定义常量
    int Edge[MAXV][MAXV];      // 邻接矩阵
} MGraph;
```

请设计算法 int IsExistEL(MGraph G)，判断 G 是否存在 EL 路径，若存在，则返回 1，否则返回 0。

要求：

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

（3）说明你所设计算法的时间复杂度和空间复杂度。

> [!success]- 答案与解析
> **解析：**
>
> (1) 算法的基本设计思想：在无向图的邻接矩阵中，某行（或列）非零元素个数之和为该行对应顶点的度。遍历邻接矩阵，计算各顶点的度，并统计其中度为奇数的顶点个数 count。遍历结束后，根据题目定义，若 count 为 0 或 2（不大于 2 的偶数，0 也是偶数），则返回 1，否则返回 0。
>
> (2) C 语言代码算法描述如下：
>
> // 算法功能：遍历图的邻接矩阵，计算各顶点的度，并统计顶点的度为0 int isExistEL(MGraph G) { int degree = 0; // 暂存当前正在计算的顶点的度 int count = 0; // 度为奇数的顶点个数 for (int i = 0; i < G.numVertices; i++) { degree = 0; // degree用于记录当前所求顶点的度 for (int j = 0; j < G.numVertices; j++) { if (G.Edge[i][j] != 0) { // 两个顶点之间存在边 degree += 1; } } if (degree % 2 == 1) // 判断该顶点的度是否为奇数 count++; // 度为奇数的顶点个数加一 } if (count == 0 || count == 2) // 判断度为奇数的顶点个数 return 1; else return 0; }
>
> (3) 本答案给出的参考代码，时间复杂度为  $O(n^2)$（ $n$ 为图  $G$ 的顶点数），空间复杂度为  $O(1)$。
>

## 题干

15. 某计算机的存储器总线中有 24 位地址线和 32 位数据线，按字编址，字长为 32 位。

如果 00 0000H～3F FFFFH 为 RAM 区，那么需要  $512K \times 8$ 位的 RAM 芯片数为（）。

A. 8

B. 16

C. 32

D. 64

> [!note]- 原题截图
> ![[408真题 2021 T15.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** RAM 区有 $3FFFFH-000000H + 1H = 400000H = 2^{22}$ 个地址，按字编址，则一个地址表示 4B 的存储空间，故 RAM 区总大小为  $2^{22} \times 4B = 2^{24}B = 16MB$。而单个 RAM 芯片大小为 512KB，所以总共需要  $16MB \div 512KB = 32$ 片 RAM 芯片。
>
> 【点评】常规题。本题容易误选 A。易错点是“按字编址”，一个地址表示 4B 的存储空间。这跟常见的“按字节编址”，一个地址表示 1B 的存储空间不同。

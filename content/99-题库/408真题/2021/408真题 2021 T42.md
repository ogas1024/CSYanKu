## 题干

42. （8分）已知某排序算法如下：

```c
void cmpCountSort(int a[], int b[], int n)
{
    int i, j, *count;
    count = (int *)malloc(sizeof(int)*n);

    //C++语言：count=new int[n];
    for (i=0; i<n; i++)     count[i]=0;
    for (i=0; i<n-1; i++)
        for (j=i+1; j<n; j++)
            if (a[i]<a[j])     count[j]++;
            else     count[i]++;
    for (i=0; i<n; i++)     b[count[i]]=a[i];
    free(count);     //C++语言：delete count;
}
```

请回答下列问题。

（1）若有 `int a[]={25,-10,25,10,11,19}`，`b[6]`；

则调用 `cmpCountSort(a,b,6)` 后数组 b 中的内容是什么？

（2）若 a 中含有 n 个元素，则算法执行过程中，元素之间的比较次数是多少？

（3）该算法是稳定的吗？若是，则阐述理由；

否则，修改为稳定排序算法。

> [!success]- 答案与解析
> **解析：**
>
> (1) b={-10,10,11,19,25,25}。题中的算法是一个基于比较的排序算法（采用了计数排序思想）。代入题目给出的数据，跟着代码手工运行推导一遍即可。第2和第3个for循环内容是排序算法的主体。count[x]=y，表示数组中有a中有y（count[x]）个元素比a[x]小。y（count[x]）越大表示比a[x]小的元素越多，a[x]在新数组b中的排序就越靠后。算法比较结束后最终count数组的值为{5,0,4,1,2,3}，根据count数组的值可得数组b的值。
>
> (2) 元素之间的比较次数是  $\frac{n(n-1)}{2}$。第一个元素会与后面 n-1 个元素逐个比较，共比较 n-1 次；第二个元素会与后面的 n-2 个元素逐个比较，共比较 n-2 次；…；第 n-1 个元素会与最后一个元素比较，共比较 1 次。总比较次数为  $(n-1)+(n-2)+\cdots+1=n(n-1)/2$ 次。
>
> (3) 该算法是不稳定的。将程序中的 if 的判断条件改为 “if (a[i] <= a[j])”，即可变为稳定的算法。根据第一问中两个 25 就可以看出，根据代码，第一个 25（a[0]）是最大的，放到了 b[5] 位置，第二个 25（a[2]）放在了 b[4] 位置，所以是不稳定的。将条件变化之后，a[0] 放在了 b[4] 位置，a[2] 放在了 b[5] 位置。
>
> ▷【点评】常规题。这题其实是考查对C语言代码的理解，不涉及数据结构的内容，更非数据结构这个科目的主干内容，其实是不适合在408中考查的，在C语言考试中考这种题比较合适。这也是迄今为止（2009～2025）408中唯一一次考这种题。单纯从代码中，看不出这段代码的含义，但把题目给出的数据代入到代码中，手工运行一遍即可发现这段代码实现的功能（代码题都是这种解题套路）。处理起来比较费时间。

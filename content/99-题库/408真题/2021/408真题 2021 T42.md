## 题干

42. （8分）已知某排序算法如下：

```c
void cmpCountSort(int a[], int b[], int n)
{
    int i, j, *count;
    count = (int *)malloc(sizeof(int)*n);

    //C++语言：count=new int[n];
    for (i=0; i<n; i++)     count[i]=0;
    for (i=0; i<n-1; i++)
        for (j=i+1; j<n; j++)
            if (a[i]<a[j])     count[j]++;
            else     count[i]++;
    for (i=0; i<n; i++)     b[count[i]]=a[i];
    free(count);     //C++语言：delete count;
}
```

请回答下列问题。

（1）若有 `int a[]={25,-10,25,10,11,19}`，`b[6]`；

则调用 `cmpCountSort(a,b,6)` 后数组 b 中的内容是什么？

（2）若 a 中含有 n 个元素，则算法执行过程中，元素之间的比较次数是多少？

（3）该算法是稳定的吗？若是，则阐述理由；

否则，修改为稳定排序算法。

> [!note]- 原题截图
> ![[408真题 2021 T42.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 调用后 `b={-10,10,11,19,25,25}`。
> 2. 元素间比较次数为 $n(n-1)/2$。
> 3. 原算法不稳定。应将比较语句改为：
>
> ```c
> if (a[i] <= a[j]) count[j]++;
> else count[i]++;
> ```
>
> 这样相等元素比较时，后出现元素的计数增加，从而保持原有先后次序。
>
> **解析：** `count[i]` 表示严格小于 a[i] 的元素数并据此确定目标下标；双重循环让每对元素恰比较一次。加入等号后相等键值的原序稳定保留。

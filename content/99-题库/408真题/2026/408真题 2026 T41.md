## 题干

41. （本题 13 分）已知二叉搜索树采用二叉链表存储，类型定义如下：

```c
typedef struct BSTNode                  //二叉搜索树结点
{   int data;                           //保存结点的关键字值
    struct BSTNode *left, *right;       //指向左孩子、右孩子的指针
} BinTNode;
typedef BinTNode *BTree;                //二叉搜索树
```

对于给定的非空二叉搜索树 $T$（root 为指向 $T$ 的根结点的指针）和整数 $k$，请设计尽可能高效的查找算法：`void searchX(BTree root, int k)`，查找 $T$ 中其关键字值与 $k$ 之差的绝对值最小的所有结点，输出差值的绝对值和结点中的关键字值。要求：

（1）给出算法的基本设计思想。（4 分）

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。（9 分）

> [!success]- 答案与解析
> **官方答案要点：**
>
> （1）算法的基本设计思想
>
> 按照在二叉搜索树中查找目标 $k$ 的方法，从根开始沿着某条向下的路径进行查找。若当前结点中的关键字值与 $k$ 相等，则结果只包含一个结点，差值的绝对值为 0，不相等时，结果最多包含两个结点，差值的绝对值大于 0。
>
> 对于不相等的情况，若当前结点中的关键字值大于 $k$，则结果只可能是当前结点或/及左子树中的结点，此时沿 left 指针继续查找。若当前结点中的关键字值小于 $k$，则结果只可能是当前结点或/及右子树中的结点，此时沿 right 指针继续查找。直到遇到空指针时为止。
>
> （2）算法实现
>
> ```c
> void searchX(BTree root, int k)
> {   BTree p = root, pmin1, pmin2;
>     int min = MAX;                          //MAX 为能表示的整型最大值
>     if (p == NULL) return;                  //若为空树，则返回
>     while (p != NULL)
>     {   if (p->data == k)                   //结果只包含一个结点
>         {   min = 0;
>             printf("差值绝对值 = %d 结点 = %d\n", min, p->data);
>             return;
>         }
>         else if (abs(p->data - k) < min)    //出现差值绝对值更小的结点
>         {   min = abs(p->data - k);
>             pmin1 = pmin2 = p;
>         }
>         else if (abs(p->data - k) == min)   //出现另一个差值绝对值为 min 的结点
>             pmin2 = p;
>         if (p->data > k)
>             p = p->left;    //若当前结点的 data>k，则结果还可能在左子树中
>         else
>             p = p->right;   //若当前结点的 data<k，则结果还可能在右子树中
>     }
>     if (pmin1->data != pmin2->data)
>         printf("差值绝对值 = %d 结点 1 = %d 结点 2 = %d\n", min, pmin1->data, pmin2->data);
>     else
>         printf("差值绝对值 = %d 结点 = %d\n", min, pmin1->data);
>     return;
> }
> ```
>
> **解析（据官方答案整理推导）：**
>
> **为什么只需查一条路径。** 二叉搜索树的中序序列递增（关键字互不相同）。与 $k$ 之差绝对值最小的结点，只可能是“不大于 $k$ 的最大关键字”所在结点（$k$ 的前驱）或“不小于 $k$ 的最小关键字”所在结点（$k$ 的后继）。在当前结点 $p$ 处：
>
> - 若 `p->data` $>k$，则 $p$ 的右子树中所有关键字都大于 `p->data`，与 $k$ 的距离都比 $p$ 更远，不可能是答案；答案只可能是 $p$ 本身或左子树中的结点，所以向左走。
> - 若 `p->data` $<k$，则 $p$ 的左子树中所有关键字都小于 `p->data`，离 $k$ 比 $p$ 更远，答案只可能是 $p$ 本身或右子树中的结点，所以向右走。
> - 若 `p->data` $=k$，差值为 0 已是最小，且关键字不重复，结果只有这一个结点，直接输出返回。
>
> 因此只需沿“查找 $k$”的路径从根走到空指针，对路径上每个结点计算差值即可，这正是官方思路。
>
> **为什么结果至多两个结点。** 差值为 0 时只有一个结点。差值大于 0 时，与 $k$ 距离为 $min$ 的关键字只可能是 $k-min$ 和 $k+min$，即 $k$ 两侧各至多一个。路径上小于 $k$ 的结点，后一个总在前一个的右子树中，关键字逐渐增大、越来越靠近 $k$；大于 $k$ 的结点同理逐渐减小、越来越靠近 $k$。所以同一侧不会出现两个相同差值的结点，等于 $min$ 的结点只会是 $k$ 两侧各一个。
>
> **代码要点。**
>
> ① `min` 初值取整型最大值，第一次比较必然更新，保证 `pmin1`、`pmin2` 在使用前被赋值（树非空）。
>
> ② 出现更小差值时，把 `pmin1`、`pmin2` 都指向当前结点，相当于把结果重置为一个结点；出现与 `min` 相等的差值时，说明在 $k$ 另一侧找到了等距结点，记入 `pmin2`。
>
> ③ 每个结点处按 `p->data` 与 $k$ 的大小决定向左或向右，直到空指针。
>
> ④ 循环结束后，若 `pmin1` 与 `pmin2` 关键字不同，输出两个结点；否则只输出一个。
>
> 例如 BST 中有 4、6 而没有 5，$k=5$：查找路径会先后经过 4 和 6（一个是 $k$ 的前驱，一个是后继），两者差值都为 1，输出“差值绝对值 = 1 结点 1 = 4 结点 2 = 6”（输出顺序取决于路径上谁先出现）。
>
> **复杂度。** 只访问一条从根向下的路径，时间复杂度为 $O(h)$（$h$ 为树高，平衡时 $O(\log_2 n)$，最坏退化为单支时 $O(n)$）；只用了常数个辅助变量，空间复杂度为 $O(1)$。

## 题干

46. （本题 8 分）某基于索引节点（inode）的文件系统的目录项由文件名和索引节点号构成。磁盘中存放了索引节点表、位图、目录等元数据以及文件数据，盘块大小为 4 KB，盘块号占 4 B。索引节点表包含了所有文件的索引节点，位于从 100 号盘块开始的 4096 个连续盘块中，索引节点号是索引节点在该表中的序号，从 0 开始编号。每个索引节点占 128 B，包含直接地址项 5 个，一次间接地址项、二次间接地址项、三次间接地址项各 1 个。磁盘块位图和索引节点位图分别用于描述磁盘块和索引节点占用情况，0 表示未占用，1 表示已占用。某子目录树如题 46 图所示，其中各文件的文件名和索引节点号如题 46 表所示，file 大小为 30 KB。

![[408真题 2026 T46-fig1.webp]]

题 46 图

**题 46 表**

| 文件名 | 索引节点号 |
|:-:|:-:|
| dir | 100 |
| dir1 | 201 |
| file | 1000 |

请回答下列问题。

（1）file 的索引节点存放在磁盘的几号盘块中？若 file 的索引节点已读入内存，则访问 file 中偏移地址为 21460 的一个字节数据，最多需要访问几个盘块？该文件系统在空间足够大的磁盘中最多能创建多少个文件？（3 分）

（2）若要删除目录 dir1，则文件系统需要对哪些元数据执行哪些操作？（5 分）

> [!note]- 原题截图
> ![[408真题 2026 T46.webp]]

> [!success]- 答案与解析
> **官方答案要点：**
>
> （1）file 的索引节点存放在磁盘的 $\left\lfloor \dfrac{1000}{4096/128} \right\rfloor + 100 = 131$ 号盘块中。访问 file 中偏移地址为 21460 的一个字节数据，最多需要访问 2 个盘块。该文件系统在足够大的磁盘中最多能创建 $4096 \times (4096/128) = 128\text{K} = 131072$ 个文件。
>
> （2）将盘块位图中 dir1 占用的盘块所对应的位修改为 0、将盘块位图中 file 占用的盘块所对应的位修改为 0、将盘块位图中 file 索引节点中的一次间接地址指向的盘块所对应的位修改为 0，将索引节点位图中 dir1 的索引节点（201）所对应的位修改为 0，将索引节点位图中 file 的索引节点（1000）所对应的位修改为 0，删除目录文件 dir 中与 dir1 对应的目录项。
>
> **解析（据官方答案整理推导）：**
>
> **（1）** ① 索引节点所在盘块：每个盘块可存放 $4096/128=32$ 个索引节点。索引节点号 1000 在索引节点表中位于第 $\lfloor 1000/32\rfloor=31$ 个盘块（从 0 计，$1000=31\times 32+8$，是该块内第 8 个索引节点），索引节点表从 100 号盘块开始，故在 $100+31=131$ 号盘块。
>
> ② 访问偏移 21460 的字节：$21460=5\times 4096+980$，该字节位于 file 的逻辑块 5（从 0 计）中，块内偏移 980。5 个直接地址项只覆盖逻辑块 0～4，逻辑块 5 要经一次间接地址项（一个间接块可存 $4096/4=1024$ 个盘块号，覆盖逻辑块 5～1028）找到。索引节点已在内存，故需先读一次间接地址项指向的索引块，取得逻辑块 5 的盘块号，再读该数据块，最多访问 2 个盘块。
>
> ③ 最多文件数：每个文件（含目录文件）都要占用一个索引节点，索引节点表共 $4096$ 个盘块，每块 32 个索引节点，共 $4096\times 32=2^{17}=128\text{K}=131072$ 个索引节点，所以磁盘空间足够大时最多能创建 131072 个文件。
>
> **（2）** 删除 dir1 时，其中的 file 也要一并删除，需释放二者占用的盘块和索引节点，并从父目录中去掉 dir1 的目录项：
>
> ① 释放 file 的盘块：file 大小 30 KB，占 $\lceil 30/4\rceil=8$ 个数据块（逻辑块 0～7），其中 0～4 由直接地址项指向，5～7 经一次间接地址项指向，还要另占 1 个一次间接地址项指向的索引块。读 file 的索引节点（131 号盘块）及其一次间接索引块得到这些盘块号，把磁盘块位图中 file 的 8 个数据块和这 1 个索引块对应的位都改为 0。
>
> ② 释放 dir1 的盘块：dir1 作为目录文件，其目录数据（含 file 的目录项）占用的盘块在磁盘块位图中对应的位改为 0。
>
> ③ 释放索引节点：把索引节点位图中 dir1 的索引节点 201 和 file 的索引节点 1000 对应的位改为 0。
>
> ④ 修改父目录：在目录文件 dir（索引节点 100）的数据中删除 dir1 对应的目录项。

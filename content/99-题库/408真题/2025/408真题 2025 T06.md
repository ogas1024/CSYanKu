## 题干

6. 下列关于图的叙述中，正确的是

A. 有向图必存在入度为 0 的顶点

B. 有向无环图的拓扑有序序列存在且唯一

C. 各顶点的度均大于等于 2 的无向图必有回路

D. 可用 BFS 算法求出带权图中每一对顶点间的最短路径

> [!note]- 原题截图
> ![[408真题 2025 T06.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** ①A 错误 x：有向图中可能不存在入度为 0 的顶点。例如，如下图所示，由 3 个顶点 A、B、C 构成的有向环（边为 A→B，B→C，C→A），每个顶点的入度均为 1，不存在入度为 0 的顶点。
>
> ②B 错误 ×：有向无环图的核心性质是“必存在拓扑有序序列”，但序列不一定唯一。例如：如上图所示，由 3 个顶点 A、B、C 组成的图（边为 A→B、A→C），此图有 2 个拓扑序列：“A → B → C” 和 “A → C → B”。
>
> ③ C 正确 ✓：可以用反证法证明：假设结论不成立，即存在一个“所有顶点度  $\geq 2$ 的无向图 G，且 G 中没有回路（即 G 是无向无环图）”。对于 n 个顶点、m 条边、 $k(k \geq 1)$ 个连通分量的无向无环图，存在关系  $m = n - k$。而无向图中所有顶点的度之和等于边数的 2 倍，即总度数 = 2m。若每个顶点度  $\geq 2$，则总度数  $\geq 2n$，即  $2m \geq 2n \Rightarrow m \geq n$；但无环无向图的边数  $m = n - k \leq n - 1$（因为  $k \geq 1$），与“ $m \geq n$”矛盾。所以假设不成立，原命题“各顶点度均大于等于 2 的无向图必有回路”正确，选项 C 正确。
>
> 【提示】树是一种特殊的无向无环图，但无向无环图不一定是树。因为树一定是连通的，但无向无环图不一定是连通的。这里可以用树类比辅助分析。
>
> ④D 错误 ×：BFS 算法的核心逻辑是“按距离（边数）递增的顺序遍历顶点”，仅适用于无权图（或所有边权相等的图），此时“边数最少”等价于“路径最短”。但对于带权图（边权不相等），BFS 无法考虑边权差异，例如：顶点 A 到 B 有两条路径（A → B，权值为 5；A → C → B，权值为 3），BFS 会优先选择边数少的“A → B”，但实际最短路径是“A → C → B”。带权图的多源最短路径需用 Floyd 算法等。故选 C。
>
> ▷【点评】难题。四个选项都是对经典结论做了细微篡改，每个选项单看都“像是对的”。选项A、C、D均可举反例排除，通过排除法解题更快。

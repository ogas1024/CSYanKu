## 题干

44. （本题 9 分）

对于题 43 中计算机 M 和程序 P，假定 P 的部分机器级代码如题 44（a）图所示，其中，R0～R4 为通用寄存器，SEXT 表示按符号扩展；M 中补码除法器逻辑结构如题 44（b）图所示。

![[408真题 2025 T44-fig1.webp]]

```text
……
// X 在 R2 中，i 在 R4 中
// 数组 d 的首地址在 R3 中
mov R1, (R3 + R4*4)    // R1 ← d[i]
scov R1                // {R0, R1} ← SEXT(R1)
idiv R1, R3            // R1 ← ({R0, R1}/R2)
……
```

请回答下列问题，并说明理由。

（1）若执行题 44（a）图中 `idiv` 指令的除运算时，`d[i]=0x87654321`、`x=0xff`，则补码除法器中寄存器 R、Q 和 Y 的初始内容分别是什么（用十六进制表示）？题 44（b）图中哪个部件包含计数器？在补码除法器执行过程中，由 ALUop 所控制的 ALU 运算有哪几种？（4 分）

（2）假设 `idiv` 指令执行过程中会检测并触发除法异常，则执行 `idiv` 指令时，哪些情况下会发生除法异常（要求给出此时 `d[i]` 和 `x` 的十六进制表示机器数）？发生除法异常时，在异常响应过程中 CPU 需要完成哪些操作？（5 分）

> 题 44（a）图的指令写作 `idiv R1,R3`，右侧注释却写除以 R2。结合前文“`x` 在 R2 中”和本题始终以 `x` 为除数提问，以下按右侧注释所表达的命题意图作答；冲突原样保留。

> [!success]- 答案与解析
> **解析：**
>
> (1) 寄存器 R 中的值为 FFFF FFFFH，Q 中的值为 8765 4321H，Y 中的值为 0000 00FFH。图中的控制逻辑包含计数器。ALUop 所控制的 ALU 运算包含两种运算：加法运算和减法运算。关键寄存器初始值：① 余数寄存器（R）：补码除法中需对被除数进行符号扩展，因  $d[i]$ 为负数，符号扩展后高位全为 1，故 R 初始值的高位部分为 FFFF FFFFH（存储被除数符号扩展后的高位）；② 商寄存器（Q）：初始时低 32 位存储被除数  $d[i]$ 的低位部分，即 8765 4321H（后续迭代中 Q 的低位会逐步更新为商值）；③ 除数寄存器（Y）：初始存放除数的补码形式。题目已给出  $x = 0xff = 0x0000 00ff$，故 Y 初始值为 0000 00FFH。
>
> 控制逻辑与 ALU 操作：图中控制逻辑包含计数器，用于记录除法迭代（移位）的次数（32位除法需 32 次迭代）；ALUop 为 ALU 运算控制信号，补码除法试商时需通过 ALUop 控制 ALU 执行加法或减法运算（例如，根据余数与除数的符号关系，决定加除数或减除数以调整余数，进而确定商值）。
>
> (2) 当  $x = 0000\ 0000H$ 时，发生除 0 异常；当  $d[i] = 80000000H$ 且  $x = FFFF FFFFH$ 时，发生除运算溢出常。CPU 检测到除法异常后，需要将断点和程序状态保存到内核栈或者特定寄存器中，关中断，最后跳转到内核中的除法异常处理程序执行。
>
> ① 除数为 0 异常：当除数  $x = 0x0000\ 0000$（32 位补码表示的 0）时，无论被除数  $d[i]$ 取何值（如题目中 0x8765 4321，或其他任意 32 位补码值），都会触发除数为 0 异常。因为除法
>
> 运算中“除以0”是逻辑上不可执行的操作，属于硬性错误。
>
> ② 溢出异常：仅当被除数为 32 位补码的“最小负整数”（ $d[i] = 0x80000000$，对应十进制  $-2^{31}$），且除数为 -1（ $x = 0xFFFF\ FFFF$，32 位补码表示的 -1）时，会触发溢出异常。原因是： $-2^{31} \div (-1) = 2^{31}$，而 32 位补码正数的最大值为  $2^{31} - 1$， $2^{31}$ 超出了 32 位补码的表示范围，导致结果无法正确存储，进而触发溢出。
>
> 当检测到上述除法异常时，CPU需按固定流程执行以下操作：
>
> ① 保存异常现场：
>
> ◇ 首先保存当前正在执行指令的程序计数器（PC）值（记录异常发生的位置，方便后续恢复执行），同时保存通用寄存器的当前值、程序状态字（PSW，记录 CPU 当前的状态，如标志位等），避免异常处理过程中覆盖原有数据。
>
> ②跳转至异常处理程序：
>
> ◇ 根据“异常向量表”（存储不同异常对应的处理程序入口地址），找到“除法异常”对应的入口地址，将PC值更新为该地址，从而跳转到除法异常处理程序；
>
> ③ 后续恢复（处理程序执行后）：
>
> 异常处理程序完成错误处理（如输出错误信息、终止程序等）后，CPU会恢复之前保存的现场数据（恢复PC、通用寄存器、PSW值），若需继续执行，则从异常发生时的下一条指令开始运行。
>

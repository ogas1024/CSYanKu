## 题干

43. （本题 12 分）

现有 C 语言程序 P 的部分代码如题 43 图所示，假定运行程序 P 的计算机 M 字长为 32 位，按字节编址，数据 Cache 的数据区大小为 32KB，采用 8 路组相联映射方式，主存块大小为 64B，Cache 命中时间为 2 个时钟周期，缺失损失为 200 个时钟周期；采用页式虚拟存储管理方式，页大小为 4kB，数组 `d` 的起始虚拟地址为 `0180 0020H`（`VA31-VA0`）。

```c
int x, d[2048], i;
......
for(i = 0; i<2048; i++)
    d[i] = d[i]/x;
......
```

题 43 图　程序 P 的部分代码

请回答下列问题：

（1）主存地址中 cache 组号字段和块内地址字段分别占几位？虚拟地址中哪些位可作为 cache 索引？（2 分）

（2）`d[100]` 的虚拟地址为多少？`d[100]` 所在主存块对应的 cache 组号是多少？（3 分）

（3）假设执行 `for` 语句时对应代码已在 cache，变量 `i` 和 `x` 已装入寄存器，数组 `d` 已调入主存但不在 cache，则 `d[0]` 在其所在主存块内的偏移量是多少（用十六进制），`for` 语句执行过程中，访问数组 `d` 的 cache 缺失率和数组元素的平均访问时长是多少？（缺失率百分比保留两位）（4 分）

（4）数组 `d` 分布在几个页中？若执行 `for` 语句时对应代码已经在主存，但数组 `d` 还未调入主存，则执行 `for` 语句过程中，访问数组 `d` 所引起的缺页次数是多少？（3 分）

> [!success]- 答案与解析
> **解析：**
>
> (1) Cache 组号和块内地址都是占 6 位，VA 中的 V6～V11 可以作为 Cache 索引。题中给出 Cache 数据区大小为 32KB = 2¹⁵B，采用 8 路组相联映射方式，主存块大小为 64B = 2⁶B。块内偏移为  $\log_2 64 = 6$ 位，标记位为 32 - 6 - 6 = 20 位。
>
> (2)  $d[100]$ 的虚拟地址是 0180 01B0H，Cache 组号为 06H。
>
> 已知 d 的起始地址为 0180 0020H，数组元素是 int 类型且是 32 位计算机，故数组元素大小为 4B。故  $d[100]$ 的虚拟地址 = 0180 0020H + (100 × 4) = 0180 0020H + 0000 0190H = 0180 01B0H。中间 6 位为组索引、中间 6 位为 000110 = 06H，所以 Cache 组号为 06H。
>
> (3) 20H; Cache 缺失率 129/4096 $\approx$ 3.15%, 平均访问时间为 202 × 3.15% + 2 × 96.85% = 8.3 个时钟周期。
>
> ▷【分析】① 主存块大小为  $64\mathrm{B}=2^6\mathrm{B}$，所以块内偏移占6位。 $d[0]$ 的虚拟地址为 01800020H = 0000 0001 1000 0000 0000 0000 0010 0000B，其末 6 位为  $10\,0000\mathrm{B}=20\mathrm{H}$，即  $d[0]$ 的块内偏移是  $20\mathrm{H}$。
>
> ②每个 int 元素占 4B，则每个主存块包含  $64 \div 4 = 16$ 个 int 元素。数组 d 有 2048 个元素， $2048 \div 16 = 128$，又因为上面已经计算出  $d[0]$ 的块内偏移是 20H，存放在块内中间位置，所以需要数组 d 占  $128 + 1 = 129$ 个主存块。数组 d 不在 Cache 中，每次 Cache 缺失后会调入一个主存块，因为数组 d 占 129 个主存块，故 Cache 缺失 129 次。for 循环中，每次执行  $d[i] = d[i] / x$ 语句会访问 2 次  $d[i]$（读出计算完成后，再写回），故数组 d 总的访问次数为  $2048 \times 2 = 4096$，Cache 缺失率为  $129/4096 \approx 3.15\%$。
>
> (3) 平均访问时间公式为  $1 = 1$ 缺失 × 缺失率 +  $T_{命中} \times (1 - 缺失率)$，其中缺失访问时间  $T_{缺失} = 200 + 2 = 202$ 个时钟周期（处理 Cache 缺失后再次访问 Cache 命中），命中时间  $T_{命中} = 2$ 个时钟周期。代入计算得： $T = 202 \times 0.0315 + 2 \times (1 - 0.0315) = 8.3$ 个时钟周期。
>
> （4）数组 d 分布在 3 页中。访问数组 d 所引起的缺页次数是 3。
>
> 每页可存放 4KB/4B = 1K = 1024 个 int 元素，数组 d 共有 2048 个元素。数组 d 的起始虚拟地址为 0180 0020H，页号为 01800H，页内偏移为 020H = 32，此时页内地址并不是从 0 开始，d[0] 所在的页面，只能再存储 1024 - 32 ÷ 4 = 1016 个 int 元素。下一页可存放 1024 个元素，还需要一页存放 8 个元素。故数组 d 分布在 3 个页中。缺页的触发条件是：访问的虚拟地址所属的页未在主存中。由于执行 for 语句时数组 d 未调入主存，且数组分布在 3 页中，首次访问该页时会发生缺页（需要加载到内存），后续访问已加载的页时不再缺页，总缺页次数为 3 次。
>
> 【点评】难题。把 Cache 映射、地址拆分、缺失率统计、平均访问时间、虚存分页串成一道大题，综合性强，区分度高，做起来费时费力。但此类题 408 真题中此前考过多次，熟练掌握往年 408 真题，本题就可以拿大部分分数。

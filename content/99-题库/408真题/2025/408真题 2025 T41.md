## 题干

41. （本题 13 分）

设有两个长度均为 $n$ 的一维整型数组 $A$ 和 $res$，对数组 $A$ 中的每个元素 $A[i]$，计算 $A[i]$ 与 $A[j]$（$0\le i\le j\le n-1$）乘积的最大值，并将其保存到 $res[i]$ 中。例如，若 $A[]=\{1,4,-9,6\}$，则得到 $res[]=\{6,24,81,36\}$。现给定数组 $A$，请设计一个时间和空间上尽可能高效的算法 `calMulMax`，求 $res$ 中各元素的值。函数原型为：`void calMulMax(int A[], int res[], int n)`，

要求：

（1）给出算法的基本设计思想。（4 分）

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。（7 分）

（3）说明你所设计算法的时间复杂度和空间复杂度。（2 分）

> [!success]- 答案与解析
> **解析：**
>
> ▷【解法一】暴力解
>
> (1) 暴力解法的基本思路是根据题目描述进行模拟：对数组 A 中的每个元素  $A[i]$，通过遍历数组中所有其他元素  $A[j]$ ( $i \leq j < n$)，计算  $A[i]$ 与每个  $A[j]$ 的乘积，并记录这些乘积中的最大值，将该最大值存入  $res[i]$。
>
> (2) 算法实现如下：
>
> void calMulMax(int A[], int res[], int n) { for(int i = 0; i < n; i++) { int temp = INT_MIN; //INT_MIN是C语言的宏常量：int类型能表示的最小整数 for(int j = i; j < n; j++) { if(A[i] * A[j] > temp) { temp = A[i] * A[j]; } } res[i] = temp; } }
>
> (3) 两层循环，时间复杂度为  $O(n^{2})$。没有引入额外的辅助空间，空间复杂度为  $O(1)$。
>
> (1) 算法的基本设计思想：
>
> ▷【解法二】最优解
>
> 从后向前扫描一趟数组 A，对每个  $A[i](0 \leq i \leq n-1)$，分别找到从  $A[n-1]$ 到  $A[i]$ 中的最大值 Max 和最小值 Min，然后分以下情况处理：① 若  $A[i] \geq 0$，则  $A[i]$ 与 Max 相乘；② 若  $A[i] < 0$，则  $A[i]$ 与 Min 相乘。最终相乘的结果保存在 res[i] 中。
>
> (2) 算法实现：
>
> void calMMulMax(int A[], int res[], int n) { int i, Max, Min; Max = Min = A[n-1]; for(i = n-1; i >= 0; i--) { // 从后向前扫描数组A if(A[i] > Max) Max = A[i]; else if(A[i] < Min) Min = A[i]; if(A[i] >= 0) res[i] = A[i] * Max; // 根据A[i]的正负性分别处理 else res[i] = A[i] * Min; } }
>
> (3) 算法的时间复杂度为  $O(n)$；空间复杂度为  $O(1)$。
>

> https://leetcode.cn/problems/maximum-product-subarray/
>
> ▷【点评】常规题。408 考试中，数组类的算法题暴力解通常都很容易想到，但最优解很难想到。大部分考生甚至看懂本题最优解的答案都费劲。考场上若此类题一眼没有最优解思路，建议直接用暴力解法（能拿8分左右），为其他题目节省时间。

## 题干

某分时系统中的进程可能出现如下图所示的状态变化，请回答下列问题：

1）根据图示，该系统应采用什么进程调度策略？

2）将图中每个状态变化的可能原因填写在下表中。


| 变化 | 原因 |
| ---: | --- |
| 1 |  |
| 2 |  |
| 3 |  |
| 4 |  |
| 5 |  |
| 6 |  |

> [!note]- 原题截图
> ![[王道OS 2.2 CPU调度 综合 03.webp]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 该系统采用**时间片轮转调度**；进程阻塞时会按原因进入不同阻塞队列，因此是**多阻塞队列的时间片轮转系统**。
>
> 2. 图中六次变化的原因依次是：
>
> |变化|原因|
> |---|---|
> |1|进程被调度，获得 CPU，进入运行态|
> |2|进程请求读文件，因 I/O 进入阻塞态|
> |3|等待打印输出，因打印机未结束而阻塞|
> |4|打印结束，进程转就绪并插入队尾|
> |5|磁盘数据调入完成，进程转就绪|
> |6|时间片耗尽，运行进程让出 CPU 并排到就绪队尾|
>
> **解析：** 运行态在时间片耗尽后直接回就绪队尾是时间片轮转的典型特征；不同 I/O 等待原因对应不同阻塞队列。

## 题干

42. 【P91】【2013 统考真题】某系统正在执行三个进程  $P_{1}, P_{2}$ 和  $P_{3}$，各进程的计算（CPU）时间和 I/O 时间比例如下表所示。

为提高系统资源利用率，合理的进程优先级设置应为（ ）

| 进程名 | 计算时间 | I/O 时间 |
| --- | ---: | ---: |
| $P_1$ | 90% | 10% |
| $P_2$ | 50% | 50% |
| $P_3$ | 15% | 85% |

A. $P_{1}>P_{2}>P_{3}$

B. $P_{3}>P_{2}>P_{1}$

C. $P_{2}>P_{1}=P_{3}$

D. $P_{1}>P_{2}=P_{3}$

> [!note]- 原题截图
> ![[王道OS 2.2 CPU调度 选择 42.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 综合 CPU 与 I/O 使用特征设置优先级时，通常让 I/O 繁忙型作业优先，以及时完成设备操作并提高资源利用率。

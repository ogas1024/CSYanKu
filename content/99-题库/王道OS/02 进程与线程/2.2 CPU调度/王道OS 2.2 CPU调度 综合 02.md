## 题干

有三个作业 A、B、C，它们分别单独运行时的 CPU 和 I/O 占用时间如下图所示。

- 作业 A：$I/O_2(10\text{ ms})$，CPU$(20\text{ ms})$，$I/O_1(30\text{ ms})$，CPU$(10\text{ ms})$，$I/O_1(40\text{ ms})$，CPU$(20\text{ ms})$，$I/O_1(20\text{ ms})$
- 作业 B：$I/O_1(30\text{ ms})$，CPU$(40\text{ ms})$，$I/O_2(30\text{ ms})$，CPU$(30\text{ ms})$，$I/O_1(30\text{ ms})$
- 作业 C：CPU$(40\text{ ms})$，$I/O_1(20\text{ ms})$，CPU$(20\text{ ms})$，$I/O_2(70\text{ ms})$

现在请考虑三个作业同时开始执行。

系统中的资源有一个 CPU 和两台输入/输出设备（$I/O_1$ 和 $I/O_2$）同时运行。

三个作业的优先级为 A 最高、B 次之、C 最低，一旦低优先级的进程开始占用 CPU 或者 I/O 设备，高优先级进程也要等待到其结束后方可占用。

请回答下面的问题：

（1）最早结束的作业是哪个？

（2）最后结束的作业是哪个？

（3）计算这段时间 CPU 的利用率（三个作业全部结束为止）。

> [!note]- 原题截图
> ![[王道OS 2.2 CPU调度 综合 02.png]]

> [!success]- 答案与解析
> **答案：**
>
> 按 A、B、C 优先级依次递减并采用非抢占优先级调度，运行时序为：C 先运行至 40；A 在 40–60；B 在 60–100；A 在 100–110；C 在 110–130；B 在 130–160；A 在 160–190，随后完成 I/O 至 210。
>
> 1. 最早结束的是作业 **B**。
> 2. 最后结束的是作业 **A**。
> 3. 全部执行完历时 **$210\text{ ms}$**；CPU 忙时为各作业 CPU 阶段之和 $180\text{ ms}$，故 CPU 利用率为 **$180/210\approx85.7\%$**。
>
> **解析：** 每次当前作业释放 CPU 后，从已就绪作业中选优先级最高者；非抢占调度不会因更高优先级作业到达而中断当前 CPU 段。

## 题干

某系统中进程的虚拟地址空间包括内核区、用户栈、运行时堆、可读/写数据段、只读代码段等区域，其布局如下图所示，图中阴影部分表示未占用区域。

现有 C 语言程序的部分代码如下。

```c
char *ptr;
void main()
{
    int length;
    ptr = (char *)malloc(100);
    scanf("%s", ptr);
    length = strlen(ptr);
    printf("length = %d\n", length);
    free(ptr);
}
```

图中各区域自上而下依次为：内核区、用户栈、未占用区域、运行时堆、可读/写数据段、只读代码段、未占用区域。

请回答下列问题。

- **（1）** 上述程序执行时，其进程控制块位于哪个区域？执行 `scanf()` 等待键盘输入时，该进程处于什么状态？
- **（2）** `main()` 函数的代码位于哪个区域？其直接调用的哪些函数的功能需通过执行驱动程序实现？
- **（3）** 变量 `ptr` 被分配在哪个区域？若变量 `length` 未被分配在寄存器中，则会被分配在哪个区域？`ptr` 指向的字符串位于哪个区域？

> [!note]- 原题截图
> ![[王道OS 2.1 进程与线程简介 综合 01.png]]

> [!success]- 答案与解析
> **答案：**
>
> 1. 进程控制块（PCB）位于**内核区**。执行 `scanf()` 等待键盘输入时，进程因等待 I/O 完成而主动放弃 CPU，处于**阻塞态**。
>
> 2. `main()` 函数的代码位于**只读代码段**。程序直接调用的 `scanf()` 和 `printf()` 最终要通过系统调用访问键盘、终端等设备，其实际 I/O 操作依赖设备驱动程序。
>
> 3. `ptr` 是全局变量，分配在**可读/写数据段**；`length` 是 `main()` 的局部变量，若未被优化到寄存器中，则分配在**用户栈**；`ptr` 所指向的字符数组由 `malloc()` 动态分配，位于**运行时堆**。
>
> **解析：** 进程地址空间按用途划分为代码段、数据段、运行时堆和用户栈，而 PCB 由内核管理并位于内核区。设备 I/O 由库函数经系统调用进入内核，再由驱动程序完成。

## 题干

下面是两个并发执行的进程，它们能正确运行吗？若不能，请举例说明并改正。

```c
int x;

process P1 {
    int y,z;
    x=1;
    y=0;
    if(x>=1)
        y=y+1;
    z=y;
}

process P2 {
    int t,u;
    x=0;
    t=0;
    if(x<=1)
        t=t+2;
    u=t;
}
```

> [!note]- 原题截图
> ![[王道OS 2.3 同步与互斥 综合 01.png]]

> [!success]- 答案与解析
> **答案：**
>
> 两个并发进程都修改临界资源 `x`，未加保护时结果不确定。例如顺序执行可得 `x=0,y=1,z=1,t=2,u=2`，交错执行则可能得到 `x=0,y=0,z=0,t=2,u=2`。
>
> 设置互斥信号量 `S=1`，在 P1 和 P2 各自第一次访问 `x` 前执行 `P(S)`，完成对 `x` 的读写后执行 `V(S)`；局部变量赋值可放在临界区外。这样同一时刻只有一个进程操作 `x`。
>
> **解析：** 两次不同调度得到不同结果证明存在竞态；互斥信号量必须覆盖从读取到最终写回 x 的完整临界区。

## 题干

30. 【P25】【2022 统考真题】下列关于 CPU 模式的叙述中，正确的是（ ）。

A. CPU 处于用户态时只能执行特权指令

B. CPU 处于内核态时只能执行特权指令

C. CPU 处于用户态时只能执行非特权指令

D. CPU 处于内核态时只能执行非特权指令

> [!note]- 原题截图
> ![[王道OS-1.3选-030.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** CPU 在用户态只能执行非特权指令，在内核态则既可执行特权指令，也可执行非特权指令。

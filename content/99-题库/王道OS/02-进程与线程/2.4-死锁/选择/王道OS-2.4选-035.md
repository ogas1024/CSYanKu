## 题干

35. 【P170】【2011统考真题】某时刻进程的资源使用情况见下表，此时的安全序列是（ ）

| 进程名 | 已分配 $R_1$ | 已分配 $R_2$ | 已分配 $R_3$ | 尚需 $R_1$ | 尚需 $R_2$ | 尚需 $R_3$ | 可用 $R_1$ | 可用 $R_2$ | 可用 $R_3$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| $P_1$ | 2 | 0 | 0 | 0 | 0 | 1 | 0 | 2 | 1 |
| $P_2$ | 1 | 2 | 0 | 1 | 3 | 2 |  |  |  |
| $P_3$ | 0 | 1 | 1 | 1 | 3 | 1 |  |  |  |
| $P_4$ | 0 | 0 | 1 | 2 | 0 | 0 |  |  |  |

A. $P_1,P_2,P_3,P_4$

B. $P_1,P_3,P_2,P_4$

C. $P_1,P_4,P_3,P_2$

D. 不存在

> [!note]- 原题截图
> ![[王道OS-2.4选-035.png]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 按检测算法先消去P1，再消去P4，此后剩余进程的需求均无法由当前工作向量满足，故选D。

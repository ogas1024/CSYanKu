## 题干

某博物馆最多可容纳 500 人同时参观，有一个出入口，该出入口一次仅允许一人通过。

参观者的活动描述如下：

请添加必要的信号量和 P、V［或 `wait()`、`signal()`］操作，以实现上述过程中的互斥与同步。

要求写出完整的过程，说明信号量的含义并赋初值。

```text
cobegin
参观者进程 i:
{
    ...
    进门。
    ...
    参观；
    ...
    出门；
    ...
}
coend
```

> [!note]- 原题截图
> ![[王道OS-2.3综-019.png]]

> [!success]- 答案与解析
> **答案：**
>
> 设 `empty=500,mutex=1`。每个参观者先 `P(empty)` 申请容量，再 `P(mutex)` 通过唯一入口，进门后 `V(mutex)`；参观结束时 `P(mutex)` 通过出口，出门后 `V(mutex),V(empty)`。
>
> **解析：** empty限制馆内同时最多500人，mutex使出入口一次只通过一人。

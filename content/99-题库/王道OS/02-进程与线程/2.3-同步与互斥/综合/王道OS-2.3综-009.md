## 题干

设自行车生产线上有一个箱子，其中有 $N$ 个位置（$N\ge 3$），每个位置可存放一个车架或一个车轮；

又设有 3 名工人，其活动分别为：

工人 1 活动：

```text
do {
    加工一个车架；
    车架放入箱中；
} while(1)
```

工人 2 活动：

```text
do {
    加工一个车轮；
    车轮放入箱中；
} while(1)
```

工人 3 活动：

```text
do {
    箱中取一个车架；
    箱中取二个车轮；
    组装为一台车；
} while(1)
```

试分别用信号量与 PV 操作实现三名工人的合作，要求解中不含死锁。

> [!note]- 原题截图
> ![[王道OS-2.3综-009.png]]

> [!success]- 答案与解析
> **答案：**
>
> 设 `empty=N,wheel=0,frame=0,s1=N-2,s2=N-1`。
>
> - 工人1：加工车架；`P(s1),P(empty)` 后放入箱中，`V(frame)`。
> - 工人2：加工车轮；`P(s2),P(empty)` 后放入箱中，`V(wheel)`。
> - 工人3：`P(frame)` 取一车架并 `V(empty),V(s1)`；再连续两次 `P(wheel)` 取两车轮，分别释放两个空位并连续两次 `V(s2)`；组装汽车。
>
> **解析：** empty表示箱内空位，frame/wheel表示两类零件；s1、s2分别把车架和车轮的库存限制在N-2、N-1，避免装配者同时等两轮或一架时形成死锁。

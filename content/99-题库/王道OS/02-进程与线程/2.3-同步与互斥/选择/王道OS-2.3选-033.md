## 题干

33. 【P129】有两个并发进程 $P_1$ 和 $P_2$，其程序代码如下：

```c
P1() {
    x=1; // A1
    y=2;
    z=x+y;
    print z; // A2
}
```

```c
P2() {
    x=-3; // B1
    c=x*x;
    print c; // B2
}
```

可能打印出的 $z$ 值有（ ），可能打印出的 $c$ 值有（ ）（其中 $x$ 为 $P_1$、$P_2$ 的共享变量）。

A. $z=1,-3$；

$c=-1,9$

B. $z=-1,3$；

$c=1,9$

C. $z=-1,3,1$；

$c=9$

D. $z=3$；

$c=1,9$

> [!note]- 原题截图
> ![[王道OS-2.3选-033.png]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** A1、B1的执行先后使x可能为1或-3，因此z可能为3或-1，c可能为1或9。

## 题干

26. 【P129】一个进程因在互斥信号量 mutex 上执行 V（mutex）操作而导致唤醒另一个进程时，执行 Ⅴ 操作后 mutex 的值为（ ）

A. 大于 0

B. 小于 0

C. 大于等于 0

D. 小于等于 0

> [!note]- 原题截图
> ![[王道OS-2.3选-026.png]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 原先已有进程等待进入临界区，故V前mutex≤-1，执行V后仍有mutex≤0。

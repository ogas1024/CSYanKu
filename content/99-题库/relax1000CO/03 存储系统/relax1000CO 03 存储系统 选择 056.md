## 题干

56. 在某系统中，按字节编址。Cache 数据容量为 64B，主存大小是 Cache 数据容量的 256 倍，Cache 行大小是 8B，采用 2 路组相联映射、LRU 替换算法及直写法。有如下 C 语言程序段：数组 a 中都是 int 型数据，数组长度为 18，每个 int 型数据占 4B，假定数组 a 在主存中是从 00000000H 开始连续存储，该程序段执行前 Cache 为空，则该程序段执行过程中访问数组 a 的 Cache 缺失率是（ ）。

```
for (int i = 0; i < 4; i++) {
    for (int j = 0; j < 18; j++) {
        a[j] = a[j] + 3;
    }
}
```

A. 7.5%

B. 25%

C. 12.5%

D. 15%

> [!note]- 原题截图
> ![[relax1000CO 03 存储系统 选择 056.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 数组占用 0~8 共 9 个块，第 1 轮 Cache 映射情况，Cache 分为 4 个组（组 0、1、2、3）。其中组 0 包含块 0、4，组 1 包含块 1、5，组 2 包括块 2、6，组 3 包括块 3、7，当块 8 访问时候，根据 LRU 替换算法，块 0 被替换出去，第一轮中每块第一个元素访问全部缺失共 9 次。第 2、3、4 轮组 1、2、3 中的块在重复访问时都命中，只有组 0 内的块在块 0 访问的时候，此时 Cache 中包含块 8 和块 4，块 0 缺失替换出块 4，后续访问块 4 和块 8 时也分别缺失。每轮中 0、4、8 依次缺失替换，共计 3 次，所以缺失次数是 $9+3+3+3=18$ 次。总访问次数是 $4\times18\times2=144$ 次（每个元素每次读写共两次，共 4 轮），所以缺失率是 $18/144=1/8=12.5\%$，答案选 C。

## 题干

73. 已知某计算机采用单级页式虚拟存储管理，配有 TLB 和 Cache。CPU 执行一条读内存的取数指令（不考虑取指阶段）。假设不考虑 Cache 的写回操作（Write-Back）造成的额外开销，并且注意 Cache 也会缓存页表项。下列关于访存状态组合与主存访问次数的推断中，错误的是（ ）。

A. 若本次取数操作完全没有访问主存（即 0 次主存访问），则必定是因为：TLB 命中，且目标数据在 Cache 中命中

B. 若 TLB 未命中，但本次取数操作仅访问了 1 次主存，可能是因为：页表项在 Cache 中未命中，而目标数据在 Cache 中命中

C. 若 TLB 命中，但目标数据在 Cache 中未命中，硬件可能仅需访问 1 次主存可完成该取数指令

D. 无论 Cache 的命中率多高，只要在地址翻译阶段检测到了缺页异常，则本次访存的 TLB 必定是未命中的，且目标数据必定不在 Cache 中

> [!note]- 原题截图
> ![[relax1000CO 03 存储系统 选择 073.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** A 错误：很多人认为 0 次主存访问的唯一条件就是"TLB 命中 + Cache 命中"。但实际上，如果发生以下情况：TLB 未命中 → MMU 去查页表 → 页表项在 Cache 中命中 → 获取物理地址后，目标数据在 Cache 中也命中。在这个"TLB 缺失，但双 Cache 命中"的过程中，数据全是从高速缓存中读取的，主存访问次数依然是 0 次。因此 0 次主存访问不能说明 TLB 命中。
>
> B 正确：这是非常典型的一种状态组合。TLB 未命中，硬件去查页表；此时页表项（PTE）在 Cache 中未命中，被迫访问 1 次主存将页表块读入 Cache；拿到物理地址后去查目标数据，目标数据此时幸运地在 Cache 中命中。整个过程加起来，刚好只访问了 1 次主存。
>
> C 正确：这也是极其常规的缓存未命中情况。TLB 命中，直接拿到物理地址（0 次主存访问）。拿着物理地址去查 Cache，发现数据未命中，于是硬件去主存中取数据块放入 Cache（访问 1 次主存）。总耗时就是 1 次主存访问的开销。
>
> D 正确：如果发生缺页，说明该页面根本不在主存中。既然不在主存中，TLB 作为一个只缓存"有效物理映射"的快表，里面绝对不可能有它的有效表项，所以 TLB 必然未命中。同理，Cache 缓存的是主存的子集。既然老大哥（主存）里都没有这块数据，小弟（Cache）里自然不可能有。所以目标数据必然不在 Cache 中。该推断完全正确。

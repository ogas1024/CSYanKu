## 题干

67. 假定编译器将赋值语句"x = x + 3;"转换为机器指令"add [xaddr], 3"，其中 xaddr 是变量 x 对应的存储单元虚拟地址。若执行该指令的计算机采用页式虚拟存储管理方式，并配有相应的 TLB。该计算机的 Cache 采用回写（Write-Back）和写分配（Write-Allocate）策略。在执行该指令的过程中：取指阶段 TLB 和 Cache 均命中；读操作数阶段，TLB 命中但 Cache 未命中，且此时需要替换一个脏行（脏位为 1）；写回结果阶段 Cache 命中。则执行完该指令全过程，完成其功能需要访问主存的次数是（ ）。

A. 1 次

B. 2 次

C. 3 次

D. 4 次

> [!note]- 原题截图
> ![[relax1000CO 03 存储系统 选择 067.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 取指令阶段（0 次访存）：题干明确指出取指阶段 TLB 和 Cache 均命中，直接从 Cache 中拿到指令，访问主存 0 次。
>
> 读操作数阶段（2 次访存）：指令 add [xaddr], 3 是典型的"读-改-写"指令，必须先将 x 从内存中读出来。TLB 命中，MMU 直接将虚拟地址 xaddr 翻译为物理地址，不需要访问主存中的页表。物理地址送往 Cache，此时 Cache 未命中。关键点（脏行写回），因为 Cache 采用回写策略，且未命中时触发了替换，而被替换的 Cache 行是"脏行"（脏位为 1，说明里面的数据被修改过且尚未同步到主存），此时硬件必须先将该脏行的数据写回主存（第 1 次访问主存）。关键点（新块调入），脏行腾空后，由于是读失效，需要将包含变量 x 的主存块读入 Cache（第 2 次访问主存）。随后 CPU 从 Cache 中读取 x 的值参与加法运算。
>
> 写回结果阶段（0 次访存）：运算完成后，新值需要写回 xaddr，此时包含 x 的数据块刚刚在读阶段被调入 Cache，因此写回时 Cache 必然命中。在回写策略下，Cache 命中时仅修改 Cache 行中的内容，并将脏位置为 1，不需要同步写入主存。因此这一阶段访问主存 0 次。
>
> 总结：$0\text{（取指）}+2\text{（读操作数）}+0\text{（写回）}=2$ 次。

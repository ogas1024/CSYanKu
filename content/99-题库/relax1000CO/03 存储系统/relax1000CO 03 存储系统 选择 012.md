## 题干

12. 在 Cache-主存-外存层次结构中，当 CPU 分别遭遇 Cache 缺失和缺页异常时，关于系统的处理过程及开销，下列说法错误的是（）。

A. Cache 缺失通常直接由硬件逻辑完成数据的提取和块替换，开销较小

B. 缺页异常会触发处理器的内部异常，需要操作系统介入执行缺页处理程序，开销较大

C. 无论是 Cache 缺失还是缺页异常，CPU 都必须暂停当前正在执行的进程，进行线程切换

D. Cache 缺失的开销远小于缺页异常，因为前者访问的是主存，后者需要进行磁盘 I/O 操作

> [!note]- 原题截图
> ![[relax1000CO 03 存储系统 选择 012.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> 【解析】发生 Cache 缺失时，CPU 通常只是通过流水线停顿（Stall）等待硬件从主存取回数据，不会发生进程/线程的上下文切换；而发生缺页异常时，由于磁盘 I/O 极慢，操作系统为了提高 CPU 利用率，会将当前进程阻塞并切换到其他就绪进程。这就把存储器和操作系统的知识完美联动了起来。

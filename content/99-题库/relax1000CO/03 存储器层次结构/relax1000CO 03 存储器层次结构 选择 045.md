## 题干

45. 给定两个长度为 N 的一维数组 a 和 b（N 极大，远远超过 Cache 容量），针对以下两种代码写法，哪种写法对 Cache 的利用率更高（局部性更好）？下列关于 cache 的描述中，正确的是（）。

for(int i = 0; i < N; i++) { // 写法 1
    a[i] = a[i] * 2;
}

for(int i = 0; i < N; i++) {
    b[i] = a[i] + 10;
}

for(int i = 0; i < N; i++) { // 写法 2
    a[i] = a[i] * 2;
    b[i] = a[i] + 10;
}

A. 写法 1 更好，它把不同的操作分开了，指令的时间局部性更好

B. 写法 1 更好，它对数组 a 的访问具有更好的空间局部性

C. 写法 2 更好，它显著提升了数组 a 的时间局部性

D. 写法 2 更好，它显著提升了数组 b 的空间局部性

> [!note]- 原题截图
> ![[relax1000CO 03 存储器层次结构 选择 045.png]]

> [!success]- 答案与解析
> **答案：** C
>
> 【解析】数组长度 N 极大，超过 Cache 容量，这意味着数组会被不断挤出 Cache。
>
> 写法 1：第一个循环遍历了整个数组 a，第二个循环又重新从头遍历数组 a 去算 b。当第二个循环要用 a[0] 时，a[0] 早就因为 Cache 容量不够被后面的 a[99999] 替换出去了，必须重新从主存读！
>
> 写法 2： 在一个循环体内，刚刚算完 a[i]（此时 a[i] 还在 Cache 里，热乎着呢），紧接着下一句就立刻使用 a[i] 去算 b[i]。
>
> 结论：对同一个元素 a[i] 的两次访问在时间上被拉到了最近。这是非常典型地通过修改代码逻辑来提升时间局部性的操作，所以选 C。

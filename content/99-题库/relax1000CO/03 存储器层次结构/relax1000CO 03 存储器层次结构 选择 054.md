## 题干

54. 一个 32 位系统，系统中有一个数据容量为 128B 的 2 路组相联映射 Cache，每个 Cache 块的大小为 32B。int 数据类型的长度为 4B。如下程序，假设 table 数组的内存起始地址是 0x0。

```
int i, j;
int table[4][8];
for (j = 0; j < 8; j++)
    for (i = 0; i < 4; i++)
        table[i][j] = i + j;
```

table 中元素的访问，Cache 缺失率为（ ）。

A. 1

B. 1/4

C. 1/8

D. 1/16

> [!note]- 原题截图
> ![[relax1000CO 03 存储器层次结构 选择 054.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 一个 Cache 块可以容纳 $32/4=8$ 个 int 元素。table 按行主序存储（`table[i][j]`，i 行 j 列，每行 8 个元素恰好占满 1 个 Cache 块），但访问顺序是外层 j、内层 i，即按列访问。table 中元素的访问情况如下（m 表示 miss，h 表示 hit，按行列出）：
>
> ```
> m h h h h h h h
> m h h h h h h h
> m h h h h h h h
> m h h h h h h h
> ```
>
> 每一行（table[i][0..7]）恰好在一个 Cache 块内，虽然访问顺序是先固定 j 再变化 i，但由于 Cache 采用 2 路组相联，4 行数据可同时驻留而不冲突替换，每行的首次访问（j=0）miss，之后同行内的访问（j=1..7）由于该行早已被完整调入 Cache 而全部 hit。
>
> Miss rate = 4/32 = 1/8。

## 题干

89. 假定编译器规定 int 型和 short 型长度分别为 32 位和 16 位，执行下列 C 语言语句：

```c
unsigned short x=65530;
int y=x;
```

得到 y 的机器数为（）。

A. 0000 7FFAH

B. 0000 FFFAH

C. FFFF 7FFAH

D. FFFF FFFAH

> [!note]- 原题截图
> ![[relax1000CO 02 数据的表示和运算 选择 089.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** C 语言类型转换规则：
>
> - 同长度无符号数和有符号数转换，遵循机器数不变转变成对应真值，即补码转补码真值，无符号数转无符号数真值。
> - 短转长，看短的带不带符号。短是带符号就符号扩展，短是无符号就 0 扩展到长的位数，再根据长的变量类型转变成对应真值，这道题短的就是无符号数，所以 0 扩展就行了。
> - 长转短，直接截断。
>
> 65530 的 16 位机器数为 FFFAH，x 是 unsigned short（无符号），赋给 32 位 int 时做 0 扩展，得到 y 的机器数为 0000 FFFAH，B 正确。
>
> 思考 1：以下代码 y 的机器数是多少？
>
> ```c
> short x = 0xABCD;
> unsigned int y = x;
> ```
>
> （短的是带符号数，就进行符号扩展，符号位是 1，高位补 1，答案为 FFFFABCDH）

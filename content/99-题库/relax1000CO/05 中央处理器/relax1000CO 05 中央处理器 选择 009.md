## 题干

9. 下列有关指令周期的叙述中，错误的是（　）。

A. 一个指令周期可由若干个机器周期或时钟周期组成

B. 单周期 CPU 中的指令周期就是一个时钟周期

C. 乘法指令和加法指令的指令周期总是一样长

D. 指令周期的第一个阶段一定是取指令阶段

> [!note]- 原题截图
> ![[relax1000CO 05 中央处理器 选择 009.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** A 正确：指令周期可分解为多个机器周期（如取指、执行等）或更细粒度的时钟周期。B 正确：单周期 CPU 中所有指令都在一个时钟周期内完成，因此指令周期等同于一个时钟周期（时钟周期长度按最复杂指令设定）。C 错误：指令周期长度取决于指令复杂度和 CPU 设计——单周期 CPU 中所有指令周期长度相同（均为一个时钟周期，但因此效率较低）；而在多周期或流水线 CPU 中，不同指令执行时间通常不同，乘法指令通常比加法指令需要更多时钟周期，二者指令周期并不总是一样长。D 正确：无论指令类型如何，CPU 执行任何指令的第一步都是从内存中取出指令，然后才能译码、执行。

## 题干

67. 以下是一段 MIPS 指令序列：

```
add  $t1, $t3, $t1
sub  $t2, $t4, $t2
j    Next
addi $s1, $s2, 3
...
```

假定采用"取指、译码/取数、执行、访存、写回"这种五段式流水线方式，并控制在时钟的前半周期写寄存器堆，后半周期读寄存器堆，由于在第三条指令执行了无条件跳转指令，因此有可能发生控制冒险。如果不采取处理，发生转移时会产生以下"转移开销"：将按顺序预取的指令废除（即"排空流水线"）、从转移目标地址重新取指令。我们把由于流水线阻塞而带来的延迟执行周期数称为延迟损失时间片 C。

现在有以下两种不同的流水线数据通路：

①第一种流水线数据通路采取的方案是在 mem 阶段将目标转移地址写回 PC（袁书方案）；

②第二种流水线数据通路采取的方案是在 ID 阶段译码后通过一些简单电路形成目标转移地址并写回 PC；

以下说法错误的是（　）。

A．第一种方案的延迟损失时间片 C=2；

B．第二种方案的延迟损失时间片 C=1；

C．Cache 缺失、TLB 缺失和缺页的发生会引起流水线的阻塞

D．异常和中断的发生也会引起指令冒险

> [!note]- 原题截图
> ![[relax1000CO 05 中央处理器 选择 067.png]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 第一种方案（袁书方案）在 MEM 阶段才将目标转移地址写回 PC，此时已经顺序取入了 3 条错误指令（IF 阶段与 MEM 阶段之间相差 3 拍），需要将它们全部废除，延迟损失时间片 C=3，A 描述为 C=2 错误（应选）。第二种方案在 ID 阶段译码后就形成目标转移地址并写回 PC，此时只多取入了 1 条错误指令（IF 阶段与 ID 阶段之间相差 1 拍），延迟损失时间片 C=1，B 正确。Cache 缺失、TLB 缺失和缺页都需要从下一级存储或内存中重新获取内容，会引起流水线的阻塞，C 正确。异常和中断与分支冒险类似，当某条指令执行过程中发现异常或中断时，它后面已经进入流水线的多条指令都需要被冲刷，本质上也是一种"指令冒险"，D 正确。

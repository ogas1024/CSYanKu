## 题干

70. 以下是一段 MIPS 指令序列：

```
addi $t1, $zero, 20   #R[$t1] <- 20
lw   $t2, 12($a0)     #R[$t2] <- M[R[$a0]+12]
add  $v0, $t1, $t2    #R[$v0] <- R[$t1] + R[$t2]
```

以上指令序列中，第 1，2，3 条指令发生数据相关。假定采用"取值、译码/取数、执行、访存、写回"五段式流水线方式，那么在①不采用"转发技术"，但是采用在时钟的前半周期写寄存器堆，后半周期读寄存器堆的方式，②采用"转发技术"时，③两者都不采用，需要在第 3 条指令前分别加入（　）条空操作（nop）指令才会使这段程序不发生数据冒险。

A．3, 1, 3　　　　B．1, 3, 2　　　　C．3, 2, 3　　　　D．2, 1, 3

> [!note]- 原题截图
> ![[relax1000CO 05 中央处理器 选择 070.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 此题是关于 load-use 数据冒险的处理方式。①若不采用转发技术，但采用在时钟前半周期写寄存器堆、后半周期读寄存器堆的方式，相比完全不用任何技术（需插入 3 个 nop，把后一条指令的 ID 段阻塞在前一条 load 指令的 WB 段之后）可以节省一个时钟，只需插入 2 个 nop，将 ID 隔到前一条 load 指令的 MEM 段之后。②若采用转发技术，只需插入 1 个 nop，将 EX 隔到前一条 load 指令的 MEM 段之后，转发硬件路线由 MEM 送到 ALU 的输入端。③若两者都不采用，则需要插入 3 个 nop。综合三种情况分别需要插入 2、1、3 个 nop，对应选项 D，故本题答案为 D。
>
> 【补充·流水线冒险总结】①正常数据冒险，需插入 3 个 nop，如果采用 WB 前半段写、后半段读只需 2 个。②load-use 数据冒险，使用转发技术，相邻指令需插入一个 nop，将 EX 隔到前一条 load 指令的 MEM 段之后；不使用转发技术，需要插入 3 个 nop，同样 WB 分前后两段读写则只需 2 个 nop；也可以采用编译器将 load 指令调整到合适位置解除冒险。③分支控制冒险，若用插入技术，需插入 3 个 nop，把后一条 IF 隔到前一条 MEM 段之后，因为转移指令（无论条件还是非条件）都是在 MEM 段修改 PC。④类似循环指令的最后转移指令前若有写数据，要注意循环重新执行的前几条指令和尾部的指令也可能出现数据冒险。

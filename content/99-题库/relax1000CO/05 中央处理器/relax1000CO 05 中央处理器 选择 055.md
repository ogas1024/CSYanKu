## 题干

55. 以下有关 CPU 响应外部中断请求的叙述中，正确的是（　）。

A．每条指令结束后，CPU 都会转到"中断响应"周期进行中断响应处理

B．中断 I/O 方式下，外设接口中的数据和 CPU 中的寄存器内容直接交换

C．CPU 检测异常与中断的时机相同，并且检测到异常事件后所做的处理和检测到中断请求后所做的处理完全一样

D．在中断处理程序结束后的执行 iret 指令过程中，会从内核栈中弹出异常/中断响应时保存的用户栈指针

> [!note]- 原题截图
> ![[relax1000CO 05 中央处理器 选择 055.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** A 错误，CPU 在每条指令执行结束时检测中断请求信号，若检测到中断请求信号有效，则进入中断响应周期；若检测到中断请求信号无效，则不会进入中断响应周期。B 正确，真题考过，外设接口中的数据即 I/O 端口的数据，中断 I/O 方式下该数据与 CPU 寄存器内容直接交换。C 错误，检测时机不同，所做的处理也不同：异常的发生与指令的执行同步，与当前指令的执行过程密切相关，因此在指令执行过程中检测到异常立即响应；而中断是由外部设备或内部定时器发出的，通常是异步发生的，因此在指令执行完成后检测。CPU 对异常和中断的响应处理在大的方面基本一致，都需要保存断点和程序状态并转到相应处理程序执行，但细节并不完全一样，例如检测到中断请求后 CPU 必须通过中断回答信号启动中断控制器进行中断查询以确定优先级最高的中断类型，而对于内部异常，CPU 无需进行中断回答。D 错误，在 iret 执行过程中，会从内核栈中弹出异常/中断响应时保存的 PC 和 PSW 信息（断点信息），并检查响应前、后系统是否处于同一特权级：若处于同一特权级（即异常/中断在内核程序执行时发生，若是中断则表示发生了多重中断），则不需要从内核栈中弹出用户栈指针，因为此时并未在内核栈中保存用户栈顶指针；若不是同一特权级，则需要弹出用户栈指针。

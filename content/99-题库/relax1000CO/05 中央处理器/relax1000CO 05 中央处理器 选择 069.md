## 题干

69. 在理想的 RISC 处理器 5 段流水线（IF→ID→EX→MEM→WB）中执行以下指令序列，不采用转发技术，仅通过插入气泡处理数据冒险，寄存器可在同一周期的前半周期写，后半周期读：

```
add s0, t1, t2   // R[s0] <- R[t1] + R[t2]
lw  t3, 0(s0)    // R[t3] <- M[R[s0]]
add t4, t3, s0   // R[t4] <- R[t3] + R[s0]
```

则总执行时钟周期数是（　）。

A．9　　　　B．10　　　　C．11　　　　D．12

> [!note]- 原题截图
> ![[relax1000CO 05 中央处理器 选择 069.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 第一条指令 add s0 写 s0，第二条指令 lw t3, 0(s0) 需要在译码/取数阶段用到 s0，由于寄存器堆采用前半周期写、后半周期读，只需相差一个周期即可正确读到新值，两条指令之间不需要插入气泡。第二条指令 lw 是 load 指令，在 MEM 阶段才产出 t3，而第三条指令 add t4, t3, s0 需要在 EX 阶段使用 t3，属于 load-use 冒险；由于本题不采用转发技术，只能通过插入气泡等待 t3 写回寄存器堆后再读出，需要插入若干个气泡以保证第三条指令的译码/取数阶段安排在 lw 写回（WB）周期的前半周期完成写入之后。按流水线时序逐拍排列可得总执行时钟周期数为 11，C 正确。

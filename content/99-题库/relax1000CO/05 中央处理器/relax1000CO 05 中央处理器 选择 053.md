## 题干

53. 当 CPU 内部 cache 发生缺失时，CPU 应该如何处理？（　）。

A．阻塞当前进程，发起进程调度　　　　B．等待数据载入

C．进程异常处理　　　　D．执行其他指令

> [!note]- 原题截图
> ![[relax1000CO 05 中央处理器 选择 053.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** cache 缺失是硬件事件，由 CPU 硬件透明处理，不会触发进程调度（进程调度是操作系统的职责），A 错误；cache 缺失不是软件异常（如缺页/页面错误），不需要操作系统或异常处理程序介入，它是硬件自动处理的，C 错误；cache 缺失时 CPU 需要从下一级存储（如主存）中把数据载入 cache，这个过程由硬件自动完成，CPU（或该指令）需等待数据载入完成后才能继续，B 正确；D 与 cache 缺失时硬件自动处理数据加载的机制不符。

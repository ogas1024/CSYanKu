## 题干

68. 在理想的 RISC 处理器 5 段流水线（IF→ID→EX→MEM→WB）中执行以下指令序列，采用转发和硬件阻塞处理数据冒险：

```
lw  t0, 0(s0)    // R[t0] <- M[R[s0]]
add s1, t0, s2   // R[s1] <- R[t0] + R[s2]
sub t1, s1, t0   // R[t1] <- R[s1] - R[t0]
sw  t1, 4(s0)    // M[R[s0]+4] <- R[t1]
```

则平均 CPI 是（　）。

A．2.0　　　　B．2.25　　　　C．2.5　　　　D．3.0

> [!note]- 原题截图
> ![[relax1000CO 05 中央处理器 选择 068.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 对于理想的 RISC 处理器 5 段流水线（IF→ID→EX→MEM→WB），每个流水段占一个时钟周期，执行了四条指令，需要求总时钟周期数。其中只有 lw 指令和紧随其后需要用到 t0 的 add 指令之间出现 load-use 冒险，无法只通过转发技术解决，需阻塞一个时钟周期；sub 指令虽然也用到 s1、t0，但与 add 之间已隔开足够拍数，可通过转发解决，无需再阻塞。因此共需 9 个时钟周期，$\text{CPI} = \dfrac{9}{4} = 2.25$，B 正确。

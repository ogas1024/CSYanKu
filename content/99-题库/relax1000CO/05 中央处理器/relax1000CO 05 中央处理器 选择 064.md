## 题干

64. 某流水线处理器采用数据旁路（转发）技术，在执行下列指令序列仍可能产生阻塞的情况是（　）。

注：

```
ADD R1,R2,R3        //R[1] <- R[2] + R[3]
SUB R1,R2,R3        //R[1] <- R[2] - R[3]
LW  R1,0(R2)        //R[1] <- M(R[2]+0)
```

A．ADD R1,R2,R3；SUB R4,R5,R6　　　　B．ADD R1,R2,R3；SUB R4,R1,R6

C．LW R1,0(R2)；ADD R3,R4,R5　　　　D．LW R1,0(R2)；ADD R3,R1,R4

> [!note]- 原题截图
> ![[relax1000CO 05 中央处理器 选择 064.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** A：ADD R1,R2,R3（R1=R2+R3）与 SUB R4,R5,R6 两条指令无寄存器共享，无数据依赖，无需数据转发，A 错误。B：ADD R1,R2,R3（写 R1）与 SUB R4,R1,R6（读 R1）存在 RAW 冒险，但可通过数据转发将 ADD 在 EX/MEM 段的运算结果直接传递给 SUB 的 EX 阶段，流水线不会停顿，B 错误。C：LW R1,0(R2)（从内存读取数据存入 R1）与 ADD R3,R4,R5（与 R1 无关）两条指令无寄存器共享，无数据依赖，无需数据转发，C 错误。D：LW R1,0(R2)（写 R1，加载结果在 MEM 阶段才可用）与 ADD R3,R1,R4（读 R1，需在 EX 阶段使用 R1 的值）属于典型的 load-use 类型数据冒险，即使使用转发技术仍需硬件阻塞一个周期，D 正确。

## 题干

40. DMA 的传送方式可以分停止 CPU 访存、周期挪用、DMA 与 CPU 交替访存 3 种方式。下列说法错误的是（　）。

A. 停止 CPU 访存方式适用于高速 I/O 设备进行 DMA 传输

B. 周期挪用方式适用于 I/O 设备的读写周期大于存取周期的情况

C. DMA 与 CPU 交替访存适用于总线周期大于存取周期的情况

D. 周期挪用方法可以兼顾 I/O 传送的及时性和 CPU 访问内存的效率

> [!note]- 原题截图
> ![[relax1000CO 06 总线和输入输出系统 选择 040.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：**
>
> 停止 CPU 访存方式控制简单，因为需要等一组数据全部传送完成后再让出总线控制权，因此比较适合高速 I/O 设备，以尽可能减少 CPU 的等待时间，A 正确。周期挪用方式中，I/O 设备每挪用一个主存周期都要申请和归还总线控制权，若传输一个字的数据本身只需 1 个主存周期而 DMA 接口需占用多个主存周期才划算，因此适合 I/O 设备的读写周期大于存取周期的情况，B 正确。DMA 与 CPU 交替访存适用于 CPU 的工作周期比主存存取周期长的情况，即把一个 CPU 工作周期分为两部分分别用于 DMA 访存和 CPU 访存，而不是“总线周期大于存取周期”，C 错误。周期挪用方法按字传输：CPU 访存时若 I/O 设备有请求则让 CPU 先完成访存，再由 DMA 控制器访存；若 CPU 和 DMA 控制器同时请求访存，则 CPU 暂停访存一到多个主存周期，由 DMA 控制器完成若干个字的数据传输，这样 CPU 访存不会被延误较长时间，DMA 访存也能及时进行，D 正确。

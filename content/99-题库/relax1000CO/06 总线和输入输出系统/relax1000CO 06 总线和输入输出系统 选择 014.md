## 题干

14. 独立编址方式下，可以实现从 I/O 端口到 CPU 寄存器的数据传输的指令是（　）。

A. OUT 指令

B. WRITE 指令

C. READ 指令

D. IN 指令

> [!note]- 原题截图
> ![[relax1000CO 06 总线和输入输出系统 选择 014.png]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：**
>
> 从 I/O 端口到 CPU 寄存器，是 CPU 把外设的相关信息（数据/状态寄存器的内容）读进来，用的是 I/O 指令中的 IN 指令。WRITE 和 READ 指令是文件操作相关的指令。注意：I/O 接口中控制线通常传送读/写命令，本质就是 IN/OUT 指令通过译码发出的读写控制信号，而不是指 read 和 write 指令；如果是统一编址方式，MOV 指令即可实现数据传输。

## 题干

20. 设二叉树共有 n 个结点，下列程序段的时间复杂度是（ ）。

```c
int maxFunc(TreeNode root) {
    if (root == NULL) return 0;
    return max(maxFunc(root->left), maxFunc(root->right)) + 1;
}
```

A. $O(\log_2 n)$

B. $O(n)$

C. $O(n\log_2 n)$

D. $O(2^n)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 020.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 此题目的算法的意思是计算出二叉树的最大深度，通过简单地遍历一遍二叉树内的所有结点即可求出结果。此算法的时间复杂度是 $O(n)$。

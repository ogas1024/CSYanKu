## 题干

18. 对于下列求 Fibonacci 数的算法，其时间复杂度为（ ）

```c
int Fibonacci(int n) {
    if(n == 1 || n==2) return 1;
    return Fibonacci(n-1) + Fibonacci(n-2);
}
```

A. $O(n)$

B. $O(n^2)$

C. $O(\sqrt{n})$

D. 指数复杂度

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 018.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 根据递推关系得 $T(n)=T(n-1)+T(n-2)+O(1)$，可以用递归树展开的方式，树高为 $O(n)$，时间复杂度是递归树的结点个数，显然这是一个指数级时间复杂度。

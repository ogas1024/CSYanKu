## 题干

23. 下列递归代码的时间复杂度为（ ）

```c
void process(int n) {
    if (n <= 1) return;

    int sum = 0;
    for (int i = 0; i < n; ++i) sum += i;
    printf("%d\n", sum);
    for (int i = 0; i < 2; ++i)
        process(n / 2);
}
```

A. $O(n\log_2 n)$

B. $O(n^2)$

C. $O(n^2\log_2 n)$

D. $O(\log_2 n)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 023.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：**
>
> 【方法一】代入法
>
> $$T(n)=2T(n/2)+O(n)=2\big(2T(n/4)+O(n/2)\big)+O(n)=4T(n/4)+O(n)+O(n)$$
> $$=4T(n/4)+2O(n)=4\big(2T(n/8)+T(n/4)\big)+2O(n)=8T(n/8)+3O(n)$$
> $$=2^{\log_2 n}T(1)+\log_2 n\cdot O(n)=O(n\log_2 n)$$
>
> 适合代入法的例子：12 年真题阶乘
>
> ```c
> int fact(int n) {
>     if (n <= 1) return 1;
>     else return n * fact(n - 1);
> }
> ```
>
> $$T(n)=\begin{cases}O(1) & n\le 1\\ O(1)+T(n-1) & n>1\end{cases}$$
> $$T(n)=O(1)+T(n-1)=O(1)+O(1)+T(n-1)=2O(1)+T(n-2)=\cdots$$
> $$=(n-1)O(1)+T(1)=(n-1)O(1)+O(1)=nO(1)=O(n)$$
>
> 【方法二】递归树法。根据递归式，其中 $2T(n/2)$ 是每次递归都会产生 2 个子递归，规模变为原来的 1/2，且每次参数为 n 的递归中，for 循环累计求和的开销是 $\Theta(n)$。
>
> 递归树结构：$T(n)$ 分两支 $T(n/2)、T(n/2)$，各自再分两支 $T(n/4)$，如此重复，共 $\log_2 n$ 层。
>
> 递归树的高度为 $\log_2 n$，每层的工作量如下：
>
> - 第 0 层（根层）：执行 $O(n)$
> - 第 1 层：执行 $2\times O(n/2)=O(n)$
> - 第 2 层：执行 $4\times O(n/4)=O(n)$
> - 第 3 层：执行 $8\times O(n/8)=O(n)$
> - ……
>
> 每一层的工作量都是 $O(n)$，递归树有 $\log_2 n$ 层。
>
> 【方法三】主定理（记结论）
>
> 递归表达式形如：$T(n)=aT(n/b)+f(n)$
>
> - $n^{\log_b a}>f(n)$，则 $T(n)=\Theta(n^{\log_b a})+O(n^{\log_b a})=\Theta(n^{\log_b a})$
> - $n^{\log_b a}<f(n)$，且对于某个常数 $c<1$ 和所有足够大的 n 有 $af(n/b)\le cf(n)$，则可以推导出 $T(n)=\Theta(f(n))$
> - $n^{\log_b a}=f(n)$，则 $T(n)=\Theta(n^{\log_b a})+\Theta(n^{\log_b a}\log_2 n)=\Theta(n^{\log_b a}\log_2 n)$
>
> 回到这题：$T(n)=2T(n/2)+\Theta(n)$，$a=2,b=2,f(n)=O(n)$，$n^{\log_b a}=n=f(n)$，满足第三种情况，答案为 $O(n\log_2 n)$。

## 题干

10. 下列代码的时间复杂度是（ ）

```c
for (int i = 1; i <= n; i ++ ) {
    for (int j = 1; j <= n; j ++ ) {
        k = 1;
        while (k <= n) k *= 5;
    }
}
```

A. $O(n^2)$

B. $O(n^3)$

C. $O(n^2\log_2 n)$

D. $O(n\log_2 n)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 010.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 外面两个 for 循环，执行循环次数分别是 n, n；每次循环执行一次 while 循环，一次 while 循环的时间开销 $T(n)=\log_5 n=O(\log_2 n)$，所以整个时间复杂度 $T(n)=n*n*\log n=O(n^2\log_2 n)$。

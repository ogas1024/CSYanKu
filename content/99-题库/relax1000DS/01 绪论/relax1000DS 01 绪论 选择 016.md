## 题干

16. 以下代码的时间复杂度为（ ）

```c
void F(int n) {
  int sum = 0;
  for (int i = 1; i <= n; i ++ ) {
    for (int j = 0; j < n; j += i) {
      sum += j;
    }
  }
}
```

A. $O(n^2)$

B. $O\left(n^{\frac{3}{2}}\right)$

C. $O(n\log_2 n)$

D. $O(n^3)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 016.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 考虑到内部循环每次执行 $\frac{n}{i}$ 次操作。总的执行次数就是 $\sum \frac{n}{k}=n\sum\frac{1}{k}$，即 $O(n\log n)$。
>
> 调和级数 $H_n=\sum_{k=1}^{n}\frac{1}{k}$ 近似 $O(\log n)$ 证明如下：
>
> 证明下界：$\sum_{k=1}^{n}\frac{1}{k}\ge\sum_{k=2}^{n}\frac{1}{k}+1\ge\int_2^{n+1}\frac{1}{x}dx+1=\ln(n+1)-\ln(2)+1=\ln\left(\frac{n+1}{2}\right)+1=\ln(n+1)\Rightarrow H_n\in\Omega(\log n)$
>
> 证明上界：$\sum_{k=1}^{n}\frac{1}{k}\le 1+\int_1^n \frac{1}{x}dx=1+\ln n\Rightarrow H_n\in O(\log n)$
>
> 综合以上，$\ln(n+1)\le H_n\le 1+\ln n \Rightarrow H_n\in\Theta(\log n)$

## 题干

13. 以下程序的时间复杂度是（ ）

```c
for (int i = 1; i <= n; i ++ ) {
    for (int j = i; j <= n; j ++ ){
        count ++ ;
    }
}
```

A. $O(n)$

B. $O(n^2)$

C. $O(n\log_2 n)$

D. $O(\log_2 n)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 013.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 外层循环：i 从 1 到 n，共执行 n 次；
>
> 内层循环：对每个 i，j 从 i 到 n，共执行 $n-i+1$ 次（当 $i\le n$ 时）
>
> 我们要计算语句 count++ 总共执行了多少次：
>
> $T(n)=\sum_{i=1}^{\lfloor n/2\rfloor}(n-i+1)$，令 $m=\lfloor n/2\rfloor$，有
>
> $T(n)=\sum_{i=1}^{m}(n-i+1)=\frac{m(n+n-m+1)}{2}=\frac{m(2n-m+1)}{2}=O(n^2)$，答案选 B。

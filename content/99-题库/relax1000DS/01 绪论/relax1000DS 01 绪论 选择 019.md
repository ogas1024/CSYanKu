## 题干

19. 以下是经典汉诺塔问题的伪代码，在调用 hanoi(n, 'A', 'C', 'B'); 时，时间复杂度是（ ）。

```c
void hanoi(int n, char from_rod, char to_rod, char aux_rod) {
    if (n == 1) {
        只有一个盘子时，直接移动到目标柱子
        return;
    }
    hanoi(n-1, from_rod, aux_rod, to_rod);
    将最大的盘子（第 n 个）从起始柱子移动到目标柱子
    hanoi(n-1, aux_rod, to_rod, from_rod);
}
```

A. $O(2^n)$

B. $O(n)$

C. $O(n^2)$

D. $O(n\log n)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 019.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 此题也可考察盘子移动次数，难度会更高。设 n 个盘子的汉诺塔问题移动次数为 $S(n)$，推导如下：
>
> ① $n=1$，只需要将这个盘子从源塔移动到目标塔，$S(1)=1$；
>
> ② 分析代码：
>
> - `hanoi(n-1, from_rod, aux_rod, to_rod);` 将上面的 $n-1$ 个盘子从起始柱子通过目标柱子移动到辅助柱子，这个递归的移动次数为 $S(n-1)$
> - 将最大的盘子（第 n 个）从起始柱子移动到目标柱子，由①可知，移动 1 次即可
> - `hanoi(n-1, aux_rod, to_rod, from_rod);` 将那 $n-1$ 个盘子从辅助柱子通过起始柱子移动到目标柱子，这个递归的移动次数也为 $S(n-1)$
>
> ③ $S(n)=2S(n-1)+1 \to S(n)+1=2(S(n-1)+1)=2^2(S(n-2)+1)=\cdots=2^{n-1}(S(1)+1)=2^n \to S(n)=2^n-1$
>
> 综上，盘子的移动次数为 $2^n-1$，即时间复杂度为 $O(2^n)$，答案选 A。

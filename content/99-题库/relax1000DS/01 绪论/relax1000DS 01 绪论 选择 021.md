## 题干

21. 下列代码的时间复杂度是（ ）

```c
int func(int n) {
    if (n == 1) return 1;
    return func(n - 1) * n;
}
```

A. $O(n^2)$

B. $O(n)$

C. $O(2^n)$

D. $O(n\log_2 n)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 021.png]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 递归关系式为 $T(n)=T(n-1)+O(1)$，为什么这里是 $O(1)$ 不是 $O(n)$，因为 `*n` 是单个乘法操作，时间消耗为常数。展开递归：$T(n)=T(n-1)+O(1)=(T(n-2)+O(1))+O(1)=(T(n-3)+O(1))+O(1)+O(1)=\cdots=T(1)+O(n)$。因为 $T(1)=O(1)$，最终得：$T(n)=O(n)$

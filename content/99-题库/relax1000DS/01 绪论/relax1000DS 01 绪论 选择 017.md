## 题干

17. 下面程序的时间复杂度是（ ）

```c
void func(int n){
    int i, j, k;
    int count = 0;
    for (int i = 1; i <= n; i *= 2){
        for (int j = 1; j <= i; j ++ ){
            for (k = 1; k <= j; k ++ ){
                count ++ ;
            }
        }
    }
}
```

A. $O(n^3)$

B. $O(n^2)$

C. $O(n\log_2 n)$

D. $O(n^2\log_2 n)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 017.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：**
>
> $$\sum_{i=\{1,2,4,\cdots,2^q\}}\ \sum_{j=1}^{i}\ \sum_{k=1}^{j}1$$
> $$=\sum_{i=\{1,2,4,\cdots,2^q\}}\ \sum_{j=1}^{i} j$$
> $$=\sum_{i=\{1,2,4,\cdots,2^q\}}\ \frac{i(i+1)}{2}$$
> $$=\frac{1}{2}\sum_{i=\{1,2,4,\cdots,2^q\}} i^2+i$$
> $$=\frac{1}{2}(1+4+4^2+\cdots+4^q)+\frac{1}{2}(1+2+\cdots+2^q)$$
> $$=\frac{1}{2}\left(\frac{1-4^{q+1}}{1-4}\right)+\frac{1}{2}\cdot\frac{1-2^{q+1}}{1-2}$$
> $$=\frac{4^{q+1}-1}{6}+\frac{2^{q+1}-1}{2}\ \xrightarrow{2^q\sim n}\ O(n^2)$$

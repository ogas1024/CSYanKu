## 题干

25. 下列程序段的空间复杂度是（ ）。

```c
int func(int m,int n){
    if(m==n)
        return 1;
    else{
        int mid=(m+n)/2;
        return func(m,mid)+func(mid+1,n);
    }
}
```

A. $O(\log_2 n)$

B. $O(n)$

C. $O(n\log_2 n)$

D. $O(2^n)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 025.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 可以写出算法的递归表达式是 $S(n)=2\times S(n/2)+1$；可以画出该递归式对应的递归树：根节点区间 $[0,n]$ 分两支 $[0,n/2]$、$[n/2+1,n]$，再各自分两支（如 $[0,n/4]$、$[n/4+1,n/2]$ 及 $[n/2+1,3n/4]$、$[3n/4+1,n]$），依此类推。
>
> 在最坏情况下，递归会一直分解到 m 等于 n，每次递归将区间一分为二，因此递归深度为 $O(\log n)$，选择 A。

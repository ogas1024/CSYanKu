## 题干

14. 下列代码的时间复杂度是（ ）

```c
for(i=1;i<=n;i++)
    for(j=1;j<=n;j++){
        c[i][j]=0;
        for(k=1;k<=n;k++)
            c[i][j]=c[i][j]+a[i][k]*b[k][j];
    }
```

A. $O(n)$

B. $O(n^2)$

C. $O(n^2\log_2 n)$

D. $O(n^3)$

> [!note]- 原题截图
> ![[relax1000DS 01 绪论 选择 014.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 该算法为矩阵乘法，所有语句频度之和，是矩阵阶数 n 的函数，用 f(n) 表示之。换句话说，上例算法的执行时间与 f(n) 成正比：$f(n)=2n^3+3n^2+2n+1$，即时间复杂度是 $O(n^3)$。
>
> 各语句频度标注：
>
> ```c
> for(i=1;i<=n;i++)                          // 频度为 n+1
>     for(j=1;j<=n;j++)                      // 频度为 n*(n+1)
>     {
>         c[i][j]=0;                          // 频度为 n^2
>         for(k=1;k<=n;k++)                   // 频度为 n^2*(n+1)
>             c[i][j]=c[i][j]+a[i][k]*b[k][j]; // 频度为 n^3
>     }
> ```

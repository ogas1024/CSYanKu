## 题干

21. $a \times (b + c) - d$ 的前缀表达式是（ ）。

A. abcd*+-

B. abc+*d-

C. -\*a+bcd

D. -+\*abcd

> [!note]- 原题截图
> ![[relax1000DS 03 栈队列和数组 选择 021.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：**
>
> 【方法一】括号法
>
> 按运算顺序添加括号：((a * (b + c)) - d)，按计算顺序依次把括号内的运算符提到括号外，再去掉括号
>
> ① 括号先算：(b + c) → 前缀是 + b c
>
> ② 然后：(a * (b + c)) → 前缀是 * a + b c
>
> ③ 最后：* a + b c - d → 前缀是 - * a + b c d
>
> 【方法二】栈模拟，参考上题。

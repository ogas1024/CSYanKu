## 题干

43. 判断线索二叉树中 *p 结点有右孩子结点的条件是（ ）。

A. p != NULL

B. p->rchild != NULL

C. p->rtag == 0

D. p->rtag == 1

> [!note]- 原题截图
> ![[relax1000DS 05 树与二叉树 选择 043.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 根据线索二叉树的定义，rtag=0 表示有右孩子，rtag=1 表示没有右孩子，此时右指针表示的是后继的线索。

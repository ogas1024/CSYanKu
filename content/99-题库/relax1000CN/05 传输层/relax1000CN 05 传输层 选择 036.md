## 题干

43. 一台主机使用 TCP（MSS=1KB, RTT=50ms）传输数据，在 cwnd 为 16KB 时发生超时。此后，接收方在其所有 ACK 中通告的 rwnd 恒为 14KB。请计算，从超时事件发生起到该主机的 cwnd 再次增长到 16KB，其平均数据吞吐量约为（ ）。

A. 75.5 KB/s

B. 152.5 KB/s

C. 178.2 KB/s

D. 227.5 KB/s

> [!note]- 原题截图
> ![[relax1000CN 05 传输层 选择 036.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 超时事件后，慢开始门限 ssthresh 变为当前 cwnd 的一半，即 16KB/2=8KB，拥塞窗口 cwnd 重置为 1KB，进入慢开始阶段。在慢开始阶段，cwnd 从 1KB 开始按指数规律增长，直到达到 ssthresh，进入拥塞避免阶段。过程为 1KB→2KB→4KB→8KB，共经历 3 个 RTT，发送的数据量为 1+2+4=7KB。在拥塞避免阶段，cwnd 从 8KB 开始，每个 RTT 增加 1KB，直到增长到 16KB。此过程需要 16-8=8 个 RTT。在此期间，发送窗口 swnd=min(cwnd, rwnd)。因 rwnd 恒为 14KB，故各 RTT 发送的数据量为 min(8,14)+min(9,14)+...+min(15,14) = 8+9+10+11+12+13+14+14 =91KB。总耗时为 3+8=11 个 RTT，即 11*50ms = 550ms = 0.55s。总发送数据量为 7KB + 91KB = 98KB。因此，平均数据吞吐量为 98KB/0.55s $\approx$ 178.2 KB/s，故 C 正确。

## 题干

3. 下列选项中，能在通信两端唯一标识一个特定 TCP 连接的是（ ）。

A. 源 IP 地址、目的 IP 地址

B. 源端口号、目的端口号

C. 协议号（TCP）、目的 IP 地址、目的端口号

D. 源 IP、源端口、目的 IP、目的端口

> [!note]- 原题截图
> ![[relax1000CN 05 传输层 选择 045.png]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 一个 TCP 连接是通过其两端的套接字来唯一确定的，套接字又由 IP 地址和端口号拼接而成。因此，必须由通信双方的 IP 地址和端口号共同组成的四元组才能在整个互联网中唯一地标识出这条连接。任何一个元素不同，都代表一条不同的连接。

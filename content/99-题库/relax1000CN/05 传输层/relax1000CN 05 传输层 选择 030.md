## 题干

37. 下列关于 TCP 拥塞控制的说法中，正确的是（ ）。

A. 发送方和接收方接收窗口的大小是一样的

B. TCP 的拥塞避免算法启动后，便可确保网络不再发生拥塞

C. 快重传机制要求发送方一旦收到 3 个冗余 ACK 就立刻重传，且接收方不允许使用捎带确认

D. 根据网络分层的“黑盒”思想，TCP 协议仅使用网络层的服务，因此 TCP 的拥塞控制机制独立于 IP 层的内部工作状态

> [!note]- 原题截图
> ![[relax1000CN 05 传输层 选择 030.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 发送窗口的大小取接收方接收窗口和拥塞窗口的较小值，在同一时刻，发送方的发送窗口并不总是和接收方的接收窗口一样大，故 A 错误。“拥塞避免”也并非指完全能够避免拥塞，而是指在拥塞避免阶段将 cwnd 值控制为按线性规律增长，使网络比较不容易出现拥塞，故 B 错误。TCP 的拥塞控制正是为了适应和响应 IP 网络内部的拥塞状态（如路由器丢包）而设计的，两者密切相关，故 D 错误。

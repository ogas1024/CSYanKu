## 题干

85. 在移动 IP 中，如何将发往移动节点归属地址的数据报转发到其当前的转交地址？（　　）

A. 修改原始 IP 数据报的目的地址为转交地址

B. 将原始 IP 数据报作为载荷，封装在一个新的 IP 数据报中

C. 将原始 IP 数据报加密后传输

D. 将原始 IP 数据报的 IP 首部和 TCP 首部都替换掉

> [!note]- 原题截图
> ![[relax1000CN 04 网络层 选择 085.webp]]

> [!success]- 答案与解析
> **答案：** B
>
> **解析：** 在移动 IP 中，使用隧道技术将发往移动节点归属地址的数据报转发到其当前的转交地址。隧道技术的本质是一种封装。归属代理收到发往移动节点的原始 IP 数据报后，并不修改它，而是把它看作一个整体的数据块，在其外部再封装上一个新的 IP 首部。

## 题干

24. 某网络拓扑如下图所示，其中路由器 R2 实现 NAT 功能。若远方路由器发送了一个 IP 分组，当 IP 分组即将到达 R2 时，该 IP 分组的目的 IP 地址是（　　）。

拓扑：Internet — R1（外网口 210.1.1.2/30）— R2（NAT，内网口 192.168.0.1/28）— H（192.168.0.2/28）

A. 210.1.1.1

B. 210.1.1.3

C. 192.168.0.1

D. 192.168.0.2

> [!note]- 原题截图
> ![[relax1000CN 04 网络层 选择 024.png]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** NAT 技术允许多台主机通过共享一个全局唯一的公网 IP 地址来访问外部网络。当一个位于外部网络的主机要向内部主机 H（192.168.0.2）发送 IP 分组时（这通常是对 H 之前发出的请求的响应），它不能直接使用私有地址 192.168.0.2 作为目的地址，因为私有地址在公网上是不可路由的，该分组的目的地址必须是 NAT 路由器 R2 的公网地址。R1 连接 R2 的端口的 IP 地址为 210.1.1.2/30，在此单对单链路上，主机号不能全 1 也不能全 0，还能给 R2 连接 R1 端口分配的 IP 地址仅有 210.1.1.1，故选 A。

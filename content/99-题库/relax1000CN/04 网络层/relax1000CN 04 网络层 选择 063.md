## 题干

63. 假设一个网络运行着距离矢量路由选择协议，如果路由器 A 和路由器 B、路由器 C 之间的链路开销分别为 1、3。某个时刻，路由器 A 收到了从 B 发送过来的距离矢量，列出了 B 与 A、B、C、D 之间的开销依次是 (1, 0, 1, 5)；A 同时收到了 C 发送过来的距离矢量 (3, 1, 0, 1)。A 更新了自己的距离矢量，可能是（　　）

A. $(0, 1, 2, 1)$

B. $(0, 1, 3, 1)$

C. $(0, 1, 2, 4)$

D. $(2, 1, 2, 4)$

> [!note]- 原题截图
> ![[relax1000CN 04 网络层 选择 063.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 将 B 的每一个距离矢量分量加上 A-B 链路开销 1，即 (1+1, 0+1, 1+1, 5+1)=(2, 1, 2, 6)；将 C 的每一个距离矢量分量加上 A-C 链路开销 3，即 (3+3, 1+3, 0+3, 1+3)=(6, 4, 3, 4)；再与 A 到自身的开销 0 一起，逐项取最小值：到 A 为 0，到 B 为 min(2,4)=1，到 C 为 min(2,3)=2，到 D 为 min(6,4)=4。因此更新后的结果为 (0, 1, 2, 4)。

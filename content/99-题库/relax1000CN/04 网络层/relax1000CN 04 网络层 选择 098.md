## 题干

98. 主机 H 的 IP 为 10.0.0.10/24，默认网关为 10.0.0.1。当 H 向 IP 地址为 8.8.8.8 的节点发送分组时，H 的数据链路层构建的以太网帧，其目的 MAC 地址是（　　）；该分组到达网关路由器后，路由器查找自身路由表并转发，此时路由器执行的操作不包括（　　）。

A. 10.0.0.1 的 MAC 地址；修改目的 IP 地址

B. 10.0.0.1 的 MAC 地址；修改源 MAC 地址

C. 10.0.0.1 的 MAC 地址；TTL 值减 1

D. 8.8.8.8 的 MAC 地址；重新计算 IP 首部校验和

> [!note]- 原题截图
> ![[relax1000CN 04 网络层 选择 098.png]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 当主机 H 要向 IP 地址为 8.8.8.8 的节点发送分组时，会先对比自己的 IP 地址和目的 IP 地址是否位于同一局域网。主机所在网络的网络号为 10.0.0.0，而 8.8.8.8 与之不在同一网段，因此主机 H 会将 IP 分组发送给默认网关，目的 MAC 地址为默认网关（10.0.0.1）的 MAC 地址。默认网关收到来自主机 H 的 IP 分组后，会将 TTL 减 1、修改源 MAC 地址为自己的 MAC 地址、重新计算 IP 首部校验和，但不会修改目的 IP 地址（不考虑 NAT 场景）。因此路由器不会执行的操作是“修改目的 IP 地址”，选 A。

## 题干

88. 一个在外地网络的移动节点，向 Web 服务器发起 HTTP 请求（使用 TCP）。在此 TCP 连接的三次握手过程中，移动节点发送的 SYN 报文的源 IP 地址，以及 Web 服务器返回的 SYN+ACK 报文的目的 IP 地址分别是（　　）。

A. 转交地址，转交地址

B. 转交地址，归属地址

C. 归属地址，转交地址

D. 归属地址，归属地址

> [!note]- 原题截图
> ![[relax1000CN 04 网络层 选择 088.webp]]

> [!success]- 答案与解析
> **答案：** D
>
> **解析：** 移动 IP 对运输层透明。这意味着 TCP 层在建立连接时，始终使用稳定不变的归属地址作为自己的身份标识。移动节点发送 SYN 报文，IP 层的源地址是归属地址。Web 服务器收到后，会向这个连接的端点回复 SYN+ACK 报文，IP 层的目的地址是移动节点的归属地址，该报文会被路由到归属代理，再被隧道转发。

## 题干

45. 主机 H 通过 HTTP/1.1 与服务器 S 通信，请求一个大小为 6MSS 的图像文件。H 与 S 之间的 RTT 恒为 10ms，TCP 连接已建立，且 TCP 的拥塞窗口 cwnd 初始值为 1MSS，慢开始门限为 8MSS。假设 S 收到 H 的请求后立即开始发送数据，忽略 HTTP 报文开销和 TCP 段的传输时延。从 H 发送针对该图像的 HTTP 请求报文的时刻算起，到 H 收到全部图像文件为止，至少需要经过（ ）。

A. 30ms

B. 35ms

C. 40ms

D. 45ms

> [!note]- 原题截图
> ![[relax1000CN 06 应用层 选择 045.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 第 1 个 RTT：H 的 HTTP 请求到达 S，S 立即开始发送数据，此时 cwnd=1MSS，发送 1 个 MSS。第 2 个 RTT：S 收到确认后 cwnd 翻倍至 2MSS，继续发送 2 个 MSS，累计已发送 3 个 MSS。第 3 个 RTT：S 收到确认后 cwnd 翻倍至 4MSS（仍小于慢开始门限 8MSS），发送剩余的 6-3=3 个 MSS，数据在本 RTT 内全部发送完毕。因此整个过程至少需要 3 个 RTT，即 30ms。

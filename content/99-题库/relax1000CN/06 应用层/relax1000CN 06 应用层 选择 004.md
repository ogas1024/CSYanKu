## 题干

4. 假设使用 C/S 模型分发一个大文件 F 给 N 个用户所需最短时间为 $T_{C/S}$，而使用 P2P 模型分发相同文件给 N 个用户所需最短时间为 $T_{P2P}$，则当 N 很大时，$T_{C/S}$ 和 $T_{P2P}$ 之间的大小关系是（ ）。

A. $T_{C/S}$ 远小于 $T_{P2P}$

B. $T_{C/S}$ 约等于 $T_{P2P}$

C. $T_{C/S}$ 远大于 $T_{P2P}$

D. 无法估计

> [!note]- 原题截图
> ![[relax1000CN 06 应用层 选择 004.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 传统 C/S 模型中服务器是唯一瓶颈，需要向 N 个用户分别发送完整文件副本，总上传数据量为 N·F，分发时间随用户数 N 近似线性增长。P2P 模型中每个下载完成的用户都能立即作为上传者，系统总上传能力随用户数同步增长，分发时间增长速度远慢于线性增长。故当 N 很大时，$T_{C/S}$ 远大于 $T_{P2P}$，C 正确。

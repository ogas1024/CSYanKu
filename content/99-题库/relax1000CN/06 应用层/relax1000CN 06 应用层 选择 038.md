## 题干

38. 对于一个 URL http://www.ky.com:8080/dir/index.html，下列说法中错误的是（ ）。

A. http 是该 URL 使用的协议

B. www.ky.com 是提供服务的主机域名

C. 使用了默认端口号 8080

D. /dir/index.html 是主机上资源的路径

> [!note]- 原题截图
> ![[relax1000CN 06 应用层 选择 038.png]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** HTTP 协议的默认端口号是 80，当 URL 中像本题一样明确指定了端口号 8080 时，浏览器将连接到这个指定端口；只有 URL 中省略端口号时才使用默认端口 80，因此 C（"使用了默认端口号 8080"）错误。

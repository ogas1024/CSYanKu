## 题干

9. 假设网络中有两台 DHCP 服务器 S1 和 S2，客户端 C 广播"DHCP 发现"报文后，S1 和 S2 均回复了"DHCP 提供"报文。若 C 选择了 S1 的租约，则 S2 是在哪个阶段得知自己的"DHCP 提供"报文未被接受的？（ ）

A. 客户端 C 广播"DHCP 请求"报文后

B. DHCP 服务器 S1 广播"DHCP 确认"报文后

C. 客户端 C 租约期满后

D. DHCP 服务器 S2 的"DHCP 提供"报文超时后

> [!note]- 原题截图
> ![[relax1000CN 06 应用层 选择 009.webp]]

> [!success]- 答案与解析
> **答案：** A
>
> **解析：** 客户端 C 收到一个或多个"DHCP 提供"报文后，会选择其中一个（S1）并广播一个"DHCP 请求"报文，其中包含所选服务器（S1）的标识符；网络中所有 DHCP 服务器都会收到这个广播。S2 收到后检查服务器标识符，发现不是自己，即可得知自己的"DHCP 提供"未被采纳，从而收回为 C 预留的 IP 地址。

## 题干

8. 新加入的主机 H 通过发送"DHCP 发现"报文寻找 DHCP 服务器 S，此过程中该报文的源 IP 地址和目的 IP 地址分别是（ ）。

A. 0.0.0.0、S 的 IP 地址

B. H 的 IP 地址、S 的 IP 地址

C. 0.0.0.0、255.255.255.255

D. H 的 IP 地址、255.255.255.255

> [!note]- 原题截图
> ![[relax1000CN 06 应用层 选择 008.webp]]

> [!success]- 答案与解析
> **答案：** C
>
> **解析：** 在 DHCP 发现阶段，客户端主机 H 尚未获得 IP 地址，源 IP 地址填 0.0.0.0；客户端不知道 DHCP 服务器位置，需以广播形式查找，目的 IP 地址为 255.255.255.255。

## 题干

【答案 P179】16. （2020 统考真题）某校园网有两个局域网，通过路由器 R1、R2 和 R3 互联后接入 Internet, S1 和 S2 为以太网交换机。

局域网采用静态 IP 地址配置，路由器部分接口以及各主机的 IP 地址如下图所示。

![[王道CN 4.2 IPv4 综合 16-fig1.jpg]]

假设 NAT 转换表结构为

| 外网 IP 地址 | 外网端口号 | 内网 IP 地址 | 内网端口号 |
|---|---|---|---|
|  |  |  |  |

请回答下列问题：

- **（1）** 为使 H2 和 H3 能够访问 Web 服务器（使用默认端口号），需要进行什么配置？

- **（2）** 若 H2 主动访问 Web 服务器时，将 HTTP 请求报文封装到 IP 数据报 P 中发送，则 H2 发送的 P 的源 IP 地址和目的 IP 地址分别是什么？经过 R3 转发后，P 的源 IP 地址和目的 IP 地址分别是什么？经过 R2 转发后，P 的源 IP 地址和目的 IP 地址分别是什么？

> [!note]- 原题截图
> ![[王道CN 4.2 IPv4 综合 16.png]]

> [!success]- 答案与解析
> **答案：**
>
> （1）在R2设置静态端口映射：外网203.10.2.2:80 ↔ 内网192.168.1.2:80；R3无需为H2、H3预设静态项。
>
> （2）H2发P：源192.168.1.2，目的203.10.2.2；经R3：源203.10.2.6，目的203.10.2.2；经R2：源203.10.2.6，目的192.168.1.2。
>
> **解析：** Web服务器位于R2内网，外部访问必须用R2公网地址和80端口静态映射到服务器。H2主动访问时R3动态改写源地址，R2再依据静态映射改写目的地址；服务器目的端口仍为80。

## 题干

【答案 P177】12. 某网络拓扑见下图，R1 和 R2 为路由器，R2 实现了 NAT 功能，Switch 为交换机，Hub 为集线器，Web 服务器 S、主机 H1～H4 和路由器各接口的 IP 地址配置见图中标注。

![[王道CN 4.2 IPv4 综合 12-fig1.jpg]]

回答下列问题：

- **（1）** R2 的 E1 接口的 IP 地址是什么？H1 配置的默认网关是什么？

- **（2）** 假设 H1 和 R2 的 ARP 缓存初始均为空，交换机的交换表初始也为空，H1 向 H3 发送一个 IP 分组 A，H3 收到 A 后向 H1 发送一个响应 IP 分组 B，则能收到封装 A 的以太网帧的主机有哪些？能收到封装 B 的以太网帧的主机有哪些？

- **（3）** H1 发出的封装有 HTTP 请求报文的 IP 分组 C，首部中的源 IP 地址和目的 IP 地址分别是什么？当 C 从 R2 转发出去时，首部中的源 IP 地址和目的 IP 地址分别是什么？

> [!note]- 原题截图
> ![[王道CN 4.2 IPv4 综合 12.png]]

> [!success]- 答案与解析
> **答案：**
>
> （1）R2的E1为203.10.2.1；H1默认网关为172.18.1.126。
>
> （2）封装A的帧在Hub侧由H3、H4收到（H3接收，H4丢弃）；封装B的帧由H4、H1收到（H1接收，H4丢弃）。
>
> （3）H1发出C时源/目的IP为172.18.1.33和213.48.226.31；R2经NAT转发后源/目的IP为203.10.2.1和213.48.226.31。
>
> **解析：** /30点到点链路只有两个可用地址，据图推出E1。跨子网通信经R2并分别触发ARP；Hub会把帧复制给同冲突域主机。NAT只把私有源地址替换为R2公网接口地址，目的服务器地址不变。
